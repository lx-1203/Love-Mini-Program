## 1. 产品简介

### 1.1 产品定位

校园恋爱小程序（Campus Love）是一款专为在校大学生设计的校园社交应用，致力于为大学生提供：

- **真实校园社交**：基于学生身份认证，确保用户真实可信
- **智能匹配推荐**：根据兴趣、专业、校区智能推荐
- **安全聊天互动**：实时聊天、语音消息、视频通话
- **丰富校园生活**：校园话题、活动报名、兴趣圈子

### 1.2 适用人群

- 在校大学生（含本科生、研究生、博士生）
- 年龄 18-30 岁
- 持有有效学生证件或教育邮箱

### 1.3 支持平台

| 平台 | 入口 | 说明 |
|------|------|------|
| 微信小程序 | 微信搜索"校园恋爱" | 主要发布渠道 |
| H5 网页 | https://h5.campuslove.example.com | 浏览器访问（部分功能受限） |

### 1.4 核心价值

- ✅ **真实**：所有用户经过校园认证，杜绝虚假账号
- ✅ **安全**：隐私保护、内容审核、举报机制完善
- ✅ **有趣**：智能匹配、丰富互动、趣味活动
- ✅ **免费**：核心功能永久免费，会员服务可选

## 2. 首次使用

### 2.1 注册与登录

#### 2.1.1 微信小程序登录

1. 在微信中搜索"校园恋爱"小程序
2. 点击"进入小程序"
3. 首次进入会弹出「隐私协议」弹窗
4. 阅读隐私协议后，可选择：
   - **同意并继续**：进入小程序
   - **查看协议**：详细阅读隐私政策与用户协议
   - **不同意**：退出小程序

#### 2.1.2 完成基础资料

首次登录后需完成基础资料填写：

1. **昵称**：2-12 字符，支持中英文数字
2. **性别**：男 / 女（注册后不可修改）
3. **生日**：用于年龄计算与匹配
4. **学校**：从下拉列表选择（覆盖全国 1000+ 高校）
5. **校区**：部分学校有多个校区
6. **入学年份**：用于学生身份验证

#### 2.1.3 校园认证（可选，强烈推荐）

完成基础资料后可进行校园认证，获得以下权益：

- 解锁匹配功能
- 发布动态与评论
- 参与活动报名
- 信任标识（认证图标）

**认证方式**（任选其一）：

1. **学生证上传**：上传学生证照片（清晰可见学校、姓名、学号、有效期内）
   - 审核 time：1-24 小时
   - 隐私保护：仅用于审核，不会公开展示
2. **教育邮箱验证**：输入 .edu 邮箱接收验证码
   - 即时验证，无需等待审核

### 2.2 完善个人资料

完善的个人资料可显著提升匹配成功率：

#### 2.2.1 必填项

- 昵称、性别、生日、学校、校区、入学年份
- 头像（建议清晰正面照，≤ 5MB）
- 个人简介（≤ 200 字，展示真实的自己）

#### 2.2.2 选填项（推荐完成）

- **照片墙**：最多 6 张生活照（≤ 10MB/张）
  - 建议：自然真实，避免过度滤镜
  - 禁止：违规内容、他人照片、广告二维码
- **个人视频**：1 个 30 秒以内短视频（≤ 50MB）
  - 介绍自己、展示才艺
- **兴趣标签**：从 50+ 标签中选择 3-10 个
  - 包含：运动、音乐、电影、阅读、美食、旅行等
- **匹配偏好**：
  - 期望性别：男 / 女 / 都可以
  - 期望年龄范围：18-30 岁
  - 期望校区：本校 / 不限
  - 期望兴趣：3-5 个标签

#### 2.2.3 资料完成度

资料完成度 ≥ 80% 时：
- 匹配优先级提升
- 解锁「精选推荐」
- 获得「资料完整」徽章

### 2.3 隐私设置

进入「我的 → 设置 → 隐私」可配置：

- **资料可见范围**：所有人 / 仅匹配对象 / 仅本校
- **位置展示**：精确 / 仅城市 / 不展示
- **在线状态**：展示 / 隐藏
- **最近活跃**：展示 / 隐藏
- **被搜索**：允许 / 禁止
- **消息接收**：所有人 / 仅匹配对象 / 仅认证用户

## 3. 核心功能

### 3.1 首页（Home）

#### 3.1.1 课表与日程

- 同步学校教务系统课表（如支持）
- 手动添加日程提醒
- 上课时间自动隐身，避免打扰

#### 3.1.2 AI 智能计划

- AI 根据你的课表、兴趣、匹配对象推荐每日行动
- 例如："今天下午没课，去图书馆自习，可能遇到兴趣相投的同学"
- 可设置接收/关闭 AI 计划推送

#### 3.1.3 推荐匹配

- 基于兴趣、专业、校区的智能推荐
- 每日刷新 10-20 个推荐对象
- 支持滑动浏览（左滑跳过、右滑喜欢）

#### 3.1.4 校园活动

- 学校社团活动、官方活动、用户自发活动
- 按时间、地点、类别筛选
- 一键报名，活动前 1 小时提醒

### 3.2 发现（Discover）

#### 3.2.1 推荐匹配

**核心匹配玩法**：

1. 浏览推荐用户卡片（含头像、昵称、年龄、学校、兴趣标签、个人简介）
2. **喜欢**：点击爱心图标或右滑
3. **跳过**：点击 × 图标或左滑
4. **超级喜欢**：长按爱心（每日 1 次，VIP 每日 3 次）
5. **反悔**：误操作可在 5 秒内反悔（每日 1 次，VIP 每日 5 次）

**匹配成功**：

- 双方互相喜欢即匹配成功
- 弹窗提示"互相喜欢了，开始聊天吧！"
- 自动创建临时聊天会话（72 小时有效）
- 在 72 小时内发送 ≥ 1 条消息可解锁长期聊天

#### 3.2.2 喜欢我的人

- 查看谁喜欢了你（VIP 专享）
- 普通用户仅显示数量，需解锁查看详情

#### 3.2.3 互相喜欢

- 查看已匹配成功的对象列表
- 点击进入聊天会话

### 3.3 聊天（Messages）

#### 3.3.1 临时聊天

- 匹配成功后自动创建 72 小时临时聊天
- 72 小时内未发送消息，会话自动结束
- 发送 1 条消息后转为长期聊天

#### 3.3.2 消息类型

| 类型 | 说明 | 限制 |
|------|------|------|
| 文字 | 普通文本消息 | ≤ 500 字符 |
| 语音 | 录音消息 | ≤ 60 秒 |
| 图片 | 静态图片 | ≤ 10MB |
| 视频 | 短视频 | ≤ 50MB |
| 表情 | 内置表情包 | - |
| 名片 | 个人名片 | - |
| 位置 | 地理位置 | 需授权 |

#### 3.3.3 高级功能

- **已读回执**：可设置开启/关闭
- **消息撤回**：2 分钟内可撤回
- **删除消息**：仅删除本地，对方仍可见
- **举报消息**：违规消息可举报
- **清空聊天**：清空本地聊天记录

#### 3.3.4 联系方式交换

匹配后可发起联系方式交换请求：

1. 点击聊天页面右上角「交换联系方式」
2. 选择要交换的联系方式：微信 / 手机号 / QQ
3. 输入你的联系方式，发送请求
4. 对方接受后双方可见
5. 对方拒绝后 24 小时内无法再次请求

### 3.4 校园（Campus）

#### 3.4.1 校园话题

- 浏览本校同学发布的话题动态
- 支持图文、视频、投票
- 可点赞、评论、转发
- 按热度、最新、关注排序

#### 3.4.2 发布话题

1. 点击右下角「+」按钮
2. 选择类型：图文 / 视频 / 投票
3. 编辑内容（≤ 1000 字）
4. 添加图片（≤ 9 张）或视频（1 个）
5. 添加话题标签（1-3 个）
6. 选择可见范围：所有人 / 仅本校 / 仅好友
7. 点击发布

#### 3.4.3 兴趣圈子

- 加入感兴趣的圈子（运动、音乐、阅读等）
- 圈子内可发帖、评论、私信
- 圈主可管理成员、设置规则

### 3.5 村落（Village）

#### 3.5.1 树洞

- 匿名发布心事、烦恼、秘密
- 不可见真实身份
- 支持匿名评论与拥抱
- 违规内容会被自动过滤

#### 3.5.2 表白墙

- 公开向心仪对象表白
- 可匿名可实名
- 支持图文、视频
- 每日最多发布 1 条

#### 3.5.3 失物招领

- 发布寻物启事或拾物信息
- 可设置悬赏金额（虚拟币）
- 联系方式仅双方达成意向后可见

### 3.6 我的（Profile）

#### 3.6.1 个人主页

- 查看自己的资料卡片（与对方视角一致）
- 编辑资料、照片墙、视频
- 查看资料完成度

#### 3.6.2 我的动态

- 已发布的话题、表白、树洞
- 可编辑、删除、设为私密

#### 3.6.3 我的匹配

- 查看历史匹配对象
- 取消匹配（不可恢复）
- 屏蔽用户

#### 3.6.4 我的足迹

- 浏览历史
- 点赞历史
- 评论历史

#### 3.6.5 签到

- 每日签到获得积分
- 连续签到额外奖励（3 天、7 天、30 天）
- 积分可兑换会员、虚拟礼物

#### 3.6.6 钱包

- 查看余额、充值记录、消费记录
- 充值虚拟币（用于打赏、悬赏）
- 提现（仅限活动奖励）

### 3.7 设置

- 账号设置：修改昵称、头像、密码
- 隐私设置：见 §2.3
- 通知设置：推送、声音、震动
- 黑名单：查看与管理屏蔽用户
- 关于：版本号、用户协议、隐私政策
- 退出登录
- 注销账号（30 天冷静期）

## 5. 隐私与安全

### 5.1 隐私保护承诺

我们承诺：

1. **最小化采集**：仅采集提供服务必需的信息
2. **加密存储**：所有敏感信息均加密存储
3. **不售卖**：绝不向第三方售卖用户数据
4. **用户控制**：你可随时查看、修改、删除个人数据
5. **透明披露**：定期发布透明度报告

详见《隐私政策》。

### 5.2 隐私接口说明

应用使用的隐私接口及目的：

| 接口 | 目的 | 触发时机 |
|------|------|----------|
| `wx.getLocation` | 显示附近活动、距离 | 用户主动点击"附近"时 |
| `wx.chooseLocation` | 发布活动时选择地点 | 用户主动选择时 |
| `wx.chooseAddress` | 实物奖品邮寄 | 中奖后填写地址时 |
| `wx.saveImageToPhotosAlbum` | 保存图片到相册 | 用户主动点击保存时 |
| `wx.startRecord` | 录制语音消息 | 用户主动按住录音按钮时 |
| `wx.getUserProfile` | 获取头像昵称（首次登录）| 用户主动点击登录时 |

### 5.3 内容审核

#### 5.3.1 审核机制

- **机审**：敏感词过滤 + 图片视频 AI 识别
- **人审**：机审疑似违规的内容人工复核
- **用户举报**：用户举报的内容优先处理

#### 5.3.2 违规类型

| 类型 | 处罚 |
|------|------|
| 色情低俗 | 永久封禁 |
| 政治敏感 | 永久封禁 |
| 谩骂侮辱 | 警告 → 7 天 → 30 天 → 永久 |
| 广告引流 | 删除内容 → 7 天 → 30 天 |
| 诈骗 | 永久封禁 + 报警 |
| 人身攻击 | 警告 → 7 天 → 30 天 |
| 骚扰 | 警告 → 7 天 → 30 天 |

### 5.4 举报与申诉

#### 5.4.1 举报渠道

- 用户主页 → 右上角「...」→ 举报
- 聊天页面 → 长按消息 → 举报
- 话题动态 → 右上角「...」→ 举报

#### 5.4.2 举报类型

- 色情低俗
- 政治敏感
- 谩骂侮辱
- 广告引流
- 诈骗
- 人身攻击
- 骚扰
- 其他

#### 5.4.3 处理时效

- 紧急（诈骗、人身威胁）：1 小时内
- 严重（色情、政治）：4 小时内
- 一般（广告、骚扰）：24 小时内

#### 5.4.4 申诉

- 对处罚有异议可在 7 天内申诉
- 申诉路径：我的 → 设置 → 帮助与反馈 → 申诉
- 申诉结果 3 个工作日内反馈

### 5.5 账号安全

#### 5.5.1 安全建议

- 不要使用简单密码（如 123456）
- 不要将账号借给他人
- 不要点击不明链接
- 不要向他人透露验证码
- 定期检查登录设备

#### 5.5.2 异常登录

- 异地登录会触发安全提示
- 短时间内多次登录失败会锁定账号 30 分钟
- 异常行为会触发风控，可能要求二次验证

#### 5.5.3 注销账号

- 路径：我的 → 设置 → 账号 → 注销账号
- 30 天冷静期：期间可撤销注销
- 注销后：
  - 个人信息删除
  - 发布内容保留（匿名化为"已注销用户"）
  - 匹配关系解除
  - 会员权益作废
  - 余额清零（需先提现）

## 6. 常见问题

### 6.1 账号问题

#### Q1：忘记密码怎么办？

A：小程序使用微信登录，无需密码。如需注销账号，见 §5.5.3。

#### Q2：可以更换绑定的微信吗？

A：暂不支持。如需更换，请先注销账号再重新注册。

#### Q3：为什么提示"账号已被禁用"？

A：可能违反了社区规范，请查看处罚通知或联系客服申诉。

### 6.2 匹配问题

#### Q4：为什么推荐的用户很少？

A：可能原因：
- 资料完成度低（建议 ≥ 80%）
- 匹配偏好过严（建议扩大年龄、校区范围）
- 校园用户基数少（建议等待用户增长）
- 账号异常（联系客服排查）

#### Q5：为什么匹配后对方不回复？

A：可能原因：
- 对方不活跃（建议优先匹配在线用户）
- 临时聊天 72 小时内未发送消息会自动结束
- 你的开场白不够吸引人（建议个性化）

#### Q6：可以撤销"喜欢"吗？

A：5 秒内可点击"反悔"撤销（每日 1 次，VIP 5 次）。超过 5 秒无法撤销。

### 6.3 聊天问题

#### Q7：为什么发不出消息？

A：可能原因：
- 网络异常
- 对方已删除匹配
- 账号被限制（违规处罚）
- 临时聊天已过期（72 小时）

#### Q8：消息撤回时限？

A：普通用户 2 分钟，VIP 5 分钟。

#### Q9：如何拉黑用户？

A：进入对方主页 → 右上角「...」→ 拉黑。拉黑后双方不可见，不可发消息。

### 6.4 会员问题

#### Q10：VIP 权益未生效？

A：尝试以下操作：
1. 退出小程序重新进入
2. 检查支付是否成功（微信支付账单）
3. 联系客服核查订单

#### Q11：如何关闭自动续费？

A：路径：我的 → 设置 → 账号 → 自动续费 → 关闭。也可在微信「我 → 服务 → 钱包 → 支付设置 → 自动续费」中关闭。

#### Q12：会员可以退款吗？

A：见 §4.3.3 退款政策。

### 6.5 内容问题

#### Q13：发布的内容为什么被删除？

A：可能违反了社区规范。查看「我的 → 通知」中的处罚通知，或联系客服申诉。

#### Q14：被误判违规怎么办？

A：在 7 天内申诉，路径：我的 → 设置 → 帮助与反馈 → 申诉。

### 6.6 技术问题

#### Q15：小程序加载很慢？

A：尝试以下操作：
1. 切换 Wi-Fi / 4G/5G 网络
2. 清理微信缓存（微信 → 我 → 设置 → 通用 → 存储空间）
3. 退出小程序重新进入
4. 更新微信到最新版本

#### Q16：图片/视频上传失败？

A：可能原因：
- 文件超过限制（图片 ≤ 10MB，视频 ≤ 50MB）
- 网络不稳定
- 文件格式不支持
- 存储空间不足

#### Q17：语音消息无法播放？

A：检查手机音量、静音模式，尝试切换听筒/扬声器模式。

更多问题见 `docs/FAQ.md`。
