## 3. 修复进展（按阶段）

- **Phase 1（基础设施）**：catchtap 40 处 → @tap.stop（编译产物验证）；URLSearchParams polyfill（3 单测）；TabBar query storage 桥接（hot/mine）；发帖页路由修复；cat-latest/mine 契约；深色模式接线（store+设置页+H5 选择器）。
- **Phase 2（核心页面）**：寻觅卡片可见（白色占比 42.6%→61.7%）；收藏持久化；校园认证圈（徽标/话题/拦截）；学校绑定一致化；活动报名/退出闭环。
- **Phase 3（消息/我的/FAB）**：VIP 头像装饰移除；编辑资料热区 88rpx；我的页 emoji→SVG；FAB 五 Tab 接入 + 方形化。
- **Phase 4（长尾）**：本文件归档；高严重度项与硬编码收敛见 4.3/4.4 记录。
- **Phase 5（验证）**：门禁/automator/review/报告/提交。
