# 《寻觅 v3.1 最终设计与开发契约》

> 唯一规范来源：`素材/3.0`（README / FLOW_SPEC / 16 页 SVG / Design System）+ 本文档。
> 一句话设计原则：**「寻觅」不是让用户不停浏览内容，而是让用户更自然地从“看到一个人”走到“和这个人产生关系”**。
> 修改规则：任何页面/组件/API/状态改动，必须先改本文档再改代码。

## 0. 一级页面职责冻结

| 页面 | 用户心里的问题 | 形态 |
| --- | --- | --- |
| 发现 | 我可以认识谁？ | Browse（主动挑人，聚合页） |
| 附近 | 我身边有什么人/圈子？ | Explore（列表 + 四 Tab） |
| ❤️匹配 | 有没有一个现在适合我的人？ | Intent（系统帮我找，速配） |
| 消息 | 谁正在和我产生关系？ | Relationship（会话 + 悄悄话分组） |
| 我的 | 别人看到的我是什么样？ | Identity（v3 列表式） |

发现=Browse，匹配=Intent，二者职责严格切分：发现页含 CardSwiper 但整体是「快捷入口 + 推荐卡 + 细分列表」聚合页；匹配页只做速配/在线速配。

## 1. Design Token（冻结）

- Primary `#34C98A`（操作/确认/导航/认证/在线）
- Love `#FF6FA3`（喜欢/匹配结果/情绪）
- Whisper 蓝 `#4D8DFF`（悄悄话/信息）
- 背景 `#F7FAF9`、卡片 `#FFFFFF`、主文字 `#333333`、次文字 `#8A9694`、分隔线 `#E8EEEE`
- brand-600 `#22A976`
- 兴趣标签三色：`#EAF8F2/#279B70`、`#FFF0F6/#E94D87`、`#EEF3FF/#4D79D8`
- Hero 渐变 `#34C98A→#B8EFD9`；粉色渐变 `#FF6FA3→#FFD1E2`
- Hero 节奏：仅 匹配中心=绿 Hero、匹配成功=粉 Hero、我的=极浅绿区、发现/附近/消息=白底

## 2. 状态 Token（冻结）

`success`=Primary、`warning`、`error #E94D87`、`info #4D8DFF`、`online`=Primary、`offline #C8CFCD`、`disabled`、`pressed`、`selected`；写入 tokens.ts 与 scss 双源。

## 3. Icon System（冻结）

- 核心关系动作：`MatchActionButton`（LIKE/WHISPER/PASS），统一 64×64，彩色圆形底 + 白色图标 + 投影 + 细白描边（粉 `#FF6FA3` / 蓝 `#4D8DFF` / 灰 `#8A9694`）。
- 普通线性 icon：编辑/搜索/设置/更多/返回 等。
- 图标填充色不得与所在卡片/背景同色系；深色照片上白底圆钮、浅底品牌色圆钮。

## 4. TabBar（冻结）

发现 / 附近 / ❤️匹配 / 消息 / 我的；顺序/路径/图标不变；PNG 三态：灰 `#8A9694` / 绿 `#34C98A` / 中央白心。

## 5. User Card / List Row（冻结）

- 大卡 4:5；信息位：照片 → 姓名/年龄/认证 → 学校·距离 → 兴趣标签 → 一句话 → 匹配度（各页统一）。
- 列表行：头像/姓名/学校·距离/在线徽标；附近列表不出现操作按钮，操作在详情页。

## 6. 关系状态机（冻结）

```
NONE → LIKE→LIKED / PASS→PASSED / WHISPER→WHISPER_SENT→READ
LIKED + 对方 LIKE → MATCHED → CHAT → 解除匹配 → UNMATCHED
```

- 单向喜欢文案：**已送出心动**（不显示“喜欢成功”）；互喜文案：**匹配成功**。

## 7. 他人主页 CTA 状态机（冻结）

| 状态 | CTA |
| --- | --- |
| 陌生 | ❤️ 喜欢 TA（粉，主） |
| 已喜欢 | ✓ 已送出心动（可撤销） |
| 互相喜欢 | 💬 发消息（绿，主） |
| 已拉黑 | 已屏蔽（不可操作） |
| 对方不存在 | 用户不可用 |

- 关注为次级操作，移入「更多」菜单，不在首屏 CTA 区。

## 8. 治理菜单（冻结）

- 他人主页「•••」按状态展示：举报 / 拉黑 / 取消匹配（仅已匹配出现取消匹配）。
- 悄悄话联动：已送达的悄悄话保留展示；后续禁止互动；发送时已被拉黑 → 禁止发送且不扣费。

## 9. 悄悄话领域模型（统一）

- 单一 `Whisper` / `WhisperService`；入口 A（卡片 ☆）、入口 B（他人主页）、入口 C（旧 B3 `/recommendations/{userId}/whisper[/unlock]`）底层统一走 WhisperService，旧接口仅保留兼容壳。
- 状态机：`DRAFT→PAYING→SENT→DELIVERED→READ`；异常 `PAY_FAILED / SEND_FAILED / REFUNDED / BLOCKED / EXPIRED`。
- 文案：**优先送达 / 直接进入 TA 的悄悄话**（不承诺“必达”）。
- 服务端创建成功 = 收件箱生成 + NEW_WHISPER + 消息页展示。

## 10. 悄悄话规则（冻结）

- 同一对用户 A↔B 最多 1 条有效；每个发送者每日 ≤5 条；需实名。
- 幂等 `clientRequestId`：同一 id 只扣一次费、只生成一条记录。
- 钱包扣费与创建同事务；创建失败自动退款（REFUNDED）。

## 11. 匹配中心规则（冻结）

- 展示「今日剩余 N 次」+「今日已喜欢 N 人」（`getRecommendationQuota`）。
- 在线速配第二入口：「🟢 现在在线：有 N 位匹配度较高的人在线 [立即匹配]」。
- 在线候选在动作前 re-check 在线状态，离线自动降级普通匹配。

## 12. 匹配文案与进度（冻结）

- 单向喜欢：**已送出心动**；互喜：**匹配成功**。
- 匹配中进度为视觉模拟（“正在寻找适合你的 TA ● ● ●”），不显示虚假算法百分比。

## 13. 我的主页（冻结）

- 核心数据：**匹配 / 我喜欢 / 获赞**（消除“喜欢”歧义）。
- 动态区只展示最近 2–3 条 +「查看全部」；语音默认折叠。
- 移除 ProfileTabs/心动值/成就/VIP/社交升温首屏块。

## 14. 兴趣规则（冻结）

- 注册阶段引导**可跳过**；用户主动进入「兴趣偏好」页**必须 ≥3 个才能保存**。

## 15. 搜索（冻结）

- 分组「用户 / 标签 / 学校」。
- 学校结果点击进入**校园主页**（认证用户数/活跃用户/活动/兴趣圈 + 推荐用户），不落普通用户列表。

## 16. 页面路由（冻结）

- 主包 45→47：下线 `pages/profile/saved`；新增 `pages/discover/matching`、`pages/discover/match-success`、`pages/home/segment`。
- 分包新增 `subpackages/setup/interest`。

## 17. API 数据模型单一来源（冻结）

- OpenAPI → Type → clientApi → Mock → Page 同源；字段命名统一表：

| 语义 | 统一字段 |
| --- | --- |
| 我喜欢的列表 | `likes` |
| 喜欢我的列表 | `likedBy` |
| 互相喜欢 | `mutualLikes` / `matched: true` |
| 心动信号 | `heartSignal` |
| 悄悄话 | `whisper`（状态机字段 `status`） |

- 禁止各层自造别名。

## 20. 页面路由与组件命名

- 新增路由：`pages/discover/matching`、`pages/discover/match-success`、`pages/home/segment`、`subpackages/setup/interest`；删除 `pages/profile/saved`。
- 组件命名：`MatchActionButton / MatchHub / MatchingProgress / MatchSuccess / SegmentEntries / PersonRow / WhisperSheet / WhisperGroup / RelationshipCTA / GovernanceMenu / ProfileHero / CoreStats / MenuList / MyPosts / VoiceCollapse / CampusProfile`。

## 21. 验收红线

1. 发现与匹配职责不重叠（发现不出现“开始匹配”，匹配不出现聚合入口）。
2. 悄悄话不承诺“必达”；单向喜欢文案恒为“已送出心动”。
3. 他人主页 CTA 按状态机切换，关注不入首屏 CTA。
4. 我的主页动态 ≤3 条 + 语音折叠。
5. Hero 节奏：只有匹配中心/匹配成功/我的有渐变，发现/附近/消息白底。
6. 旧 v2 色值与 `saved/收藏` 入口残留 = 0。
