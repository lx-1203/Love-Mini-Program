# 恋爱小程序运营后台 · 设计令牌（Design Tokens）

> 来源：Meta 风格设计系统改造而来｜定位：Web 后台管理系统｜语言：中文
> 设计基调：**简洁、低视觉干扰、易用、操作路径短、导航清晰一致**
> 适用角色：运营后台（数据看板 / 用户管理 / 内容审核 / 活动配置）

---

## 1. Visual Theme（视觉主题）

**Philosophy**: 以信息密度与操作效率为先，用克制的色彩与统一的栅格降低认知负担。
**Direction**: `minimal · utilitarian · data-dense · low-chroma`
**Personality**: `calm · precise · trustworthy · neutral`
**Reference**: Meta Design System（cobalt 主色系）— 已去除营销化胶囊与圆角，收敛为后台友好形态。

> 关键约束：品牌主色 cobalt **仅用于「主操作」与「激活态」**，不用于页面装饰、背景渐变或营销氛围，避免运营后台被误读为 C 端活动页。

---

## 2. Color Palette（色彩角色映射）

> 所有色值取自 Meta 令牌并做后台角色重映射；语义色保留 Meta 原值，仅补充「浅底徽章」配色。

### 2.1 品牌主色（仅主操作 / 激活态）

| Token | HEX | 用途 |
|-------|-----|------|
| `--color-primary` | `#0064e0` | 主按钮、关键操作、导航激活文字、链接 |
| `--color-primary-hover` | `#0457cb` | 主按钮 hover / active |
| `--color-primary-soft` | `#e9f1fd` | 导航选中底、主色徽章底、聚焦浅环（主色 8% 白底） |
| `--color-on-primary` | `#ffffff` | 主按钮文字 |

### 2.2 语义色（状态 / 反馈）

| Token | HEX | 用途 |
|-------|-----|------|
| `--color-success` | `#31a24c` | 成功、通过、在线 |
| `--color-warning` | `#f2a918` | 警告、待处理、需注意 |
| `--color-danger` | `#e41e3f` | 危险、删除、封禁、失败 |
| `--color-success-soft` | `#e8f5ec` | 成功徽章底 |
| `--color-warning-soft` | `#fbf1dc` | 警告徽章底 |
| `--color-danger-soft` | `#fce8ec` | 危险徽章底 |

### 2.3 中性色（页面 / 卡片 / 文字 / 边框）

| Token | HEX | 用途 |
|-------|-----|------|
| `--color-canvas` | `#f1f4f7` | **页面整体背景**（surface-soft，低干扰浅灰） |
| `--color-surface` | `#ffffff` | **内容卡片 / 侧边栏底色** |
| `--color-sidebar` | `#ffffff` | 左侧固定侧边栏底色（右接 hairline 分隔） |
| `--color-border` | `#ced0d4` | 输入框描边、卡片边框 |
| `--color-border-soft` | `#dee3e9` | 表格行分隔、工具栏下边线、次级分隔 |
| `--color-text-primary` | `#1c1e21` | 标题、正文主文字（ink） |
| `--color-text-secondary` | `#5d6c7b` | 次级文字、表格副信息（steel） |
| `--color-text-tertiary` | `#8595a4` | 辅助文字、占位符、元信息、禁用态（stone） |
| `--color-disabled-text` | `#bcc0c4` | 禁用文字 |
| `--color-disabled-bg` | `#f1f4f7` | 禁用控件底色 |

**文字三级层次小结**：主 `#1c1e21` → 次 `#5d6c7b` → 辅助 `#8595a4`。

### 2.4 色彩使用纪律（后台专属）

- 主色 `#0064e0` 出现位置：**主按钮、激活导航项、文字链接、聚焦环**。其余一律中性灰。
- 页面背景统一为 `#f1f4f7`，内容卡为白；用「灰底托白卡」制造层级，而非阴影。
- 语义色只用于徽章 / 状态点 / 行内提示，禁止铺大色块背景。

## 3. Typography（字体排印）

### 3.1 字体族（中文优先回退链）

```css
--font-sans: "Noto Sans SC", "Source Han Sans SC", "PingFang SC",
             "Microsoft YaHei", "Hiragino Sans GB", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "SF Mono", "Roboto Mono", Menlo,
             Consolas, "Courier New", monospace;
```

- 正文 / 界面：**Noto Sans SC** 为首（开源、字重齐全、跨平台一致）；Mac 自动回退 PingFang SC，Windows 回退微软雅黑。
- 数字 / ID / 金额 / 代码：使用 `--font-mono`，保证列对齐与可读性。
- **字重规范**：400 常规（正文）、500 中等（按钮/徽章）、600 半粗（标题/表头）。避免 700+ 重字重，保持克制。

### 3.2 字号层级（后台紧凑基准 = 14px）

| Level | 字号 | 字重 | 行高 | 用途 |
|-------|------|------|------|------|
| 页面标题 H1 | 20px | 600 | 28px | 顶栏页面名、详情页标题 |
| 区块/卡片标题 H2 | 16px | 600 | 24px | 卡片标题、表单分组标题 |
| 子标题 H3 | 14px | 600 | 22px | 列表小标题、表格内分组 |
| 正文 Body | 14px | 400 | 22px | 默认正文、表格单元格 |
| 次级文字 | 13px | 400 | 20px | 说明文案、副标题 |
| 辅助/元信息 | 12px | 400 | 18px | 占位符、时间戳、脚注 |
| 徽章/标签 | 12px | 500 | 18px | 状态徽章、标签 |

> 后台基准字号取 **14px**（非 C 端 16px），在有限屏幅内提升信息密度；字号跨级严格 ≤6px 跳变，保持节奏稳定。

## 4. Spacing & Radius（间距与圆角）

### 4.1 间距步长（4px 基准，后台统一 8px 主步长，比营销更紧凑）

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-1` | 4px | 图标与文字内距 |
| `--space-2` | 8px | 控件内元素间距 |
| `--space-3` | 12px | 卡片内边距（小）、表单项间距 |
| `--space-4` | 16px | 卡片内边距（默认）、区块间距 |
| `--space-5` | 20px | 工具栏左右内边距 |
| `--space-6` | 24px | 内容区主内边距、卡片间距 |
| `--space-8` | 32px | 大区块间距 |
| `--space-10` | 40px | 页面级分组间距 |
| `--space-12` | 48px | 空状态 / 整页留白 |

### 4.2 圆角（后台收敛：6–10px，禁用营销胶囊）

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 4px | 状态徽章、标签、小元素 |
| `--radius-md` | 6px | **按钮、输入框、下拉** |
| `--radius-lg` | 8px | **内容卡片、表格容器、弹窗** |
| `--radius-xl` | 10px | 大卡片、图片容器 |
| `--radius-full` | 9999px | 头像、圆形状态点（仅此场景） |

> 改造说明：Meta 原模板的 100px 胶囊按钮、24–32px 大圆角卡片在后台改为 6–8px，降低「活泼感」、提升「工具感」。

## 5. Component Styles（组件规范）

### 5.1 侧边栏导航项（Sidebar Nav Item）

- 容器：宽 `220px`（可折叠至 `64px` 图标态），底白 `#fff`，右侧 `1px #dee3e9` 分隔。
- 单条目：**高度 40px**，左右内距 `12px / 16px`，圆角 `6px`，文字 `14px / 400 #5d6c7b`。
- **选中态**：底 `#e9f1fd`（primary-soft）+ 文字 `#0064e0` / 600 + 左侧 `3px #0064e0` 竖条（紧贴左缘）。
- 非选中 hover：底 `#f1f4f7`。
- 分组标题（如「运营／审核」）：`12px / 500 #8595a4`，上下间距 `16px / 8px`。

### 5.2 顶部工具栏（Top Toolbar）

- 高度 **56px**，底白 `#fff`，下边线 `1px #dee3e9`，左右内距 `0 24px`，`position: sticky; top: 0; z-index: 200`。
- 左侧：页面标题 `20px / 600 #1c1e21` + 可选面包屑 `13px #8595a4`。
- 右侧：操作区（主按钮 / 搜索 / 用户头像），项间距 `12px`。

### 5.3 按钮（Button）

| 变体 | 背景 | 文字 | 边框 | 高度 | 圆角 | Hover |
|------|------|------|------|------|------|-------|
| **主按钮** | `#0064e0` | `#ffffff` / 500 | 无 | 36px | 6px | `#0457cb` |
| **次按钮** | `#ffffff` | `#1c1e21` / 500 | `1px #ced0d4` | 36px | 6px | 底 `#f1f4f7` |
| **文字按钮** | 透明 | `#0064e0` / 500 | 无 | 36px | 6px | 底 `#f1f4f7` |

- 内距：`0 16px`；小号变体高度 `32px`、内距 `0 12px`。
- 禁用：主按钮底 `#bcc0c4`、文字 `#fff`；次按钮底 `#f1f4f7`、文字 `#bcc0c4`、边框 `#dee3e9`。
- 一屏内主按钮 **唯一**（每个操作区至多 1 个主按钮），其余用次/文字按钮。

### 5.4 输入框（Input / Select）

- 高度 **36px**（搜索框可用 32px），内距 `0 12px`，圆角 `6px`，边框 `1px #ced0d4`。
- 文字 `14px #1c1e21`；占位符 `#8595a4`。
- **聚焦**：边框 `#0064e0` + 外环 `0 0 0 3px rgba(0,100,224,0.15)`。
- 错误态：边框 `#e41e3f` + 外环 `rgba(228,30,63,0.12)`；下方 `12px #e41e3f` 提示文案。
- 多行文本域（Textarea）：高度自适应，最小 `80px`，行高 `22px`。

### 5.5 数据表格（Data Table）

- 容器：白底、圆角 `8px`、边框 `1px #dee3e9`、无外阴影。
- 表头行：高 `40px`，底 `#f1f4f7`，文字 `12px / 600 #5d6c7b`，下边线 `1px #dee3e9`。
- 数据行：**行高 44px**，单元格内距 `0 16px`，文字 `14px #1c1e21`，隔行底 `1px #f1f4f7`（斑马可省略，用 hover 代替）。
- 行 hover：底 `#f1f4f7`；选中行：底 `#e9f1fd`。
- 数字列（ID/金额/计数）使用 `--font-mono` 右对齐。
- 操作列：文字按钮（查看/编辑/禁用），危险操作用 `#e41e3f` 文字按钮。

### 5.6 状态徽章（Status Badge）

- 高度 `22px`，内距 `0 8px`，圆角 `4px`，文字 `12px / 500`，与文字垂直居中。
- 配色（文字 + 浅底）：

| 状态 | 文字 | 底 |
|------|------|-----|
| 成功 / 在线 | `#31a24c` | `#e8f5ec` |
| 警告 / 待处理 | `#a96f00` | `#fbf1dc` |
| 危险 / 封禁 | `#e41e3f` | `#fce8ec` |
| 信息 / 默认 | `#0064e0` | `#e9f1fd` |

- 圆形状态点（dot）：直径 `8px`，配色同语义色，用于列表行首。

### 5.7 卡片容器（Card）

- 背景 `#ffffff`，边框 `1px #dee3e9`，圆角 `8px`，**默认无阴影（flat）**。
- 内距：默认 `16px`，宽松 `20px`；卡片标题 `16px / 600 #1c1e21` + 右侧操作槽。
- 可点击卡片 hover：边框转 `#0064e0` 或极轻阴影 `0 1px 4px rgba(20,22,26,0.08)`（保留 Meta 轻阴影仅限此处）。
- 统计数字卡：大数字 `20px / 600 #1c1e21`，同比文案 `12px`（涨 `#31a24c` / 跌 `#e41e3f`）。

## 6. Depth & Elevation（深度与层级）

后台以「边框 + 灰底」分层，阴影克制使用。

| Level | 阴影 | 用途 |
|-------|------|------|
| Flat | none | 页面、卡片、表格（默认） |
| Raised | `0 1px 4px rgba(20,22,26,0.08)` | 可交互卡片 hover、悬浮工具条 |
| Floating | `0 4px 16px rgba(20,22,26,0.12)` | 下拉、弹出菜单、日期选择器 |
| Overlay | `0 8px 32px rgba(20,22,26,0.16)` | 模态框、抽屉 |

### Z-index Scale
- 页面基底 `0`｜侧边栏/工具栏（sticky）`200`｜下拉/弹出 `300`｜模态/抽屉 `400`｜Toast/全局提示 `500`｜引导蒙层 `600`。

## 7. Cautions（注意事项 / 反模式）

### Never Do
- 禁止把主色 `#0064e0` 用作页面背景、Banner 渐变或营销氛围块（主色 = 操作，不是装饰）。
- 禁止恢复 Meta 的 100px 胶囊按钮与 24–32px 大圆角卡片（后台要「工具感」，不要「活动感」）。
- 禁止一屏出现多个主按钮；禁止用语义色铺满整行/整卡背景。
- 禁止正文用 16px 以上大字号或 700+ 重字重，避免后台显得松散。
- 禁止用纯色块区分区块，统一用 `#f1f4f7` 灰底 + 白卡 + 1px 边框。

### Prefer
- 用「灰底托白卡 + 边框」而非阴影建立层级。
- 导航激活态用「浅蓝底 + 左竖条 + 主色字」三合一，确保一眼可定位。
- 高频操作放顶栏右侧与表格操作列，缩短操作路径。
- 数字/ID 统一 mono 字体右对齐，提升扫读效率。

## 8. Responsive Behavior（响应式行为）

| 断点 | 宽度 | 行为 |
|------|------|------|
| Desktop | ≥ 1280px | 侧边栏 220px 常驻 + 内容区自由展开 |
| Laptop | 1024–1279px | 侧边栏 220px，内容内边距收至 20px |
| Tablet | 768–1023px | 侧边栏折叠为 64px 图标态（hover 展开）或抽屉；表格可横向滚动 |
| Mobile | < 768px | 侧边栏隐藏 → 顶栏汉堡唤出抽屉；内容全宽；表格横向滚动；按钮堆叠 |

### 适配规则
- 侧边栏在 <1024px 收为图标态，<768px 改为 off-canvas 抽屉（z-index 400，带半透明遮罩）。
- 内容主区内边距：≥1024px 用 `24px`，<1024px 用 `16px`。
- 数据表格在窄屏允许横向滚动，禁止强行压缩列宽导致文字截断（用省略号 + tooltip）。
- 顶栏在移动端将标题左移、操作收进「更多」菜单。

## 9. Agent Prompt Guide（原型构建师落地指南）

### Key Instructions
- 严格按本令牌取色：**主色只用于主按钮/激活态/链接/聚焦环**，其余中性灰。
- 所有圆角从 `--radius-*` 取值（按钮/输入 6px，卡片 8px），不得自造 100px 胶囊。

## 10. Admin Workflow Components（后台专属复合组件）

> 依据功能模块清单扩展：12 一级 / 75 二级；高频交互 — 审核流 11 处、批量操作 18 处、图表看板 16 处、快捷入口 6 处。以下复合组件全部复用前文令牌，供原型构建师直接落地。

### 10.1 多级侧边导航框架（Multi-level Sidebar）
- 一级分组：12 个（数据概览/用户管理/内容管理/内容审核/匹配推荐/直播语音/商业化会员/运营活动/风控举报/客服工单/消息推送/系统设置）。
- 分组标题：`12px / 500 #8595a4`，上间距 16px、下 8px，当前展开组标题转 `#5d6c7b`。
- 二级菜单项：高 40px，左侧缩进 28px，文字 `14px / 400 #5d6c7b`；图标态折叠时隐藏文字，hover 展开浮层。
- **选中态三合一**（与 5.1 一致）：浅蓝底 `#e9f1fd` + 左 3px `#0064e0` 竖条 + 文字 `#0064e0 / 600`。
- 底部固定：角色切换 / 用户入口，独立于菜单，上方 `1px #dee3e9` 分隔。

### 10.2 筛选栏（Filter Bar）
- 位置：内容区顶部、卡片之上；与画布同宽，下边距 16px。
- 控件横向排布，项间距 12px；搜索框宽 240px，下拉/日期选择器宽 160–200px，均高 36px（与按钮同高对齐）。
- 右侧操作：「查询 / 重置」用次按钮 + 主操作（如「新建」）用主按钮。
- 筛选项 >5 个时，多余收进「更多筛选」弹层。

### 10.3 详情抽屉（Detail Drawer）
- 右侧滑出，宽 480px（默认）/ 720px（宽表单）；`z-index: 400`，遮罩 `rgba(10,19,23,0.45)`。
- 白底、左 `1px #dee3e9`、贴右缘无圆角；头部标题 `16px / 600` + 关闭文字按钮，内距 `20px 24px`。
- 内容：分区小标题 `16px / 600` + 键值对（标签 `13px #8595a4` / 值 `14px #1c1e21`），行距 12px。
- 底部操作条 sticky：白底 + 上 `1px #dee3e9`，右侧主/次按钮。

### 10.4 审核工作台（Audit Workbench）— 11 处复用

## 11. RBAC 可见性（角色差异 + 管理员等级圈层）

### 11.1 功能角色差异（Role-based）
角色：运营 / 审核员 / 客服 / 风控 / 管理员。设计系统以「令牌 + 组件开关」表达可见性，**不新增配色**：
- 导航/按钮的 `visible-by-role` 属性决定渲染；不可见模块直接不占导航位（非置灰展示）。
- 危险操作（封禁 / 删除 / 改配置）仅管理员 / 风控可见，按钮统一 danger 文字按钮 `#e41e3f`。
- 视角示例：审核员隐藏「系统设置」「商业化会员」；客服仅见「客服工单」「消息推送」「用户管理（只读）」。
- 同一组件按角色仅差异「是否可见 / 是否可编辑」，样式保持一致，保证全角色体验统一。

### 11.2 管理员等级 · 三级管理圈层（Admin-grade Hierarchy）★新增
管理员分三级圈层：**上层可下钻查看下层**，权力等级越大可见范围越广；各级均可查看其管辖范围内用户产生的内容，便于举报审核直接调阅取证。

| 等级 | 圈层 | 管辖范围 | 可见用户内容（聊天 / 图片 / 帖子 / 临时聊天） |
|------|------|---------|----------------------------------------|
| L1 | 公司管理级（我们公司） | 全平台：全部区域 / 全部学校 / 全部用户 | 全量（可下钻查看 L2、L3） |
| L2 | 区域管理（按区域，如华北 / 华东 / 华南） | 本区域：全部学校 / 用户 | 本区域全量（可下钻查看 L3） |
| L3 | 学校管理（各大高校各派管理员） | 本校：仅本校用户 | 本校全量（不可越级） |

**视觉表达（系统设置页「管理员等级」卡，见 Frame 08）：**
- 三道逐级缩进的色阶层（cobalt 由深到浅 `#0064e0 → #5b99ef → #c7def7`），直观呈现「包含关系」；
- 上层色深 = 权限高，配合缩进形成明显「圈层」分隔；
- 下方「管辖内容可见性」对照表：行 = 三级、列 = 聊天内容 / 上传图片 / 帖子 / 临时聊天，勾选（`#31a24c`）标注可见范围（全量 / 本区域 / 本校）；
- 说明注：上层默认可下钻查看其下级圈层内用户产生的全部内容，举报处理时可直接调阅。

> 圈层（管理员等级）与功能角色**正交**：任一功能角色（运营 / 审核 / 客服 / 风控）均可绑定到某一级管理员（如「华东区域·审核员」）。圈层决定**数据域（能看到谁）**，角色决定**操作权限（能做什么）**，二者叠加生效。

### 13.8 欺诈风险图谱（9.4）
- 关系图谱：力导向图（节点=设备/账号/资金，边=同设备/同资金网络）；节点主色 `#0064e0`、高风险 `#e41e3f`、普通 `#5d6c7b`；边 `#dee3e9`，强关联 `#f2a918`。
- 风险评分仪表：半圆仪表（0–100），分区 `#31a24c`(低)/`#f2a918`(中)/`#e41e3f`(高)，数字 `28px/600` 居中。
- 画布工具：缩放/拖拽（光标 `grab`），选中节点高亮关联子图 `#e9f1fd` 蒙版。

### 13.9 在线客服 IM 会话窗（10.2）
- 三栏：左会话列表（宽 280px，项高 56px，未读红点 `#e41e3f` 8px）/ 中对话流（fill，气泡：用户 `#f1f4f7`、客服白底+`1px #dee3e9`、圆角 8px）/ 右用户卡（宽 280px，复用 13.2 资料结构）。

- 话术快捷插入：输入框上方话术标签组（`12px/500` 胶囊，点按插入文本）。

### 13.10 Push 推送 A/B（11.1）
- 受众分群预览：左分群条件（复用 10.2 筛选栏）+ 右预估人数（大数字 `28px/600`，`12px #8595a4` 占比）。
- A/B 分桶：可设 2–3 组（文案/时间差异），每组一行卡片（白底、`1px #dee3e9`、圆角 8px），组头 `#0064e0/600`。
- 发送方式：定时（日期选择器）/ 即时（主按钮）；发送前二次确认弹窗。

### 13.11 RBAC 权限矩阵（12.1）— 10.1 权限树矩阵变体
- 左：菜单/功能树（复用多级结构，项高 36px，复选框 `18px`、方角圆角 4px、选中 `#0064e0`）。
- 右：数据域矩阵（行=角色 运营/审核/客服/风控/管理员，列=数据域 全部/本组/本人），单元格复选框。
- 顶部：角色 Tab 切换（高 44px，选中下划线 `#0064e0`）；保存主按钮 + 「应用至子项」次按钮。
- 危险域（如「系统设置」「删除权限」）勾选时弹确认。
- 管理员等级（数据域的「圈层」维度）另见 **11.2 三级管理圈层（公司 / 区域 / 学校）**：圈层决定「能看到谁的数据」，功能角色决定「能做什么操作」，二者正交、可叠加（如「华东区域 · 审核员」）。
