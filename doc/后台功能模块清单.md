## 设计落地对应（画布）

- **Frame 00** 统一布局骨架与组件库（侧边栏 220px + 顶栏 56px + 内容主区）
- **Frame 01** 功能模块全景覆盖图（本清单的可视化）
- **Frame 02** 数据概览 Dashboard
- **Frame 03** 用户管理（列表 + 筛选 + 批量条）
- **Frame 04** 用户详情抽屉
- **Frame 05** 内容审核工作台（三栏）
- **Frame 06** 内容管理
- **Frame 07** 匹配推荐与直播语音
- **Frame 08** 商业化与会员
- **Frame 09** 运营活动与消息推送
- **Frame 10** 风控与举报
- **Frame 11** 客服工单
- **Frame 12** 系统设置 / RBAC

复杂页面统一采用模块化分区 + 说明性文案；高频操作置于顶栏右侧与表格操作列；常用功能触达路径最短。
