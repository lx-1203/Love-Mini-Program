# 寻觅「登录页」SVG Path 组件包

基于用户提供的登录页视觉参考，拆分为独立、可维护的 SVG Path 组件。

## 组件清单
基础导航：返回、更多、右箭头  
品牌/主题：小芽、飘落叶子  
登录交互：微信、已选、未选  
状态/系统：信号、Wi‑Fi、电池  
安全功能：锁定、填充锁、隐私、安全盾牌  
用户：用户头像轮廓

## 工程规则
- SVG 独立文件，不嵌入任何位图。
- Vue 组件内部直接渲染 Path/基础 SVG 几何。
- 默认 24px，建议 24 / 32 / 48px 三档。
- 中性线性图标使用 `currentColor`；品牌色图标保留参考图颜色。
- 登录页主插画、人物照片/插画不强行转为 Path，应该作为 WebP/PNG 独立图片资源。
