# 寻觅吉祥物素材库 - 使用指南

## 概述
吉祥物"寻觅芽"是小程序的品牌IP形象，用于增强产品亲和力和情感化设计。
所有素材均为 PNG 透明背景 + SVG 矢量格式，可直接在小程序中使用。

## 素材目录

### V2 正式版（推荐使用）
路径: `素材/吉祥物/xunmi_mascot_design_system_v2/`

| 目录 | 分类 | 数量 | 说明 |
|------|------|------|------|
| 01-mascot | 主吉祥物 | 9 | 默认/微笑/开心/眨眼/思考/惊讶/流泪/生气/困倦 |
| 02-expression | 互动表情 | 15 | 平静/加油/鼓掌/心动/哭泣/打招呼/爱心/拥抱/跳跃/派对/害羞/睡觉/喜欢/微笑/挥手 |
| 03-state | 业务状态 | 4 | 忙碌/心动/离线/在线 |
| 04-chat | 聊天气泡 | 6 | 你好/好的/在吗/太棒了/晚安/收到 |
| 05-nav | 导航头像 | 5 | 首页/匹配/消息/附近/我的 |
| 06-avatar | 头像组件 | 5 | 默认/开心/戴眼镜/心动/困倦 |

- `name.master.png` — 原始尺寸

- `png/name@{16,24,32,48,72,128,256}.png` — 多尺寸PNG

## 小程序中的使用方式

### 1. XunmiMascot 组件（推荐）

```vue
<script setup>
import XunmiMascot from '@/components/common/XunmiMascot.vue';
</script>

<!-- 基础用法：后向兼容旧 mood 名 -->
<XunmiMascot mood="default" size="lg" />
<XunmiMascot mood="happy" size="md" animated />
<XunmiMascot mood="sad" size="xl" />

<!-- V2 全表情体系 -->
<XunmiMascot mood="mascot_smile" size="lg" />
<XunmiMascot mood="mascot_wink" size="md" animated />

<!-- 互动表情 -->
<XunmiMascot mood="mascot_wave" size="lg" />
<XunmiMascot mood="mascot_heart" size="md" />
<XunmiMascot mood="mascot_cheer" size="lg" animated />

<!-- 聊天气泡 -->
<XunmiMascot mood="chat_hi" size="sm" />
<XunmiMascot mood="chat_good" size="sm" />

<!-- 导航小头像 -->
<XunmiMascot mood="nav_home_mascot" size="sm" mini />
<XunmiMascot mood="nav_match_mascot" size="sm" mini />

<!-- 装饰元素 -->
<XunmiMascot mood="sparkle" size="xs" />
<XunmiMascot mood="heart_pink" size="sm" />
<XunmiMascot mood="star" size="xs" />

<!-- 状态标识 -->
<XunmiMascot mood="status_online" size="xs" />
<XunmiMascot mood="status_busy" size="xs" />
```

### 2. 尺寸规格

| 尺寸 | 普通模式 | 迷你模式 | 适用场景 |
|------|----------|----------|----------|
| xs | 64rpx (32px) | 48rpx (24px) | 状态指示、装饰小元素 |
| sm | 80rpx (40px) | 56rpx (28px) | 导航头像、聊天气泡、标签 |
| md | 160rpx (80px) | 80rpx (40px) | 卡片内吉祥物、按钮图标 |
| lg | 240rpx (120px) | 120rpx (60px) | 空状态、引导页、弹窗 |
| xl | 400rpx (200px) | 160rpx (80px) | 启动页、全屏引导 |

### 3. 场景使用建议

| 页面/场景 | 推荐吉祥物 | 说明 |
|-----------|-----------|------|
| 启动页/引导页 | mascot_default + animated | 品牌形象展示 |
| 空状态（无数据） | mascot_sad / mascot_cry | 引导用户操作 |
| 匹配成功 | mascot_love / mascot_heart | 喜庆氛围 |
| 消息气泡 | chat_hi / chat_good | 对话亲切感 |
| TabBar 导航 | nav_*_mascot (mini) | 底部导航头像 |
| 个人主页头像 | head_default / head_happy | 用户头像框 |
| 点赞/收藏 | heart_pink / sparkle | 动效反馈 |
| 错误/警告 | mascot_surprised / exclamation | 提示用户 |
| 空闲等待 | mascot_sleepy / mascot_sleep | 陪伴感 |
| 帖子/动态 | 星星/花/五彩纸屑 | 装饰点缀 |
| 搜索/相机场景 | mascot_search / mascot_camera | 功能引导 |
| 在线状态 | status_online | 绿色圆点标识 |

### 4. CSS 背景方式

```css
.mascot-bg {
  width: 80px;
  height: 80px;
  background: url('/static/assets/images/mascot/mascot_smile.png') center / contain no-repeat;
}

/* 或使用 SVG（推荐，更清晰） */
.mascot-svg {
  background: url('/static/assets/images/mascot/mascot_smile.svg') center / contain no-repeat;
}
```

### 5. 动效使用

组件内置呼吸动效（`animated` prop），也可自定义：

```vue
<XunmiMascot mood="mascot_love" size="lg" animated class="custom-anim" />
```

```css
.custom-anim {
  animation: mascot-jump 0.6s ease-in-out;
}
@keyframes mascot-jump {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}
```
