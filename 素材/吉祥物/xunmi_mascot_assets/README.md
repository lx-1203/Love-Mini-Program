# 寻觅吉祥物资产包 V1

来源：用户提供的吉祥物总览图。
本包将图中可复用的吉祥物、状态、气泡、装饰、导航小头像等拆分为独立 PNG 与 SVG 文件。

## 文件结构
- mascot_base/        基础表情
- interaction/        互动动作
- emotion/            情绪状态
- scene_function/     场景功能
- chat_bubbles/       聊天气泡
- status/             在线/忙碌/离线/心动状态
- decor/              心形、星光、问号等装饰
- nav/                底部导航小吉祥物
- head_icons/         头像/小头像系列
- utility/            其他辅助元素

## 使用方式
- PNG：直接作为微信小程序 image / CSS background-image 使用。
- SVG：本包中的 SVG 是“透明 PNG 封装型 SVG”，适合直接作为静态资源使用。
- 真正 path 级 SVG：建议后续以高分辨率透明母图为源进行人工矢量化；当前包没有伪造为 path SVG。

## 设计基准
- 主绿：#34C38F
- 浅绿：#E8FBF2
- 心动粉：#FF8DA8
- 高光黄：#FFECA4
- 透明背景
- 资产默认保留适量安全留白，便于小程序布局。

## 重要说明
由于源文件本身是一张带渐变背景的 AI 生成总览图，本次拆分属于“基于源图的可用素材裁切 + 背景分离”，并非原始矢量工程文件恢复。
因此：
1. 视觉结构会尽量保持源图一致；
2. 极细边缘、发光、阴影可能存在轻微色差；
3. SVG 文件是 PNG 封装，不是 path 级矢量；
4. 需要生产级 path SVG 时，应以透明高清母图逐个矢量化。

共拆分 67 个独立资产。
