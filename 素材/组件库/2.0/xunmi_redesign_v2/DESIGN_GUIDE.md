# 寻觅 A+B Fusion v2

## 一、为什么当前页面总不像参考图
当前实现的核心问题不是某个按钮，而是视觉层级和产品叙事没有统一：
1. 首屏信息过多：签到、功能入口、Banner、活动、社交进度同时争夺注意力。
2. 人不是第一主角：人物照片/头像、名字、共同点、心动动作没有形成连续阅读路径。
3. 卡片太多且高度/圆角/阴影不统一，页面像“功能集合”而不是一个产品。
4. 颜色职责混乱。应固定为：绿色=发现/校园，粉色=心动/喜欢，紫色=兴趣，蓝色=消息。
5. 图标风格混用：emoji、线性、实心、系统图标同时出现。
6. 文案偏工具型，例如“社交升温进度”，恋爱氛围弱。
7. 他人主页像相亲资料表，收入/职业/身高抢了第一视觉，缺少“为什么值得认识”。
8. 我的主页是资料堆叠，没有“我的恋爱名片”这个中心任务。
9. 兴趣圈独立存在会让产品像论坛；它应该属于“附近”的内容生态。
10. 参考图的关键是“大人物 + 少量高权重动作 + 大留白”，而当前实现是“很多小卡片 + 很多文字”。

## 二、视觉系统
- 背景 #F7F9F8
- 品牌绿 #34C98F
- 深绿 #159C6C
- 心动粉 #F35C9D
- 兴趣紫 #9A7BEE
- 消息蓝 #4D8DFF
- 主文字 #20242A
- 次文字 #7A838D
- 卡片 #FFFFFF
- 页面左右边距 18px
- 普通圆角 16~18px；Hero 24px
- 卡片间距 12~16px
- 标题 20~28px / 700
- 正文 12~14px / 400~500
- 不要大面积使用渐变；渐变只用于个人主页/品牌 Hero。
- 一个页面只保留一个主 CTA。

## 三、首页
目标：第一眼看到“值得认识的人”。
结构：问候 -> 搜索 -> 小签到 -> 今日心动推荐 -> 校园里的心动。
推荐卡阅读顺序：照片 -> 名字/年龄 -> 学校/距离 -> 一句话 -> 兴趣 -> 匹配度 -> 喜欢。
签到成功只改变状态，不弹全屏弹窗。
点击推荐卡进入他人主页；点击兴趣圈进入附近的兴趣圈 tab。

## 四、附近
底部入口只叫“附近”，内部四个 tab：附近的人 / 兴趣圈 / 校园 / 活动。
附近的人：主卡一次只突出一个人，动作只保留喜欢、收藏/稍后看、跳过。
兴趣圈：圈子简介、成员、在线人数、共同兴趣、热门帖子、加入。
校园：学校列表和校园流。
活动：活动卡和报名。

## 五、兴趣圈
兴趣圈不是论坛，而是“认识人的破冰入口”。
帖子结构：头像/昵称/学校/年龄 -> 正文 -> 话题 -> 互动 -> “认识 TA”。
“认识 TA”点击后记录兴趣；如果双方都喜欢则形成匹配并进入消息。
发帖按钮叫“分享一下今天”，流程：内容 -> 图片 -> 话题 -> 位置 -> 可见范围 -> 发布。

## 六、我的主页
中心任务是“打造自己的恋爱名片”。
第一屏：头像、昵称、年龄、学校、个人一句话、兴趣、编辑按钮。
第二层：心动值/被喜欢/匹配等关系数据。
第三层：用户自由控制模块显示/隐藏，可后续加入拖动排序。
可控模块：简介、照片墙、兴趣、动态、圈子、学校、心动值。

## 七、他人主页
第一视觉必须是“这个人”。顺序：照片 -> 名字/年龄 -> 学校/距离/在线 -> 一句话 -> 你们的共同点 -> TA的动态 -> 兴趣 -> 更多资料折叠 -> 固定底部“喜欢 TA / 聊天”。
点击共同兴趣进入兴趣圈；点击动态进入动态详情。
喜欢：未互相喜欢则显示“已发送心动”；互相喜欢则“匹配成功”并进入聊天。
不要把收入、职业、身高等放在第一屏。

## 八、消息
顶部两个轻量入口：匿名匹配聊天、喜欢与访客。
下面使用轻量列表：头像 + 两行文字 + 时间 + 未读。
排序：新匹配 -> 未读 -> 最近聊天 -> 官方消息。
不要做成大块卡片堆叠。

## 九、底部导航
发现 / 附近 / 匹配 / 消息 / 我的。
发现=推荐人和校园入口；附近=附近的人+兴趣圈+校园+活动；匹配=核心心动动作；消息=聊天；我的=恋爱名片。

## 十、微信小程序实现
SVG只做固定视觉元素；头像、昵称、学校、兴趣、匹配度等全部用 WXML 数据绑定。
推荐组件：x-bottom-nav、x-profile-hero、x-person-card、x-interest-tag、x-common-points、x-circle-card、x-post-card、x-action-button、x-heart-value。
页面：home、nearby、circle、messages、my、profile-detail。

## 十一、验收标准
1. 第一眼能看到“人”。
2. 一个页面只有一个主 CTA。
3. 3 秒内理解当前页面目的。
4. 绿色和粉色承担固定语义。
5. 不出现无意义功能卡片堆叠。
6. 他人主页先看到共同点，不先看到收入/职业。
7. 兴趣圈真的能帮助认识人。
8. 喜欢 -> 匹配 -> 聊天形成连续闭环。
9. 我的主页可以自由控制展示内容。
