# 寻觅 v3｜重排后的 SVG 设计拆分

本包对应当前确认的结构：

**首页 → 匹配中心**
- 首页首屏职责改为匹配中心
- 保留在线速配、关系进度、普通匹配、在线速配、匹配流程
- 底部 Tab「首页」激活

**匹配 → 寻觅**
- 「匹配」Tab 改为参考你提供的 Blast / Nearby 风格的沉浸式寻觅页面
- 主卡为大图人物卡
- X = 跳过
- ☆ = 悄悄话
- ♥ = 喜欢
- 下方继续浏览更多推荐
- 所有图片区域均为独立图片槽位，方便正常上传真实头像/生活照

**我的 → 个人主页**
- 保持之前 v3 个人主页结构，不继续改动

**头像框**
- 独立于照片层
- 正常上传任何比例照片后，通过 1:1 cover + 圆形裁切保持视觉稳定
- 状态点、认证标识、心动边框作为 overlay，不压住主体脸部
