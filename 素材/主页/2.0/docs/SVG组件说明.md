
# Profile SVG组件系统说明

## 1. profile-hero.svg

用途：
主页顶部视觉区域。

包含：
- 背景人物区域
- 头像浮层
- 用户身份

使用：
作为 Profile 页面第一屏。

动态数据：
cover、avatar、nickname、verify、online。


## 2. profile-card.svg

用途：
个人介绍卡。

展示：
- 一句话介绍
- 用户人格描述。


## 3. profile-interest.svg

用途：
兴趣标签模块。

功能：
展示共同兴趣，提高聊天转化。


## 4. profile-action.svg

用途：
底部互动按钮。

他人主页：
喜欢、聊天、心动卡。

自己主页：
编辑、分享。


## 5. profile-gallery.svg

用途：
生活故事照片。

注意：
不是普通相册，而是生活证明。


## 6. profile-bottom-nav.svg

用途：
全局导航。

固定：
首页 / 附近 / 寻觅 / 消息 / 我的。
