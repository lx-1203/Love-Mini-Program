# 寻觅｜匹配页完整设计与 SVG 使用规范

## 1. 本次确定的页面
本版删除“个人视频”功能；匹配流程只围绕：发现 → 喜欢/超级喜欢/跳过 → 匹配成功 → 消息。

匹配页采用“沉浸式全屏卡片”：
- 大图占主要视觉区域
- 左上：距离
- 右上：在线状态
- 底部渐变：姓名、年龄、认证、学校、年级、标签、简介、匹配度
- 右侧竖向操作：喜欢 / 超级喜欢 / 跳过
- 底部使用新的 5 Tab：发现 / 附近 / 匹配 / 消息 / 我的
- 中间“匹配”是品牌核心入口，使用绿色圆形浮岛，图标为白色爱心

## 2. 删除内容
删除：
- 个人视频
- 匹配页视频卡片
- 个人主页“个人视频”区
- 与视频相关的入口和文案

保留：
- 用户照片
- 学校/年级
- 距离
- 在线状态
- 认证
- 兴趣标签
- 自我介绍
- 匹配率
- 附近
- 搜索/筛选
- 喜欢/超级喜欢/跳过
- 匹配成功
- 消息

## 3. 颜色 Token
--brand: #34C38F;
--brand-dark: #269B70;
--brand-light: #E9FBF3;
--pink: #FF5D9E;
--pink-light: #FFF0F7;
--blue: #4D8DFF;
--page: #F7FAF9;
--text: #222222;
--subtext: #7A7A7A;
--line: #EEF2F1;

语义：
绿色 = 品牌 / 在线 / 匹配
粉色 = 喜欢 / 心动
蓝色 = 超级喜欢
灰色 = 跳过 / 次要操作

## 4. 新底部导航
固定五项：
1. 发现
2. 附近
3. 匹配（中心主入口）
4. 消息
5. 我的

不要再使用原来的“发现 / 圈子 / 首页 / 消息 / 我的”。
原因：匹配产品的核心路径应该直接把“匹配”放到导航中心，而不是把“首页”作为业务核心。

中心匹配按钮：
- 56~64rpx 视觉尺寸
- 绿色 #34C38F
- 白色爱心
- 轻微阴影
- 标签文字“匹配”使用品牌绿

## 5. 微信小程序使用

目录建议：
/assets/icons/
/assets/components/

WXML：
<image class="icon" src="/assets/icons/match-heart.svg" mode="aspectFit" />

WXSS：
.icon {
  width: 44rpx;
  height: 44rpx;
}

SVG 使用 currentColor 的图标，可以用外层 color 控制颜色；如果微信环境对 currentColor 兼容处理不理想，直接复制 SVG 并把 currentColor 替换成固定颜色。

## 7. 匹配卡片布局
建议以 343×610 设计稿比例为基准，再用 rpx 自适应。
照片区域建议 ≥ 70%。
底部渐变只用于提高文字可读性，不要把文字放到单独的白色资料卡里。
信息顺序：
姓名 + 年龄 → 在线/认证 → 学校/年级/距离 → 兴趣标签 → 一句话介绍 → 匹配度。

## 8. 交互
右侧：
- ❤️ 喜欢
- ☆ 超级喜欢
- × 跳过

底部中心匹配 Tab 点击进入匹配流。
喜欢后若对方也喜欢：进入“匹配成功”页。
匹配成功页只提供两个 CTA：
- 去打个招呼
- 继续探索

## 9. 注意
不要把整张页面做成一个 SVG。
SVG 应作为图标和可复用视觉组件；人物照片、用户信息、标签、匹配率等必须由微信小程序 WXML 动态渲染。
