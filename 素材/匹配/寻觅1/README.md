# 寻觅匹配系统 SVG 素材规范

## 颜色
主色：#35C99A
恋爱情绪色：#FF6B9D
强调色：#FFC857
背景：#F4FBF8

## 使用规范
- SVG统一 viewBox 64x64 或 100x100
- 图标禁止直接修改颜色，使用主题变量替换
- 按钮尺寸：
  - 小按钮 40px
  - 主操作按钮 64px
- 圆角：
  - 卡片 24px
  - 浮层 16px

## 文件说明
icon-like：喜欢
icon-pass：跳过
icon-super-like：超级喜欢
icon-match-heart：匹配成功
icon-chat：聊天入口
icon-send：发送消息
loading-ring：匹配动画
