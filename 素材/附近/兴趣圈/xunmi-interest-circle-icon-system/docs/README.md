# 寻觅「兴趣圈」Icon Path System

## 资产范围
- 导航：返回、搜索、更多/菜单
- 底部 Tab：首页、附近、匹配、消息、我的
- 兴趣分类：摄影、旅行、音乐、运动、美食、更多
- 操作：加入/添加、创建圈子、查看更多
- 系统/装饰：星球装饰、Wi‑Fi、信号、电池、时间框架

## 规范
- 统一 `viewBox="0 0 24 24"`
- SVG 只使用 `<path>`，不依赖 `<circle>/<rect>/<line>`，方便后续 Figma/Illustrator/SVG 编辑。
- 默认 `currentColor`，组件可通过 CSS `color` 或 `strokeWidth` 控制。
- 推荐尺寸：16 / 20 / 24 / 32 / 48 px。
- 主色：#00B86B；深色：#1A1A1A；辅助灰：#667085。

## 重要说明
这些 SVG 是依据你提供的界面视觉进行“路径级重建”，不是从 PNG 自动追踪得到的原始矢量路径。
因此可以直接用于开发、Figma 导入和 PNG 导出，但不能声称与原图像素级 100% 相同。
如果需要“逐像素/逐路径”还原，需要以原始 SVG/Figma/Icon Font 源文件为基准，而不是从截图反推。
