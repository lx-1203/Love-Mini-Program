## 一、总体结论

### 现有 SVG 素材覆盖率：约 75%

**已有的 SVG 素材（118 + 70 = 188 个）非常丰富，覆盖了大部分图标需求。** 但对照 15 张理想效果图逐页核查后，仍存在以下缺口：

| 类别 | 已有数量 | 缺失/待补充 | 覆盖率 |
|------|---------|------------|--------|
| TabBar 图标 | 5 | 0 | 100% |
| 功能图标 | 30 | 6 个需新增 | 83% |
| 头像相关 | 8 | 1 个需优化 | 88% |
| 标签组件 | 12 | 1 个需新增 | 92% |
| 卡片模板 | 6 | 2 个需新增 | 67% |
| 进度组件 | 5 | 1 个需新增 | 80% |
| 吉祥物 | 8（主库）+ 70+（扩展） | 1 个消息页专用 | 95% |
| 装饰元素 | 12 | 3 个需新增 | 75% |
| 空状态 | 5 | 1 个需新增 | 80% |
| Logo | 3 | 0 | 100% |
| 聊天元素 | 6 | 2 个需新增 | 67% |
| 登录相关 | 5 | 0 | 100% |
| 页面模板 | 3 | 0 | 100% |
| **校园圈封面插画** | 0 | **需新增 5-8 张** | **0%** |
| **登录页背景插画** | 1（框架） | **需完整插画** | **20%** |
| **人物头像照片** | 0 | **需位图，非 SVG** | **N/A** |

### 核心发现

1. **✅ 图标类素材基本齐全**：118 个标准 SVG + 70+ 吉祥物 SVG，功能图标、标签、按钮、头像框等都有。
2. **🔴 校园圈封面图完全缺失**：理想图中每个圈子有独特的校园风景封面（清华校门/未名湖等），当前 SVG 库中没有对应插画。
3. **🔴 登录页背景插画不完整**：只有 `login-illustration-frame.svg`（框架），没有完整的校园情侣场景插画。
4. **🔴 匹配进度图标缺失**：匹配中页的 4 项匹配度（旅行/音乐/电影/生活）左侧彩色图标，当前 SVG 库中没有对应风格的图标。
5. **⚠️ 部分图标风格不统一**：项目中同时存在 v2 PNG 图标、emoji SVG、common SVG 三套体系，与理想效果图的线框风格不完全一致。
6. **⚠️ 吉祥物形象不统一**：理想图消息页中是可爱萌芽吉祥物，实际代码中使用的是另一套形象。

## 四、项目代码中图标使用问题

### 4.1 图标体系混乱

当前项目 `images.ts` 中同时存在多套图标体系：

| 体系 | 位置 | 格式 | 数量 | 风格 |
|------|------|------|------|------|
| svg-spec（理想图源） | `static/assets/svg-spec/` | SVG | 118 | 统一线框风 |
| v2（freesvglab） | `static/assets/icons/v2/` | PNG+SVG混合 | 20+ | 扁平填充风 |
| common（lucide） | `static/assets/icons/common/` | SVG+PNG混合 | 50+ | lucide 线框风 |
| social（社交） | `static/assets/icons/social/` | SVG | 12 | 线框风 |
| home icons | `static/assets/home/icons/` | SVG | 9 | 风格不一 |
| message svg | `static/assets/message/svg/` | SVG | 15+ | 风格不一 |
| emoji 替换 | `ICONS_EMOJI` 配置 | SVG+PNG | 40+ | 混杂 |

**问题**：
1. 多套图标风格不统一，导致页面视觉杂乱
2. PNG 图标不支持 currentColor 主题色切换
3. 同名图标存在多个版本（如 heart 有至少 5 个不同文件）

**建议**：
- 统一以 `svg-spec`（理想效果图-svg拆分）为标准图标源
- 逐步替换 PNG 图标为 SVG 版本
- 清理重复和风格不一致的图标

### 4.2 TabBar 图标问题

`ICONS_TABBAR` 当前使用的是 PNG 格式，而 `svg-spec/01-tabbar/` 中已经有 5 个 SVG 版本。

**建议**：切换到 SVG 版本，支持 currentColor 控制选中/默认态颜色。

## 五、素材获取渠道与建议

### 5.1 iconfont.cn（阿里巴巴矢量图标库）
- **优势**：中文搜索、海量图标、支持 SVG 下载、可自定义颜色
- **推荐搜索关键词**：
  - 校园插画：`校园 插画`、`大学 风景`、`青春校园`
  - 匹配图标：`旅行 图标`、`音乐 图标`、`电影 图标`、`生活方式 图标`
  - 功能入口：`功能图标 彩色`、`APP 图标 圆角`
  - 毕业帽：`毕业帽`、`学士帽`、`graduation cap`

### 5.2 freesvglab.com
- **优势**：免费 SVG、高质量、风格统一
- **推荐搜索方向**：
  - 插画类：`illustration`、`campus`、`couple`、`love`
  - 图标类：`travel`、`music`、`film`、`lifestyle`
  - 装饰类：`sparkle`、`heart`、`decoration`

### 5.3 自制/组合方案

对于找不到完全匹配的素材，可以：

1. **基于现有 SVG 修改**：
   - 用现有图标改色、改尺寸
   - 组合多个简单元素成新图标

2. **用 CSS 实现**：
   - 进度条、圆角按钮、标签胶囊 → 纯 CSS
   - 头像环、状态点 → CSS border + 伪元素
   - 涟漪动画 → CSS animation + box-shadow

3. **渐变 + 几何图形组合**：
   - 校园圈封面：渐变背景 + 简笔建筑图形
   - 功能入口图标：圆形渐变背景 + 简单线稿图标
