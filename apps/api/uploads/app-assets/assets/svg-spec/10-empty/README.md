# 10 Empty 空状态插画

各种空状态场景的吉祥物插画，约 200x200 尺寸。

## 文件列表

| 文件名 | 说明 | 使用场景 |
|--------|------|----------|
| empty-story.svg | 吉祥物+空相框 | 动态/故事为空 |
| empty-gallery.svg | 吉祥物+相机 | 相册/照片为空 |
| empty-feed.svg | 吉祥物+聊天气泡 | 动态列表为空 |
| empty-match.svg | 吉祥物+大爱心（爱心眼） | 暂无匹配 |
| empty-search.svg | 吉祥物+放大镜 | 搜索无结果 |

## 设计规范

- 统一吉祥物造型，搭配对应主题图标
- 背景透明，可嵌入各种背景色
- 尺寸 200x200，居中显示
- 配合文字提示使用
