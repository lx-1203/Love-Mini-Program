## 使用说明

- 所有图标 viewBox: `0 0 24 24`
- stroke 颜色使用 `currentColor`，通过 CSS `color` 控制
- 统一线宽 2px
- 统一 `stroke-linecap="round"` 和 `stroke-linejoin="round"`
- 实心图标使用 `fill="currentColor"`
