# 05 Tags 标签

| 文件名 | 说明 |
|--------|------|

| tag-interest-pink.svg | 粉色兴趣标签（浅粉底深粉字） |

| tag-new.svg | 新标签（红粉色角标） |

## 设计规范

- 标签统一圆角胶囊形（高度的一半为圆角半径）
- 文字与背景色对比度符合可访问性标准
- 角标为45度三角形，用于图片左上角
