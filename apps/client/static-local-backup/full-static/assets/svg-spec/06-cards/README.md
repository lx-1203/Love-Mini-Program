# 06 Cards 卡片模板

各种卡片外壳和模板，用于构建页面组件。

## 文件列表

| 文件名 | 说明 |
|--------|------|
| card-shell-rounded.svg | 圆角卡片外壳（20px圆角，白色，柔和阴影） |
| card-match-overlay.svg | 匹配卡片底部渐变遮罩（底部加深） |
| card-user-horizontal.svg | 横向用户卡片模板 |
| card-feed.svg | 动态/帖子卡片模板 |
| card-notification.svg | 通知卡片模板 |
| card-circle.svg | 兴趣圈卡片模板 |

## 设计规范

- 卡片统一圆角 16-20px
- 使用 `feDropShadow` 滤镜实现柔和阴影
- 卡片模板为骨架占位形式，可直接替换内容
