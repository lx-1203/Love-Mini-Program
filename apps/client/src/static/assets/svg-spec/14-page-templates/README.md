# 14 Page Templates 页面线框模板

完整页面的 SVG 线框图骨架，尺寸 375x812（iPhone标准宽度）。

## 文件列表

| 文件名 | 说明 |
|--------|------|
| home-layout.svg | 首页布局线框（发现页） |
| match-layout.svg | 匹配卡片页布局线框 |
| profile-layout.svg | 个人主页布局线框 |

## 设计规范

- 画布尺寸：375 x 812（iPhone X 及以上尺寸）
- 状态栏高度：44px
- 底部Tab栏高度：84px（含安全区）
- 主色：薄荷绿 `#36C99A`
- 辅色：心形粉 `#FF6B81`
- 线框使用灰色占位，便于识别布局结构
