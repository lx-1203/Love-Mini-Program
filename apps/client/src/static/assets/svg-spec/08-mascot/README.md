# 08 Mascot 吉祥物「寻觅芽」

可爱的绿色小芽吉祥物，圆形麻糬造型，头顶两片嫩芽。

## 角色设定

- 名字：寻觅芽
- 造型：圆形麻糬状浅绿色身体
- 头顶：两片嫩芽叶子（薄荷绿）
- 眼睛：圆圆的黑色眼睛
- 腮红：粉色（#FFB6C1）
- 身体渐变：`#D4F5E4` → `#7DDEBB`

## 使用场景

- 空状态插画：搭配对应图标
- 引导页/欢迎页：吉祥物挥手
- 匹配成功：爱心眼表情
- 加载等待：漂浮姿势
