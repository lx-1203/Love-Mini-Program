# 09 Decorations 装饰元素

各种装饰性元素，用于丰富页面视觉效果。

## 文件列表

| 文件名 | 说明 |
|--------|------|
| leaf-1.svg | 单片薄荷叶 |
| leaf-2.svg | 双叶嫩芽 |
| leaf-falling.svg | 飘落的叶子 |
| heart-soft.svg | 柔和粉色实心心 |
| heart-outline.svg | 心形轮廓（currentColor） |
| heart-tiny.svg | 微型心形 |
| sparkle-star.svg | 四角星形闪光 |
| sparkle-dot.svg | 圆点闪光（带光晕） |
| wing-left.svg | 左天使翅膀 |
| wing-right.svg | 右天使翅膀 |
| confetti.svg | 彩纸屑 |
| speech-bubble.svg | 空对话气泡 |

## 设计规范

- 叶子使用薄荷绿系颜色
- 心形使用粉色系
- 闪光为金色（#FFD700）
- 可组合使用，营造氛围
