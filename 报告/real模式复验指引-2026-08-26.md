## 一、环境准备

### 1.1 Redis（必需，real profile 强制）

**方式 A：Docker（推荐）**
```bash
docker compose up -d redis
# 或单独启动
docker run -d --name campus-redis -p 6379:6379 redis:7-alpine
```

**方式 B：Windows 本机安装**
- 下载 Redis for Windows（https://github.com/tporadowski/redis/releases），解压后：
```bash
redis-server.exe --port 6379 --requirepass <REDIS_PASSWORD>
```
- 验证：`redis-cli.exe -a <REDIS_PASSWORD> ping` → PONG

### 1.2 MySQL（必需）

- 数据库：`campus_love`（docker compose 的 `MYSQL_DATABASE` 默认值）
- 首次初始化（Flyway 会自动迁移 `database/` 下脚本，或手动执行）：
```bash
mysql -h 127.0.0.1 -u root -p < init-mysql.sql
```

```bash

set JWT_SECRET=<随机强密钥，≥32字符>
set DB_URL=jdbc:mysql://127.0.0.1:3306/campus_love?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
```

> 安全说明：项目所有密码字段强制外部化（`${VAR:?}` 无默认值），漏配会 fail-fast 拒绝启动（DatabaseConfigValidator / RedisConfig）。

## 四、写路径持久化复验步骤

### 4.1 注册 → 资料写入 → 重登恢复（R5.1 / R4.2）

```bash
# 1) 注册新账号（返回 token）
curl -X POST http://127.0.0.1:8080/api/v1/auth/register -H "Content-Type: application/json" \
  -d '{"phone":"13800009999","password":"Test@123456","birthDate":"2000-01-01"}'
# 2) 保存 token 后写基础资料
curl -X PUT http://127.0.0.1:8080/api/v1/profile/basic -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"nickname":"复验用户","gender":"MALE","birthDate":"2000-01-01","height":175}'
# 3) 写校园资料
curl -X PUT http://127.0.0.1:8080/api/v1/profile/campus -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"campusName":"测试大学","department":"计算机系"}'
# 4) 退出登录（清 token）→ 重新登录
curl -X POST http://127.0.0.1:8080/api/v1/auth/login -H "Content-Type: application/json" \
  -d '{"phone":"13800009999","password":"Test@123456"}'
# 5) 读回资料，断言与写入一致（R4.2 通过标准）
curl http://127.0.0.1:8080/api/v1/profile/basic -H "Authorization: Bearer $NEW_TOKEN"
curl http://127.0.0.1:8080/api/v1/auth/me -H "Authorization: Bearer $NEW_TOKEN"
```

### 4.2 发帖 → 点赞 → 评论 → 重启后端 → 数据仍在（R4.2 持久化）

```bash
# 发帖
curl -X POST http://127.0.0.1:8080/api/v1/posts -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"category":"travel","title":"持久化验证帖","content":"重启后应仍在","images":[]}'
# 记录返回的 postId → 点赞 → 评论
curl -X POST http://127.0.0.1:8080/api/v1/posts/{postId}/like -H "Authorization: Bearer $TOKEN"
curl -X POST http://127.0.0.1:8080/api/v1/posts/{postId}/comments -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"content":"持久化评论"}'
# 重启后端 → 重新登录 → 读回列表/详情，断言帖子/点赞数/评论仍在
curl "http://127.0.0.1:8080/api/v1/posts?page=1&pageSize=20" -H "Authorization: Bearer $NEW_TOKEN"
```

### 4.3 实名认证持久化（R5）

- 学生证上传：`POST /verification`（multipart，upload 学生证图）→ 审核状态落库
- 重登后进入「认证中心」应显示已提交状态；审核通过后显示"已认证"徽章

### 4.4 自动化冒烟（可复用）

```bash
node scripts/verify-post-images.cjs   # 全部断言应 PASS
```

## 五、通过标准（对照 PRD）

| 验收项 | 通过标准 |
| --- | --- |
| R4.2 | 写操作 → 退出重登 → 数据完整恢复；后端重启后数据仍在（数据库级） |
| R4.3 | 读写响应 ≤300ms |
| R4.4 | 断网写操作有提示，重连后数据一致，无脏数据 |
| R5.1-R5.5 | 注册→资料→实名→兴趣→名片→核心入口全流程；公开页仅显徽章不显原始数据 |
