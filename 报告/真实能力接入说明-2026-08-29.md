## 1. 真实地理位置

**现状**：`apps/client/src/utils/location.ts` 已真实调用 `uni.getLocation`（首页/附近页 `initLocation` 自动执行），取经纬度并解析城市。此前 manifest 未声明权限导致**真机必失败**——本轮已修复：`manifest.json` mp-weixin 节点已加 `"requiredPrivateInfos": ["getLocation"]` 与 `permission["scope.userLocation"]`（构建产物 app.json 已验证包含）。

**真机可用还需要**：
1. 登录 [微信公众平台](https://mp.weixin.qq.com)（AppID wxc67cd233d72388d0）→「开发管理 → 接口设置」→ 申请开通 `getLocation`（属于需申请类目方可使用的接口；社交-交友类目通常可申请，需说明使用场景）。
2. 「设置 → 服务内容声明 → 用户隐私保护指引」中勾选「位置信息」，否则真机弹窗授权后被平台拦截。
3. 逆地理编码（经纬度→城市名）如需更精准可接腾讯位置服务（免费额度足够）：`https://apis.map.qq.com/ws/geocoder/v1` 需配置 request 合法域名。

**验收标准**：真机打开小程序 → 弹出定位授权 → 同意后首页/附近显示真实城市与真实距离。

## 2. 真实图片

**现状**：全链路已真实——用户头像/帖子图/相册通过 `wx.chooseMedia` 选图 → `POST /v1/media`（multipart）上传到后端磁盘存储（`{storageRoot}/uploads`），展示走 `/api/v1/media/**` 鉴权代理；装饰图走后端 app-assets 托管（807 个文件已播种）。

**上线时需要**：
1. 后端部署域名（HTTPS + ICP 备案）→ `.env` 配置 `VITE_API_BASE_URL=https://你的域名/api`；微信公众平台「开发设置 → 服务器域名」配置 uploadFile/downloadFile/request 合法域名。
2. 图片量大后建议把本地磁盘存储换成对象存储（腾讯云 COS/OSS）：只改 `LocalMediaStorageService` 一个实现类（接口 `MediaStorageService` 已抽象），加 bucket 配置即可。

**验收标准**：真机拍照/相册上传 → 别的用户可见该图。

## 3. 真实语音

**现状**：
- **录音**：`utils/audio-recorder.ts` 封装 `uni.getRecorderManager`（真实录音），聊天语音条 `VoiceRecorder.vue`、`voice-upload.ts` 上传后端——这条链路是真实的。
- **AI 语音/声音名片评分（AGNES）**：`.env` 已有 `AGNES_API_BASE` 指向内部评测服务；未配置时走模拟回包。

**接入真实语音识别/评测需要**（三选一）：
1. **微信同声传译插件**（WeChatSI）：小程序管理后台「设置 → 第三方设置 → 插件管理」添加该插件（免费额度），前端 `requirePlugin("WechatSI")` 直接文字互转，无需后端。
2. **腾讯云 ASR**（一句话识别/录音文件识别）：开通腾讯云账号 → 实名认证 → 创建密钥 → 后端加 `AsrService` 调 `asr.tencentcloudapi.com`，费用约 1~2 元/小时音频。
3. 继续用内部 AGNES 评测服务：只需在 `.env` 配置真实 `AGNES_API_BASE` 并保证该服务可达。

**注意**：录音权限 `scope.record` 微信会自动在首次录音时弹窗，无需 manifest 额外声明；但「用户隐私保护指引」需勾选「麦克风」。

**验收标准**：真机按住说话 → 松开后对方能播放该语音（链路已通）；若接 ASR，语音自动转文字显示。

## 4. 真实短信

**现状**：后端已有完整验证码骨架：`SmsCodeController`（`POST /v1/sms/send-code`）+ `SmsCodeService`（生成/校验/限频），当前发送通道为**模拟**（验证码回显在响应/日志中，供联调）。前端手机号登录页已对接该接口。

**接入真实短信需要**：
1. **资质**：企业主体营业执照 + 已备案网站/小程序/App（签名报备必需）。
2. **服务商**（任选）：
   - 腾讯云 SMS：开通 → 创建签名（如「校园恋爱」）+ 正文模板（验证码模板）→ 拿到 `SdkAppId / SecretId / SecretKey`。国内约 0.045 元/条。
   - 阿里云 SMS：同流程，约 0.045 元/条。
3. **代码改动**（仅后端一处）：`SmsCodeService` 中「模拟发送」分支替换为服务商 API 调用（HTTP 签名请求），新增配置项 `SMS_PROVIDER=tencent / aliyun`、`SMS_SIGN=…`、`SMS_TEMPLATE_ID=…`、`SMS_SECRET_ID/KEY=…`（加到 `.env`，密钥不入库）。
4. **平台配置**：微信公众平台配置 request 合法域名（服务商 API 由后端调用，不需要加域名）；但小程序内「手机号快速验证」若改用微信原生组件 `button open-type="getPhoneNumber"` 则按微信计费（0.03 元/次）且无需短信。

**验收标准**：真机输入手机号 → 收到真实短信 → 输入验证码登录成功；同一手机号 60s/24h 限频生效。

## 5. 实名认证

**现状**：产品内「实名/学生认证」为**照片材料 + 后台人工审核**流（`AdminRealNameController` + 校园认证 `CampusCertificationService`），链路已真实可用。

**若要「法定实名」（公安权威核验）有三条路**：
1. **微信官方人脸核验 `wx.startFacialRecognitionVerify`**：
   - 需要：小程序类目属于开放范围（政务/金融/医疗/保险/教育等部分类目）；**社交/交友类目一般不在开放列表**——需先与微信确认类目资格，不可用则走 2/3。
   - 需要：用户微信已实名（绝大多数用户满足）+ 后端用 AppID/Secret 调微信接口预签核验任务。
   - 改动：前端认证页调起 API + 后端回调落库。
2. **第三方实名认证 API**（腾讯云慧眼、阿里云实人认证、数据堂/聚合数据二要素/三要素）：
   - 需要：企业资质 + 服务商账号 + 计费（二要素约 0.2~1 元/次，人脸核身 1~3 元/次）。
   - 改动：后端加 `RealNameVerifyService`（身份证号+姓名二要素，或加人脸照比对），前端认证页改为表单+人脸活体 SDK（H5/小程序插件）。
3. **维持现有人工审核**：合规且零成本，适合当前阶段；把「手持身份证照」的存储加密（`.env` 已有 `APP_AES_SECRET`，接 AES 落盘）+ 后台脱敏查看即可。

**共同合规要求**：《个人信息保护法》要求明示收集目的、最小化存储（身份证号加密存储、照片限定审核员可见）、隐私政策更新「身份认证」条目。

**验收标准**：提交姓名+身份证号 → 返回核验通过/失败 → 后台看到核验记录（而非仅照片）。

## 6. 真实支付（微信支付）

**现状**：未接。商业化（VIP 套餐/金币/礼物）后端表与后台管理已就绪，支付通道空缺。

**接入需要**：
1. 微信支付**商户号**（mchId）：企业主体 → [pay.weixin.qq.com] 申请 → 绑定 AppID wxc67cd233d72388d0 → 配置 APIv3 密钥 + 商户证书序列号 + 回调域名。
2. 后端：新增 `PaymentService`（JSAPI 下单 `POST /v3/pay/transactions/jsapi`）+ 支付回调验签落库 + 退款接口；用户 OpenID 由当前登录态提供。
3. 前端：`uni.requestPayment`（timeStamp/nonceStr/package/signType/paySign 由后端返回）。
4. 费率：实物 0.6%、虚拟内容通常 0.6%（部分类目更高）；结算 T+1。
5. 合规：虚拟支付在小程序内需符合微信虚拟支付规范（iOS 虚拟商品限制需特别注意——社交类会员购买在 iOS 端可能被拒）。

**验收标准**：真机支付 0.01 元测试单 → 后台订单可见 → 回调改 VIP 状态。
