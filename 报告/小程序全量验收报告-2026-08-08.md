### 5.1 类型 A：Vue Error 空对象（10 条，占比 67%）

**现象**：`[Global Error][Vue Error] {} https://vuejs.org/error-reference/#runtime-1`，
出现在 03-discover-history（2）、04-discover-video-player（2）、27-campus-certification（2）、
28-daily-question（3）、33-heart-signals（2）、49-sub-setup-recommend-pref（1）。

**根因**：页面模板使用 `$t(...)` 全局方法，但 mp-weixin 构建下 vue-i18n 的
`globalProperties.$t` 未注入（i18n 的 message compiler 在 mp-weixin 被替换为桩，
见 [i18n/index.ts](apps/client/src/i18n/index.ts) 的兼容逻辑）。script 中 `useI18n()` 解构出的
`t` 可用，但**模板里直接写 `$t(...)` 的页面在运行时取不到函数**。

**精确位置**（模板 `$t` 用法，script 仅解构 `t`）：

| 页面 | 代码位置 |
|------|----------|
| [discover/history.vue](apps/client/src/pages/discover/history.vue) | L129/137/141/145/153/160 等 10+ 处 `$t("discoverHistory.*")` |
| [daily-question/index.vue](apps/client/src/pages/daily-question/index.vue) | L83-113 全部 `$t("dailyQuestion.*")` |
| [heart-signals/index.vue](apps/client/src/pages/heart-signals/index.vue) | 模板 `$t("heartSignals.*")` |
| [campus/certification.vue](apps/client/src/pages/campus/certification.vue) | 模板 `$t("campusCertification.*")` |
| [love-center/mbti.vue](apps/client/src/pages/love-center/mbti.vue) | 模板 `$t(...)` |
| [discover/video-player.vue](apps/client/src/pages/discover/video-player.vue) | 模板 `$t(...)` |
| [subpackages/setup/recommend-pref/index.vue](apps/client/src/subpackages/setup/recommend-pref/index.vue) | 模板 `$t(...)` |

**修改方案**（不执行，仅方案）：
1. **推荐**：`main.ts` 中 `app.use(i18n)` 后显式注册
   `app.config.globalProperties.$t = i18n.global.t`（[main.ts](apps/client/src/main.ts) L81-108 区域）；
2. 或批量把上述页面的模板 `$t(...)` 替换为 `t(...)`（需逐页在 `<script setup>` 中确认已解构 `t`）；
3. 回归验证：重新构建后检查上述 6 页 console 无 `$t is not a function`。
