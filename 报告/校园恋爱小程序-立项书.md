## 一、执行摘要

**「寻觅」（Xunmi）是一款面向高校在校学生的微信小程序，专注于校园场景下的恋爱匹配与破冰社交。** 项目已完成从 0 到 1 的产品研发，并于 2026-08-20 完成像素级 UI 一致性重构，整体研发已达**可发布候选（Release Candidate）标准**。

**市场机会（真实数据）**：教育部《2024 年全国教育事业发展统计公报》显示全国高等教育在学总规模 **4846 万人**；艾媒咨询显示 2025 年中国互联网婚恋交友市场规模 **103.5 亿元**（首破百亿）；灼识咨询援引 2024 年中国在线情感社交市场 **226 亿元**、预计 2029 年达 **757 亿元**——校园垂直恋爱赛道兼具规模基数与供给空白。

核心亮点：

1. **产品完整度高**——已建成覆盖"发现推荐 → 匹配 → 破冰沟通 → 社区沉淀 → 商业化"的完整功能链路，包含发现、匹配中心、悄悄话、附近的人、村落社区、活动、钱包等 15 类核心模块。
2. **商业化路径清晰**——已形成以"交友币（coins）+ 悄悄话付费留言"为核心的闭环变现通道，计费具备幂等与退款保障；VIP 权益与聊天红包经决策已分别暂缓、下线，路线聚焦。
3. **技术底座扎实**——采用 uni-app + Vue 3 + TypeScript 前端、Spring Boot 3 + Java 17 后端、MySQL 8 + Redis 7 数据层、Docker Compose 部署与 Prometheus / Grafana 监控，架构现代、可运维。
4. **临门一脚明确**——剩余工作集中于真机验收、少量组件与动效补齐、后端接口对齐与微信审核提交，路线清晰，剩余为发布前的确定性工作项，确切上线时点取决于真机验收进度与微信审核时长。

**本轮诉求预览**：以本立项书确认项目立项与发布准备节奏，并启动融资沟通。

### 2.3 品牌定位与差异化

**「寻觅」相信：校园恋爱，值得被认真而温柔地对待。**

我们不做泛社交的流量生意，而是深耕高校这一高信任场景，用产品把"想认识人"变成"自然地认识对的人"。

- **真实校园，信任为先**：限定在校场景 + 微信身份，过滤虚假与骚扰，让每一次匹配都更可信——这是「寻觅」的信任底色。
- **破冰有温度**：以悄悄话付费留言、临时匿名聊天、附近的人，把"开口难"变成"自然搭讪"，降低陌生人首轮触达门槛。
- **关系能沉淀**：村落（校园社区）、活动、兴趣把一次心动延伸为持续连接与日常留存，而非"用完即走"的快餐匹配。
- **质感即品牌**：统一 Design Token 设计契约，全量页面视觉一致、细腻克制，以"认真恋爱"的调性传递品牌质感。

## 三、市场背景与用户痛点

### 3.1 市场基数（真实数据）

- **高校用户池**：教育部《2024 年全国教育事业发展统计公报》显示，全国各种形式高等教育在学总规模 **4846 万人**，普通 / 职业本专科在校生 **3891 万**，高等学校 3119 所，高等教育毛入学率 60.8%——规模庞大且天然高频使用微信。
- **婚恋社交大盘**：艾媒咨询数据，2025 年中国互联网婚恋交友市场规模 **103.5 亿元**（同比 +5.61%，首次破百亿）；灼识咨询援引，2024 年中国在线情感社交市场 **226 亿元**、用户约 2.8 亿，预计 2029 年达 **757 亿元**。
- **需求刚性**：公开报道显示，2024 年我国单身人口约 **2.4 亿**（占总人口 17%），20–40 岁适婚人群约 **3 亿**，"催婚焦虑"持续放大情感社交需求。

### 3.2 校园垂直的真实需求验证

- **校园案例**：上海交大校内恋爱匹配平台 SJTU Date 于 2025-03 上线，一周注册超 7000 人、首轮 2400 人成功匹配，印证高校恋爱需求强、爆发快、信任门槛低（同校邮箱注册）。
- **供给空白**：泛社交平台（陌陌 / 探探 / Soul）校园身份弱、信任成本高；高学历婚恋平台（青藤之恋）主要面向毕业生 / 研究生；"可信同校 + 轻关系破冰"尚未被结构化满足——这正是「寻觅」的切入位。

### 3.3 核心痛点（由产品功能反证）

| 痛点             | 行业佐证                           | 对应产品解法                          |
| -------------- | ------------------------------ | ------------------------------- |
| 陌生人首轮触达门槛高、易冷场 | 艾媒：42% 用户担忧对象信息虚假、41.3% 担忧隐私泄露 | 悄悄话（付费留言）、临时匿名聊天降低破冰成本          |
| 校内弱关系发现效率低     | 泛平台同校场景缺失                      | 附近的人、兴趣选择、搜索精准定位同校同好            |
| 匹配后缺乏持续关系承载    | 纯滑卡留存弱                         | 村落（校园社区）、活动、每日签到提升留存            |
| 信任与安全顾虑        | 行业信任危机突出                       | 校园身份场景 + 后端鉴权（Token v2）+ 计费幂等保障 |

### 3.4 为什么是现在 / 为什么是我们

微信小程序降低安装与试用门槛、贴合学生习惯；项目已完成从启动到发布候选的完整研发，功能链路齐备、商业化闭环跑通——具备低成本验证、快速放量的前提。

> 数据来源：教育部《2024 年全国教育事业发展统计公报》（2025-06）、艾媒咨询《2025 中国婚恋社交服务市场研究报告》、灼识咨询（引自米连科技港交所招股书）、上观新闻 SJTU Date 报道、21 财经等公开资料。

## 五、商业模式

### 5.1 商业化现状（已跑通）

| 通道         | 状态      | 说明                     |
| ---------- | ------- | ---------------------- |
| 交友币（coins） | 运行中     | 虚拟币充值与消费，计费具备幂等与退款保障   |
| 悄悄话付费留言    | 运行中     | 以付费留言作为核心破冰变现触点        |
| VIP 会员权益   | **暂缓**  | 经决策暂缓，客户端入口已下线，仅保留占位说明 |
| 聊天红包       | **已移除** | 功能已下线，相关代码已清理          |

### 5.2 商业化逻辑

以"低门槛免费匹配 + 高意愿付费破冰"组合，把高频免费行为转化为低频高客单价的付费触点；交友币作为通用计量，平滑多场景付费。

### 5.3 未来商业化空间

- 会员订阅、增值匹配、活动付费、校园商家合作等方向的延展空间，待融资后结合运营数据验证。
- **不在此文档臆测任何无来源的营收、转化率或用户规模数字。**

### 5.4 行业变现参照（真实标杆）

- **伊对（米连科技）**：2025-09 递交港交所招股书；2024 年营收 **23.73 亿元**、平均月活 **990 万**、月付费用户 **120 万**（付费率约 12%）、净利润 **1.46 亿元**——验证"虚拟币 / 会员 + 互动"情感社交模式可规模化盈利。
- **付费意愿**：行业头部付费用户 ARPU（2025）珍爱网 428 元、百合佳缘 395 元、青藤之恋 512 元，用户为高质量、高隐私匹配付费意愿持续增强。
- **对「寻觅」的启示**：以 coins + 悄悄话双通道切入，单位经济可对标上述标杆；校园场景信任更高、获客成本更低，具备更优变现效率空间。

### 7.3 阶段二：上市后验证增长（上线后 0–6 个月）

**核心目标**：在首批试点高校验证"密度—留存—付费"的单位经济模型，为规模扩张与下一轮融资积累数据。

| 里程碑        | 内容                                      | 量化指标                |
| ---------- | --------------------------------------- | -------------------- |
| G1 单校密度验证  | 首批试点高校达成活跃密度与社区氛围                       | 覆盖高校数、单校活跃用户        |
| G2 留存与付费验证 | 验证留存曲线与付费转化，对标行业付费率 ~12%、ARPU 395–512 元 | 次留 / 30 留、付费率、ARPU |
| G3 产品与生态打磨 | 村落/活动/兴趣活跃度与破冰体验优化                      | 社区活跃、悄悄话转化          |

**价值解锁**：确认单位经济可跑通，形成可复制的"单校模型"，作为阶段三放量与第一轮机构融资的核心论据。

---

### 7.4 阶段三：规模扩张（上线后 6–18 个月）

**核心目标**：将验证成功的单校模型向多校、多区域复制，建立校园密度网络，并补齐产品/运营/市场/合规团队。

- **复制扩张**：从试点高校走向区域集群，逐步覆盖更广高校网络。
- **增长投入**：校园推广、活动运营、品牌渗透，依托微信生态与校园 KOC 放大获客效率。
- **团队补齐**：随融资到位完善产品、运营、市场与合规编制，缓解执行资源集中度。
- **规模里程碑**：用户规模、营收阶梯（以 SAM 校园潜在用户约 2300 万为方向锚点）。

---

### 7.5 阶段四：商业化深化（上线后 18 个月+）

**核心目标**：在验证与规模基础上，深化变现与壁垒，构建可持续的校园情感社交生态。

- **变现延展**：基于运营数据重启评估 VIP 会员权益（当前暂缓）、拓展活动付费、校园商家合作等多元通道。
- **生态壁垒**：以"村落社区 + 活动 + 兴趣"沉淀持续关系，形成高信任校园场景护城河，提升迁移成本与留存。
- **战略选项**：区域密度成熟后可评估横向品类延伸或平台化开放能力。

---

### 7.6 融资节奏与里程碑对齐

- **本轮资金**主要支撑阶段一（发布准备）与阶段二（验证增长）起步；阶段三起可由营收滚动或下一轮融资接力。
- **关键资金里程碑**：M4（RC 就绪）前完成团队补齐；M5（上线）前完成合规与首轮推广预算到位；阶段二末（G1–G3 达标）触发规模扩张与下一轮融资决策。
