## 二、重大根因：附近页“校园十景”大图铺满顶部（才是用户所说“显示不了/卡死”）

**现象**：用户反馈“首页/附近出了问题、整个显示不了、点进去卡死”。定位后确认 **首页正常**，问题在 **附近页**：顶部出现一张巨大“校园十景”校园照片横幅，把“附近”标题、快捷入口等全部顶上/遮住，页面渲染压力大。

**根因**：
- `pages/nearby/index.vue` 中 `.campus-entry` 未设置 `position: relative`；
- 其子元素 `.campus-entry__cover-wrap` 使用 `position: absolute; inset: 0`，本意是让校园封面铺满**卡片**；
- 但父级不是定位元素，该绝对定位会相对**整页**铺满，4 张校园封面（`school-main.png`，507KB）同时铺满页面作为背景，顶部呈现“校园十景”大图，并把头部/入口内容覆盖。

**修复**：`.campus-entry` 增加 `position: relative`，让封面被约束在卡片内。

## 三、其他已修复问题

### 1. 8 个 SFC 文件被误加 Markdown 代码围栏（代码卫生）
多个 `.vue` 单文件组件首尾被误写 ```` ```vue ```` / ```` ``` ````，已清理：`home`、`chat-session`、`messages`、`discover`、`nearby`、`official-chat`、`MatchActions`、`MatchLoading`。**注：清理围栏后附近页结构虽正确，但真正的“显示不了”仍由第二节的绝对定位 bug 造成。**

### 2. 兴趣圈图片阴影笼罩 / 显示不全（P0#2）
- `components/home/InterestRecommendation.vue`：去掉图片上的黑色渐变浮层，把“圈名 + 成员数”移到图片下方白底区域，仅保留“加入”胶囊按钮；封面统一 `CIRCLE_COVERS` 摄影大图、固定尺寸。

### 3. 聊天身份 / 方向错乱（同一头像、像自己跟自己聊）（P0#3）
- `pages/chat-session/index.vue`：`selfAvatarSrc` 优先取当前用户真实头像 `profileStore.avatarUrl`，缺失回退 `AVATAR_2`；`peerAvatarSrc` 优先取 `session.partnerAvatar`，缺失按会话 hash 从头像池推导，确保不同对象不同头像、自我/对方可区分。

### 4. 助手消息气泡“上绿下粉”（P0#4）
- `pages/official-chat/index.vue`：为 `.assistant-chat` 根节点设置浅薄荷底色 `var(--c-bg-page,#F7FAF9)`，覆盖全局 `--c-gradient-page`（粉→灰）造成的“上绿下粉”。

### 5. 个人主页图片墙不可见 + 绿色“+”按钮（P0#5）
- `pages/profile/index.vue`、`components/common/GlobalPublishFab.vue`：`GlobalPublishFab` 固定右下角、点击跳 `/pages/village/post`；照片墙用 `SafeImage`（`toLocalImage` 兜底 + 审核角标）。图片不可见为**后端未下发故事/相册图片**导致，代码占位正常。

### 6. 圈子详情 / 话题页“卡死”（P0#6）
- `pages/circles/topics.vue`、`topic-detail.vue`：无 JS 异常/死循环；一次性加载较大数据图片较慢，改用 `navigateTo` + 12s 等待可正常渲染，建议后续图片懒加载 + 分页。
