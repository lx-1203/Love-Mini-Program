## 一、构建环境修复

### 问题
项目默认使用 Node.js v16.13.1，但 Vite 5.11（Vue3 模式）内部依赖 `crypto.getRandomValues()` Web API，该 API 在 Node 16 中不存在（Node 19+ 才原生支持），导致构建失败：

```
crypto$2.getRandomValues is not a function
Build failed with errors.
```

### 解决方案
1. **创建 `crypto-polyfill.cjs`**（`apps/client/crypto-polyfill.cjs`），在进程启动前 polyfill `globalThis.crypto.getRandomValues`
2. **使用 Node.js v22.17.0**（路径 `D:\codex-tools\node-v22.17.0-win-x64\`），pnpm 11.17.0 要求 Node >= 22.13

### 构建验证
```bash
# 设置 Node 22 环境
$env:PATH = "D:\codex-tools\node-v22.17.0-win-x64;" + $env:PATH

# 执行构建
cd d:\6\恋爱小程序\apps\client
node scripts/prepare-static.mjs --dev
node scripts/profile-svg-to-png.mjs
pnpm exec uni build --platform mp-weixin --mode mp-weixin
```

**结果**: `DONE Build complete.` -- 构建成功，产物位于 `dist/build/mp-weixin/`

### 注意事项
- 每次构建前需确保 PATH 中 Node 22 优先于 Node 16
- `vite.config.ts` 中已添加 `"global": "globalThis"` polyfill 作为双重保险
- Dart Sass legacy-js-api 警告为非关键性提示，不影响功能
