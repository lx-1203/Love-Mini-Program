1. **R5 注册链路未在本轮改动代码**：注册/资料/认证流程既有实现保持原样，由 QA 按 `报告/架构勘察报告-系统修复-2026-08-26.md` §五 与 PRD R5.1-R5.5 做全流程真实验证。
2. **实名阻塞边界（Open Question）**：chat-session 仅判登录+资料完善度、未判实名，与 PRD"实名阻塞核心入口"存在张力，标记产品待确认（同设计文档 §七.6，本轮不扩大判定范围）。
3. **verify-post-images.cjs 需后端服务运行**：脚本默认连 `http://127.0.0.1:8080`，后端未启动时无法通过（QA/CI 启动服务后执行）。
4. **附近页图片约束**：`.nearby-home image { max-height: 400rpx }` 全局约束保留（勘察报告 §2.2.D 提示与 PostCard 九宫格冲突，但实测 PostCard 单格/单图高度均 < 400rpx，触发概率低；若 QA 截图发现压缩可后续收窄该约束）。
5. **people.vue 分页语义**：后端 recommendations 不支持 page 参数，采用前端全量切片分批渲染（首批 20 + 触底增量），符合设计 §五。
