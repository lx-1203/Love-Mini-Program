## 二、各主要页面 UI 结构分析

### 1. pages/home/index.vue（首页 - 今日恋爱）

**功能概述**: 今日推荐 + 恋爱进度条 + 快捷入口卡片

```
关键技术:
- useHomeStore: 首页数据拉取
- useCircleStore: 兴趣圈数据
- useSessionStore: 登录态管理
- openAppPath / openUserProfile / switchTabWithQuery: 导航
- useTabBar: 自定义 TabBar 控制
- useMenuButtonRect: 右上角菜单按钮适配
- toHomeViewModel: 首页 ViewModel 转换

核心交互:
- onPullDownRefresh: 下拉刷新
- rotateToday: 轮换今日推荐人物
- handleLike: 喜欢操作（需登录）
- handleLoveStep: 恋爱进度步骤导航（profile/discover/messages）
```

### 2. pages/login/index.vue（登录页）

**功能概述**: 微信一键登录 + 手机号登录 + Hero 动态文案

```
关键技术:
- useAppConfigStore: 后台配置即时生效（login_open / register_open 开关）
- consumePendingLoginRedirect: 消费 LockScreen 写入的待跳转路径
- ROUTES 常量化路由
- IMAGE_PATHS 配置化图片路径
- createButtonGuard: 按钮防重复点击
- lightHaptic: 协议链接触觉反馈
- Sentry: 登录失败异常上报

动态文案:
- heroTitle / heroSubtitle / heroDesc / heroDescSub
- 兜底文案从 i18n 资源读取（login.heroTitle 等）
- 安全清理 onUnmounted 避免内存泄漏
```

### 3. pages/profile/index.vue（个人中心）

**功能概述**: 头像/昵称/学校/签名/VIP 状态 + 数据统计 + 资料完善度 + 功能菜单

```
关键技术:
- useProfileStore: 个人资料管理
- useLikesStore: 喜欢数据
- useCheckInStore: 签到系统
- useMock: mock/real 模式切换
- 3-K 邀请奖励: POST /invites + GET /invites/rewards
- UniUploadFileLike: H5/File 与 mp-weixin/tempFilePaths 双端兼容上传
- buildFileLike: 统一文件构造
- LockScreen: 资料未完善时锁定页面
```

### 4. pages/discover/index.vue（寻觅页）

**功能概述**: 滑动卡片匹配 + 喜欢/超级喜欢/跳过 + 实名认证门

```
关键技术:
- useDiscoverStore: 寻觅数据
- useMatchStore: 匹配状态管理
- isCacheFresh / setCachedValue: 缓存过期管理
- ensureCertified("realname"): 实名认证门控
- swipeLeft: 跳过操作
- enterMatching: 进入匹配流程（like / superLike）
- useTabBar / useMenuButtonRect: TabBar 适配
```

### 5. pages/discover/matching.vue（匹配中）

**功能概述**: 匹配加载动画 + 双方头像展示 + URL query 支持

```
关键技术:
- MatchLoading 组件: 匹配加载动画
- animationDone / checked / previewMode: 动画状态控制
- loadPartnerProfile: 异步拉取对方资料
- URL query 直达: userId/cardId/action（自动化验收/分享恢复）
- 支持从 URL query 初始化匹配上下文
```

### 6. pages/discover/match-success.vue（匹配成功）

**功能概述**: 匹配成功庆祝 + 匹配理由 + 去聊天/继续探索/分享

### 7. pages/nearby/index.vue（附近首页）

**功能概述**: 附近的人（含同城）+ 热门兴趣圈 + 校园圈 + 活动 + 附近动态

```
关键技术:
- useVillageStore: 帖子数据
- useCircleStore: 兴趣圈数据
- useActivityStore: 活动数据

```

### 8. pages/nearby/people.vue（附近的人）

```
关键技术:
```

## 七、技术栈总结

| 层面 | 技术选型 |
|------|----------|
| **框架** | uni-app (Vue 3 + Composition API) |
| **语言** | TypeScript + SCSS |
| **状态管理** | Pinia (storeToRefs) |
| **国际化** | vue-i18n |
| **包管理** | pnpm (workspace monorepo) |
| **构建目标** | mp-weixin (微信小程序) |
| **样式体系** | Design Tokens (JS) + CSS Variables (SCSS) 双源管理 |
| **组件化** | 自定义组件 (MatchLoading, MatchSuccess, PostCard, NearbySection, LockScreen, Skeleton, ErrorState, EmptyState, TopicSelector 等) |
| **导航** | 路由常量化 (ROUTES) + openAppPath/openUserProfile/switchTabWithQuery |
| **图片处理** | resolveMediaUrl 鉴权代理 + useImageFallback 占位 |
| **性能** | watch 去 deep、500ms debounce 草稿保存、未登录不发受保护请求 |
| **监控** | Sentry (登录失败上报) |
| **多端兼容** | H5 + mp-weixin 双端（File/UniUploadFileLike 兼容层） |
