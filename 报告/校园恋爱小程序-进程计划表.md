## 四、关键路径与时间轴

```
M0(完成) ──► M1 真机验收 ──► M2 组件/动效/后端对齐 ──► M4 发布候选 ──► M5 审核上线
                 │                    │
                 └── M3 商业化冻结 ───┘（W2 并行决策）

外部不可控：M5 微信审核时长
单点瓶颈：单人开发，关键路径难并行（融资后补团队可缓解）
```

- **关键路径**：M1 → M2 → M4 → M5（约 6 周）。
- **可压缩项**：动效（非阻塞）可在 W2–W3 弹性排布。
- **主要不确定项**：微信审核时长（决定 M5 实际上线日）。

## 五、风险与缓解

| 编号 | 风险 | 缓解动作 |
|------|------|----------|
| R1 | 微信审核不通过 / 时长不定 | 提前备类目与隐私材料，留审核缓冲 |
| R2 | 单人开发单点瓶颈 | 融资后补团队，关键任务留冗余 |
| R3 | 商业化验证不足 | 聚焦双通道，数据驱动迭代 |
| R4 | 校园合规与隐私 | 备隐私政策与资质，限校园场景 |
| R5 | 竞争同质化 | 强化校园垂直 + 社区沉淀壁垒 |
| R6 | 国庆重叠应急响应弱 | 上线观察期避长假或备值守 |
