## 五、缺失素材 / 数据（无法 100% 还原的项）

> 以下项因**后端未返回对应数据**或**素材缺失**而无法在当前版本完全还原，需在后台/素材补齐后即可呈现：

1. **`default-avatar.png` 缺失**：`prepare-static` 构建时提示「本地必需资源缺失 default-avatar.png」。
2. **寻觅卡片距离/在线**：推荐用户 `distanceText=null`、`activeStatusText=offline`，导致卡片左上「5km」与右上「● 在线」标签不显示；需后端为推荐用户补充距离与在线状态字段。
3. **性别字段**：推荐卡片/他人主页/我的主页均无 `gender` 字段，参考图中的「♀/♂」符号无法显示；需后端在 RecommendedPersonView / UserProfileDTO 补充。
4. **首页推荐卡生活照缩略图**：`TodayRecommendationView` 无生活照片数组，参考图姓名下方「4 张横向小照片」无法实现。
5. **星座/更多认证字段**：参考图「1.2km · 已认证 · 双子座」中的星座字段后端未提供。
6. **他人主页学校/距离/在线/动态**：`fetchPublicProfile` 返回的他人资料缺少学校、距离、在线状态，且 `recentPosts` 为空，「最近动态」模块无内容。
7. **我的故事元数据**：我的故事仅有照片 URL，无「生活日常/旅行足迹/我的心愿」等故事名称与篇数。
8. **社区动态/附近的人/兴趣圈封面**：首页 feed 的社区动态与兴趣圈无封面图数据（参考图为图片封面卡片）。
9. **我的主页右上角分享/设置图标**：参考图头部右上角有分享与设置入口，当前未添加（不影响核心结构）。

## 八、第二轮补充（2026-08-16 继续迭代）

在第二轮迭代中完成以下修复与增强（均已重新截图验证，4 页 console 错误 0）：

### 8.1 修复：寻觅页首屏空白
- **根因**：`discover/index.vue` 中重复定义了 `.match-page` / `.match-scroll` 两套样式（`height:100%` 与 `flex:1` 冲突），导致 `scroll-view` 内容高度塌陷，卡片与操作按钮全部不可见（首屏只剩导航栏和 TabBar）。
- **修复**：合并为单一 `.match-page { height:100vh }` + `.match-scroll { flex:1; min-height:0; height:100% }`，卡片恢复正常渲染。

### 8.2 新增：我的主页右上角分享/设置图标
- `MyHeader.vue` 顶部右上角新增「▦ 分享」「⚙ 设置」圆形图标（白色半透明底、白字，避开微信胶囊）。
- 设置点击进入 `/pages/settings/index`；分享点击暂提示「分享功能即将上线」。

### 8.3 优化：匹配度徽章
- 寻觅卡片右下角匹配度改为**绿色圆环进度**（`conic-gradient` 按匹配度百分比填充，兼容性兜底为纯绿色圆环）。

### 8.4 我的故事支持后端元数据
- 客户端 `UserProfileDTO` 新增 `stories` 字段；`MyStory` 优先渲染后端返回的故事（封面/标题/日期），无数据时回退为照片卡 + 虚线「添加故事」卡。

### 8.5 首页模块布局
- 「兴趣推荐」与「附近的人」改为**左右并排**（各占半宽，内部横向滚动）。
- 附近的人新增底部浅绿引导条「附近有 N 位值得认识的人 ›」。
- 「社区动态」改为**横向滚动卡片**（头像/姓名/圈子/关注/文字/图片/点赞评论分享）。
