## 2. 寻觅页重构摘要

- 目标：以「左右滑动匹配卡片」为绝对核心，辅助功能轻量化
- 成果：顶部三行化（标题/筛选/搜索+签到弹窗）、每日一问迁入圈子页、签到弹窗组件、胶囊安全距离 composable、卡片区 min-height 修正、死样式清理（约 1200 行）、错误/空态分支链重构
- 后端：双向匹配成功自动创建免费会话（RealMatchService + 3 个新单测）

## 4. 已知限制与遗留

- VIP「立即开通」= 前端守卫「建设中」（后端无微信支付端点，业务决策）
- 商城无商品详情页（前端 TODO）
- AI 聊天 `chat_ai_enabled` 硬编码 false
- 视频通话无真实 WebRTC（仅呼叫/接听状态机）
- 推荐接口部分字段（职业/收入/真实距离/活跃状态）为占位或前端映射，后端补字段为后续迭代项

## 5. 环境操作备忘（2026-08-08 实战验证）

- 本地跑后端：先 `mvn package -DskipTests` 重打包 → `java -jar` real profile（需 DB_URL/DB_PASSWORD/JWT_SECRET/AGNES_API_BASE/ADMIN_OPENID 等环境变量，见 apps/api/.env.local）
- 模拟器自动化：`cli.bat auto --project <root> --auto-port 9420 --trust-project` 启动自动化服务（必须在 IDE 未运行时执行；重复执行会关闭 IDE）
- **project.private.config.json 必须含 `"urlCheck": false`**：缺失时 devtools 代理拦截本地 https API（onProxyError / 403），页面只渲染空壳（截图 10KB vs 修复后 200KB+）
- 强杀 IDE 可能损坏 WeappCompileCache → 删除 `User Data/<profile>/WeappCache` 后重启
- automator 0.12.1 与新版开发者工具存在兼容问题（Tool.getInfo 缺 SDKVersion 导致 checkVersion 崩溃），已打容错补丁
- 截图脚本 `scripts/mp-shoot-walkthrough.cjs`：运行时 `POST /auth/guest-login`（主 47）/ `POST /auth/phone-login`（副 8）换取 token，替代会过期的硬编码 JWT
