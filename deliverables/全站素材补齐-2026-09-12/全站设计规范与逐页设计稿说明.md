## 1. 全局设计规范（设计系统）

### 1.1 设计原则

1. **主题底色统一浅绿** `#EEF7F2`，页面间不得出现白/灰断层（2026-08-31 用户验收定论）
2. **绿色 = 行动，粉色 = 喜欢**，两色禁止混用（寻觅 v3 视觉角色令牌）
3. **一令牌一值**：页面只引用 `var(--c-*)` / `--sp-*` / `--r-*` / `--s-*`，禁止私有色值
4. emoji 一律替换为标准 SVG（资源站 freesvglab.com/zh），吉祥物 4 张唯一真相源 = api app-assets
5. 除头像/人物照片外，其余视觉元素对照理想效果图 100% 还原

### 1.6 mp-weixin 渲染铁律（素材使用必读）

1. `<image>` 不响应 CSS `object-fit` → 用原生 `mode="aspectFill|aspectFit"`；禁 `image-rendering: crisp-edges`
2. 显式宽高防 0×0（基线 `_image-base.scss`）
3. 裸 `:src` 一律包 `resolveMediaUrl` / `SafeImage`（mp base lib 拒 http 图）
4. 行内 mp-audit 豁免注释勿拆行；`check:mp-image --strict` 已前置挂 3 条交付链
5. 主包 2MB 门禁：大图走后端 app-assets，构建期 `prepare-static` 管理
6. iOS WebView 装饰 image 加 `pointer-events="none"` 防吞点击
