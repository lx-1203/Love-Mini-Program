02

组件状态规范

每个组件的全状态枚举，缺一不可

三类件：筛选 chip（四枚，选中态唯一）、账单卡（类型 × 状态 徽标矩阵 + 8 个字段行的条件枚举）、 列表容器（加载中 / 空 / 有账 三互斥）。本页没有分页控件、没有下拉刷新可视件（刷新走 onPullDownRefresh，系统手势）。

筛选 chip · 两态 × 四枚

选中底 --c-gold-bg-tint（rgba(255,215,0,.18)）+ 1px --c-gold 描边 + 金字（12px/600 压在近白淡金上 ≈ 1.5:1， 在册可达性问题）；未选底 --c-bg-secondary #D1F5E7（浅绿）压白条。

列表容器 · 三互斥

判据 isLoading && isEmpty → isEmpty → v-for； isEmpty 取的是过滤后的 filteredBills， 所以「有账但当前筛选无命中」也会出 F04 空态（文案仍是「暂无账单记录」，易误读，在册）。

状态画面备注
加载中仅一行「加载中...」（common.loading，13px 三级文）无骨架屏（与 wallet 页不同档）
空EmptyState type="no-data"：BOX 图标 60px + 标题「暂无账单记录」+ 预设副题「这里空空如也」标题由页面显式传入，副题走组件预设

60px · 非素材缺口
与实况的已知差异 + 数值口径（画板不修，登记在此）：
  • 当前默认态是「重定向」，本画板四屏全部画开关开启态。判据 vip/bills.vue:36-45 onLoad → if (!featureFlags.membershipEnabled)（config/feature-flags.ts:40 硬编码 false） → toast vip.membershipDisabled → 有栈 navigateBack()、无栈 switchTab('/pages/profile/index')； 同写法见 vip/index.vue:60-69、vip/promo-code.vue:33-42。 另 onShow（:97-99）也带同一 flag 守卫，flag=false 时连请求都不发。 这三页的闸是前端常量，与 market 三页的后端 commerce.* 开关（appConfig.isCommerceOn）互不相干—— 巡检报告把两者一并记作「封存态转发到 profile」，读基准时要分清。
  • 三笔账单的全部数字 = mock 种子：stores/vip-billing.ts:69-125 （4800/8400 分、1800/2800 分、1800/1800 分，交易号 wx_mock_1001..1003，备注「首次开通 / 自动续费 / 用户申请退款」）。 real 模式走 GET /vip/bills?page=0&size=20，金额与交易号以后端订单真值为准 ⇒ 画板上的 ¥48.00 / ¥18.00 等不是后端真值，只是演示种子。
  • 日期是「渲染时刻 ± 相对天数」派生值，不是固定真值：种子用 toLocalIso(offsetDays) （:72-76，infra R2-00063）按 Date.now() 生成 ⇒ 画板取基准日 2026-10-26 09:41 换算： 订阅笔 createdAt=今日、有效期 今日 ~ +92 天 = 2027-01-26； 续费笔 −30 天 = 2026-09-26、有效期止 −1 天 = 2026-10-27； 退款笔 −60 天 = 2026-08-27 且无 periodStart/End ⇒ 有效期整行消失。 重跑画板若换日期，这三组日期必须随之重算（口径：相对当天，不是绝对日期）。
  • 在册不一致（照实况画，不修）： ① 页头返回件 ‹ 在本页是 --c-text-primary 深字，而 vip/promo-code 同位置是 --c-text-inverse 白字压金底； ② 选中筛选片金字 --c-gold 压 --c-gold-bg-tint ≈ 1.5:1（全站最低一档的选中态）； ③ 退款笔 originalAmount 与 amount 同为 1800 分 ⇒ 卡上出现「¥18.00 / 划 ¥18.00」； ④ 账单套餐名「季度会员 / 月度会员」与 vip/index 的「季卡 / 月卡」是两套中文，未共用 i18n key； ⑤ 加载失败无状态位（只 toast），与「空账」同屏。
  • BASE_PROBLEM（base 缺档 / 错档，本页按 scss 真值 1:1 落字面量）： --c-gold 错档（base #C9A36A vs scss:814 / tokens.scss:347 = #FFD700，hero 与选中片都依赖它）； 缺档 --c-accent-400(#F97316)、--c-gold-bg-tint(rgba(255,215,0,.18))、 --c-overlay-border-mid(.25)、--c-overlay-text-secondary(.85)、 --c-red-bg-tint(rgba(239,68,68,.1))、--c-romance-bg-tint(rgba(255,104,145,.1))、 --c-info-bg-tint(rgba(59,130,246,.1))、--c-secondary-blue-500(#4C6EF5，base 只有 400 档)。
  • 本页在 vip 分包、navigationStyle: custom：无原生导航栏、无 tabbar。
