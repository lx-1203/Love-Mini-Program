01

页面状态稿 · 9 屏

内容态 5 支 / 首屏空档 / 页面级空态 3 支

本页状态机有 9 态，来自模板分支 v-if="currentTopic"（内容态，内含 v-if="loading" / v-else-if="replies.length > 0" / v-else 空回复 / v-if="repliesHasMore" 加载更多 / v-if="reply.author.userId !== currentUserId" 打招呼钮） 与三条兄弟分支 v-else-if="!loading && !topicId"、 v-else-if="!loading && errorMessage"、v-else-if="!loading"。 页头由页面自绘（本页 navigationStyle 为 custom），返回是文字「返回」深玻璃胶囊。

三列等宽 · calc((100% - 20rpx)/3)
与同族 campus/topic-detail 的实测差异：两页是同一份 template 骨架 + 同一份 style 的复制体，结构基本相同； 逐条核下来差异 19 条——有意 5 条 / 漂移 12 条 / 待定 2 条（下面末三条是口径与登记说明，不算差异）。 本域视角，值一律取自 subpackages/circles/circles/topic-detail.vue 与 subpackages/campus/campus/topic-detail.vue 原文：
  • 【有意】本页无话题分类标签带；campus 顶部多一条 .topic-category-tag（CAMPUS_CATEGORY_MAP 六档，浅渐变底 brand 字 24rpx/600）。兴趣圈进入详情前已选定圈子，无分类轴。
  • 【有意】作者第二行：本页是 author.headline（恒渲染、nowrap+省略号）；campus 是 author.school（v-if，缺值整行不占位）。
  • 【有意】本页实名体系、无匿名；campus 作者名与回复名一律走 getDisplayName(isAnonymous, name)，匿名时替换成词条「匿名校友」，头像兜底字也随之取「匿」。
  • 【有意】「打个招呼」钮本页独有（跨域出口：跳私信 + 预填破冰文案 + ensureCertified("realname") 门槛）；campus 底栏的「匿名开关」本页独有（回复身份唯一出口）。两页底栏因此一栏两栏之差。
  • 【有意】回复分页机制：本页显式钮（repliesHasMore 由服务端 replyCount 判），campus 靠 @scrolltolower + 本地 repliesHasMore ref 估算，无钮。
  • 【漂移】评论区空态：本页是一句行内灰字（词条 circle.topicDetailEmptyReplies「暂无回复，快来抢沙发吧」），campus 换成 <EmptyState> 组件两行（「暂无回复」+「快来抢沙发吧」），图标 60px。同一句话两种组件、两种词格。campus 页里 .replies-empty 样式已无消费者（死样式）。
  • 【漂移】返回胶囊配色：本页 R10-L04-D06 改深玻璃底＋白字（8.4:1）；campus R10-L05-D07 改 25% 白胶囊＋深墨字。同一判点两条相反口径，全站导航带读法因此分叉。
  • 【漂移】返回钮热区：campus 补了 min-height:88rpx（R13-L05-D04），本页只有 padding ⇒ 实测热区约 34px，低于同族与自述的 44px 标准。
  • 【漂移】发送钮热区：campus 补 min-height:88rpx（R14-L05-D04 并点名「同条控件不许只修一半」），本页 .reply-btn 未补，仍是 18rpx padding 撑出的约 39px。
  • 【漂移】卡片底色：campus 三张卡 + 底栏在 R4-02525 统一改 --c-bg-container（深色模式自适应），本页仍写裸 --c-neutral-0；卡影也不同源（本页 --s-card-soft，campus 页内 0 2rpx 16rpx --c-black-shadow-xs）。深色模式下本页四块必掉档。
  • 【漂移】页头几何与色：本页底是 --c-gradient-brand（两档 mint），campus 页内自写三档 brand→brand-300→romance-300；本页上内边距 statusbar + 20px + --sp-6（≈76px），campus 是 statusbar + 24rpx（≈56px）⇒ 导航带差 20px，正文起始线不同。
  • 【漂移】字号：话题标题与导航标题本页走令牌 --fs-xl 15px，campus 硬写 34rpx 17px（既不同档又违 §1 令牌纪律）；作者头像兜底字本页 --fs-md 13px，campus --fs-xl 15px。
  • 【漂移】正文墨色：本页 --c-text-secondary #4A524E；campus 的局部变量 $text-secondary = var(--c-neutral-500) #6B7571（与它自己的 tertiary 同值）⇒ campus 话题正文与回复正文整体比本页淡一档，且两档在 campus 塌成一档。
  • 【漂移】配图网格：本页 gap 10rpx + 圆角 --r-md 6px + 外包一层 wrap；campus gap 12rpx + 圆角 --r-lg 10px、宽度直接给 img。同为三列 100px 高，圆角差 4px。
  • 【漂移】错误态兜底标题：本页 errorMessage || t('circle.topicDetailNotExist')，网络失败却写着「话题不存在或已被删除」；campus 兜底 storeErrors.campus.loadTopicDetailFailed「加载话题详情失败」。本页是文案性误导。
  • 【漂移】空态宿主写法：本页把 class="empty-state" 直接挂在 <EmptyState> 组件标签上（R10-L04-D04 判定可行），campus 在外面再包一层 <view class="empty-state">（R7-L05-D05 判定组件标签打不进样式）——两条注释对同一条 mp 编译机制的结论互相否定，必有一页是错的。F07–F09 画的是两种写法都应当落出的「页头以下垂直居中」终态，真正要复判的是本页 .empty-state{flex:1;align-items:stretch}（无 min-height:0）是否接得住高度。
  • 【漂移】缺参判定：本页 !loading && !topicId（读实时 ref），campus 用一次性 latch paramMissing；词条同源（storeErrors.*.topicIdInvalid「话题 ID 无效」），实现分叉。
  • 【待定】本页 .topic-content 挂 @longpress 长按举报（五档原因 + 补充描述），campus 无举报入口；内容安全入口按域分叉，倾向漏做而非有意。
  • 【待定】本页回复输入无 maxlength、无字数上限提示；campus 有 :maxlength="500" 与触顶提示行。微信 <input> 不写 maxlength 默认 140 字静默截断，本页因此会在 140 字处「打不进字且零反馈」。
  • 【口径】两页共用 formatDateTime(dateStr,"relative","zh-CN")，时间字一律「刚刚 / N 分钟前 / N 小时前 / N 天前」，画板按此写。
  • 【登记】本页在 circles 分包、navigationStyle custom、无原生导航栏，不画 tabbar；画了即退稿。演示人设取真名池（小满/周岚/阿辰/星辰），话题与回复正文逐字取自 stores/circle/mock-data.ts，未自造数据；本页无分数/百分比位，故无留空判点。
  • 【登记】帧即视口：F01 的回复列表在真机上超出 812px，画板按源码几何自然裁切（裁切说明只写题注、不写画面）；F04 的配图帧只放一条回复，为的是让三列网格与圆角落在同一屏内可判。
