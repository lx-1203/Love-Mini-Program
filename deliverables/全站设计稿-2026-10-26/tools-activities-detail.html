与实况的已知差异（画板不修，登记在此）：
  • 示意值，非真值：F04「58 人已报名」、F07「86 人已报名」是为撑出 v-if="showEnrollCount" 行位而填的示意数。 真值源是后端 ActivityDetailView.enrollmentCount，画板不接真值；示例活动屏（F06）该整行不渲染，符合 !isSample 约束。
  • 示意值，非真值：各屏的活动名、时间串、地点串、日期胶囊「11月8日」与介绍正文均为演示数据（真值来自后端字段）， 只有胶囊文案「报名中 / 已结束 / 音乐 / 综合 / 人已报名 / 活动介绍 / 立即报名 / 退出报名 / 分享 / 重试 / 示例活动 / 暂无活动介绍 / 活动详情」逐字取自 zh-CN.ts； F06 的新人礼遇标题/时间/地点/介绍四串逐字取自 activities.sample.newUserGift.*。
  • 源页私有色值已改最近登记令牌：--c-brand-900 #0B4A38（页头标题）→ --c-brand-800； --c-bg-brand #e8f8f0（状态胶囊 / 重试底）→ --c-brand-50； --c-badge-on-image-bg rgba(15,23,42,.7) → --c-text-primary 实底； --c-overlay-white-bg-tint rgba(255,255,255,.2)（返回圆底）→ --c-text-inverse； --c-primary 与 color-mix(brand 12%)（分类标签）→ --c-brand / --c-brand-50； --c-black-shadow-sm（操作栏上投影）→ base 壳层 .tabbar 同口径的 --c-border-light 0.5px 顶边； --card-radius 40rpx → --r-card。base 内无可用的「图上深底胶囊」档，故封面徽标用 --c-text-primary 实底 + --c-text-inverse 字。
  • SkeletonBlock 的 profile 变体里 .skeleton__cover 在本仓没有任何样式规则（只有 .shimmer），实际高度为 0 ⇒ F01 按实况不画封面骨架，只有「大圆 + 两行」卡和两块 80px 块。label 走 aria-label，画面不出现「加载中...」文字。
  • 页头无原生导航栏（子包页），由页面自绘绿带 + 44px 圆形返回；menuStyleVars 会把状态栏高度灌进 --statusbar，画板按 44px 计。
  • 本页在 tools 分包，不得出现 tabbar——画板若出现 tabbar 即为错。
  • 源码已登记 NEEDS-DATA：卡上「报名截止」列后端不下发（activityDate 是活动当天日期），故 F04/F07 的人数行只有日期胶囊、无截止日，画板不补。 日期胶囊文案取 activities.dateLabel「{month}月{day}日」，activityDateLabel 正则不匹配时整枚不渲染。
  • F07 活动状态为「已结束」，底部右位仍画「立即报名」——源模板 detail.vue:527 的右按钮只按 !isSignedUp 分叉， 不按 status 收敛，报名已截止的活动仍可点。这是结构事实，画板照画、不修，留待产品裁定。
