页面状态稿 · 7 屏

圈内只读 / 站外二选一 / mock 增强区 / 填写中 / 帖子模式 / 达上限 / 活动弹层

本页状态机有 7 屏，分支全部取自源码 v-if： v-if="circleId"（目标只读）与 v-else（发布到二选一）、 v-if="publishTarget === 'interest'"（兴趣分类宫格）、 v-if="useMock()"（话题标签区 + 喜爱开关，real 档整块消失）、 v-if="isPostMode"（关联活动区）、v-if="images.length < MAX_IMAGES"（加图瓷片）、 v-if="showActivityPicker"（活动弹层）。 页头无原生导航栏，返回是文字胶囊「返回」（circle.postTopicBack），且页头那颗「发布」已按 §3.14 撤除—— 只剩等宽占位块，全站唯一发布出口是底部主 CTA。帧即视口：超出 812px 的内容被裁掉，被裁掉什么写在题注里，不写进画面。

62×62 · 左封面 + 右标题/元信息
与同族「校园发话题页」（campus/campus/post-topic）的差异清单（两页共用同一计数常量，其余形态各走各的）：
  • 页头右端：本页 无发布钮——R11-L04-D10 按 §3.14「只保留一处发布出口」撤除页头胶囊，留 96rpx 等宽占位； 校园页顶栏右侧仍常驻「发布 / 发布中」白胶囊，与底部主 CTA 双出口并存。
  • 返回文案：本页 circle.postTopicBack =「返回」；校园页 campus.postTopic.cancel =「取消」。同一形态（白半透胶囊）两种文案。
  • 正文计数：两页同 0/1000（MAX_LENGTH = POST_MAX_LENGTH，2026-10-26 统一到 1000）。差异只在标题上限：本页 :maxlength="POST_TITLE_MAX_LENGTH" = 30，校园页硬写 maxlength="50"。
  • 配图上限：本页 MAX_IMAGES = 9（页内常量），格子内显示 N/9；校园页 UI_LIMITS.PHOTO_GALLERY_MAX = 6，计数移到分区标题右侧 N/6。
  • 卡片圆角：本页统一 --r-xl（24rpx=12px）；校园页按 R11-L05-D09 收成 --card-radius（40rpx=20px）。
  • 底部主 CTA：本页 --c-brand-800 实底（R10-L04-D10 收口）；校园页仍是 brand→brand-300 mint 渐变，禁用底取 --c-border-light。
  • 目标选择：本页有「发布到 校园圈/兴趣圈」+ 8 个兴趣分类；校园页无目标选择，改为 6 个话题分类（课程交流…校友动态）宫格。
  • 本页独有：话题标签多选（≤3）、喜爱开关、帖子模式关联活动 + 活动弹层——且标签区/喜爱区 v-if="useMock()"，real 档整块不渲染。校园页独有：未认证横幅（certGate === 'denied'）、TopicSelector 话题选择器、匿名发布开关。
与实况的已知差异 / base 缺档登记（画板不修，登记在此）：
  • base 未登记档位：本页源码用了四个 board-base.css 里没有的令牌，画板按真值以字面量落盘并逐条注明—— rgba(255,255,255,.25) = --c-overlay-white-bg-mid-strong（返回胶囊底）、 #F0FDF9 = --c-bg-brand-soft（关联活动虚线框底）、 rgba(0,0,0,.45) = --c-bg-overlay（弹层遮罩）、 0 1px 8px rgba(0,0,0,.04) = $card-soft-shadow（--c-black-shadow-xs）。 另 --c-neutral-400 未登记，其与 --c-text-placeholder 同值 #9AA39F，画板直接取后者。
  • 状态栏字色：pages.json 全局 navigationBarTextStyle: "black"，故画板用深色状态栏字； 页头文字本身也已按 R10-L04-D08 收成 --c-text-primary（白字压薄荷渐变只有 1.65:1）。
  • 标题占位继承 600 字重：本页 .title-input 未设 placeholder-style， 占位「话题标题」继承 600 字重（校园页已按 R12-L05-D06 收口为 400 + placeholder 色）。画板按各页源码实况分别落，不改源码。
  • 「发布到」只读态复用 label 样式：带 circleId 时圈名与「发布到」同用 .section-label（F01/F04/F06 可见）， 视觉上像两行同级标签，无独立只读样式。
  • 不捏造数据：本页无分数/共同点位；关联活动的标题/时间/地点取自 stores/activity.ts 的 mock 演示条目，未自创。
  • F06 的 1000/1000 是被测状态，不是文本长度反推：mp <textarea> 未开 auto-height ⇒ 定高 280rpx 内滚，画板只落首段可见文本（约 400 字）并把超出部分裁在框内，计数位表达的是「已达上限」这一状态。 真机上再按一个字符不会变成 1001——:maxlength 会先截断。
  • 本页在 circles 分包，无 tabbar——画板若出现 tabbar 即为错。
