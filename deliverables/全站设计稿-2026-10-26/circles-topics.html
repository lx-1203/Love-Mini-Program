页面状态稿 · 9 屏

回流 / 加载 / 错误 / 动态 / 作品墙 / 成员 / 活动 / 空态 / 吸顶

本页状态机有 9 态，来自 missingCircleContext（回流壳）→ loading && currentTopics.length===0（加载）/ errorMessage && currentTopics.length===0（错误）/ v-else 列表分支下 detailTab ∈ {feed, hot, works, members, activities} 与 listForTab.length===0（空态），以及 tabsPinned（深滚吸顶克隆）。 「精华」与「动态」结构相同、仅按 replyCount 降序，故不单列一屏，在 §02 页签态里体现。 页头无原生导航栏，导航控件压在封面上；帧即视口，超出 812px 的列表裁掉，裁切说明写在题注里。

与实况的已知差异 / 真值裁定（画板不修，登记在此）：
  • 计数类真值：封面「1.2w 人加入 · 486 条动态」的 memberCount=12000、topicCount=486，卡脚回复数 replyCount=46/23/12，均取自 stores/circle/mock-data.ts 的「摄影」圈种子数据（circle-photo）——即本页 mock 演示档实际渲染值，非画板编造。真实上线后由后端 CircleItem.memberCount / TopicItem.replyCount 提供同名字段。本页无「浏览量」字段，故不画浏览量。
  • 「等 N 位朋友已加入 + 头像组」整行不画：源码 R11-L04-D01 已撤销该行——后端 friendJoinedCount 是 memberCount/1000 估算的假数、无真相源。画板按源码实况，整行不出现。
  • 置顶圈规条仅 mock 演示档出现：pinnedNotice = useMock() ? t('circle.home.pinnedNotice') : ""（R11-L04-D03）。真实档恒空、整条不渲染。F04 画的是 mock 档，真实档进本页应无此条。
  • 作者头像为字符兜底：种子话题的 author.avatar 为空串，源码 v-else 走 initialOf(name) 渲成品牌渐变圆 + 首字（苏/阿/橙）。这是本页对该数据的真实渲染形态，非灰色占位块；成员 Tab 头像同源。
  • 分包页无 tabbar：本页在 circles 分包，画板不得出现底部五格 tabbar——出现的只有页面自绘的固定操作栏（加入 + FAB）。
  • 页头无原生导航栏：导航控件（返回 / 页名 / 写话题 / ···）压在封面上（R11-L04-D02），避让走 JS 实测 --statusbar。
  • 错误文案「网络异常，请稍后重试」为示意：errorMessage 由 store 运行时抛出，非本页 i18n 固定词条，画板取一句常见文案示意该状态形态。
