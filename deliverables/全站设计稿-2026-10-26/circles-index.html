与实况的已知差异 · 真值口径登记（画板不修，登记在此）：
  • 好友头像行的口径（本画板唯一的「数字类」判点，已逐层复核属实）： 列表页 index.vue:530 仍渲染该行；计数优先取后端字段 CircleView.friendJoinedCount（apps/api/.../discover/CircleController.java:194 下发）， 其真身是 apps/api/.../discover/RealCircleService.java:191-195 的 estimateFriendJoinedCount(memberCount) = clamp(round(memberCount/1000), 3, 99) （memberCount<=0 时返回 3；:181 处逐圈调用）， 是成员数的千分之一估算，与「我的好友里有谁加入了这个圈」无关。 三枚头像由公共池按圈 id 字符码取模拼出（见上），非真实用户。 real 档缺字段 ⇒ :325 返回 0 ⇒ 整行不渲染；mock 档无该字段 ⇒ :326 走 5+seed%8。 画板按 real 档公式回算：12000→12、8932→9、8123→8、6532→7、7240→7、4860→5。 理想图此处为 8 / 12 / 16 / 9 / 7 / 5，后端无该展示值的真值源（它不是任何字段的读数），画板按估算公式回算画、不照抄。 这一行是「装饰性社交证明」而非事实陈述，恢复真口径需后端补 viewer 为锚的好友-圈子关联统计（缺列已在 circle-home.vue:245-247 在册）。
  • 成员数 / 动态数取后端真值，不取理想图演示值：登记表通用规则第 0 条判据是「后端有没有真值源」—— memberCount 有（interest_circles 种子 V2026.08.15.0002：摄影 12000 / 旅行 8932 / 音乐 8123 / 运动 6532 / 美食 7240；天文 4860 与 mock 种子同值）， topicCount 有（RealCircleService 的 countTopicsByCircleIds 实算）。 理想图的 9,875 / 1.1w / 9,210 / 8,123 与 362 / 245 / 512 / 298 / 361 / 197 是 mockup 演示值，未照抄； 动态数按登记表第 11 行「2–6 随数据」取实况帧读数 6 / 4 / 4 / 4 / 5。
  • 天文圈的动态数未取到读数：实况两帧（兴趣圈列表-1-top.png / -2-bottom.png）都在视口下沿把该行裁掉， 画 2 条（同批新增圈各 2 条话题，reports/verify/2026-10-26/50-fidelity/cards.md 第 11 行），属「随数据」位、非真值锚。
  • 热门角标阈值两页不一致：本页 HOT_THRESHOLD = 8000（:235）， 主页 isHot 是 memberCount >= 10000（circle-home.vue:373）—— 同一圈子可能列表带角标、主页不带。按本页档画即摄影 / 旅行 / 音乐三张带角标，恰好与理想图三张带角标同数； 若照抄理想图的成员数（运动 1.1w、美食 9,210、天文 8,123 全 ≥8000）会变成六张全带，反成第三种差异。全站阈值归一不在本车道。
  • 实况帧过期项（§10，按源码画）：兴趣圈列表-1-top.png 的运动圈（6,532）带「热门」角标， 与源码阈值 8000 矛盾 ⇒ 该帧拍在阈值改动之前，本画板按源码判该卡不带角标；同帧美食圈读数 7,241 是运行期加入漂移，画种子值 7,240。这两帧需重拍。
  • 不画 tabbar、不画原生导航栏：本页在 circles 分包、navigationStyle: custom， 页头由页面自绘（#header 插槽 + AppShell sticky 层）。 理想图底部那条五签 tabbar 是 mockup 自带件，真机此页没有 ⇒ 不照搬。页头与 chips 同处一条吸顶层（R2b-L04-D16）。
  • 胶囊避让：搜索钮 margin-right: calc(var(--capsule-right) + 87px)（:946）为微信胶囊预留， 真机放大镜右缘紧贴胶囊左缘；画板按理想图把它放在页头最右端，全站画板统一不画胶囊。
  • 文案口径：统计行不用词条 circle.cardStats（其值「{members} 人 · {posts} 条动态」缺「加入」二字）， 改用 circle.memberUnit「人加入」+ circle.topicUnit「条动态」拼（:519-525 记的裁定）； 「+ 加入」的加号在展示层剥掉（:366-374）。筛选 ActionSheet 三档文案「全部圈子 / 只看已加入 / 按人数排序」 是 :259 的硬编码中文，未走 i18n——全站口径问题，登记不修。
  • BASE_PROBLEM：assets/board-base.css 缺源码在用的两档—— --c-text-error-dark（#991b1b，热门角标文字真值档，R10-L03-D16 为过 10px 小字 4.5:1 才选它）与 --c-overlay-border-light（rgba(255,255,255,.18)）。本页角标文字暂落已登记的最近档 --c-romance-700（#CC4A5F）。
