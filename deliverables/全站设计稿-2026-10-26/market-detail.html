页面状态稿 · 5 屏

封存 / 加载中 / 加载失败 / 商品不存在 / 商品详情

本页状态机有 5 态，来自 market/detail/index.vue:306-403 的 v-if="commerceSealed" → v-else-if="loading" → v-else-if="error" → v-else-if="notFound" → v-else-if="product" （互斥链，五者皆为假时模板整体空白——MP-R1-次要24-1 的 watch(commerceSealed) 就是为堵这条洞补的）。 页头为白底自绘导航栏（navigationStyle: custom，无原生栏、无 tabbar）。 F01 是当前默认态：commerce.enabled 缺省 false ⇒ 缺 key 即封存（app-config.ts:67）。 F02–F05 画的是开关开启态。帧即视口，超出 812px 裁掉，裁切只写在题注里。

60px · 非素材缺口
与实况的已知差异 + 数值口径（画板不修，登记在此）：
  • 默认态是封存，画板 F02–F05 画的是开关开启态。判据在 market/detail/index.vue:33 commerceSealed = !appConfig.isCommerceOn()，实装于 stores/app-config.ts:64-77： switches["commerce.enabled"] !== true 即封存——缺 key 与 false 同义（缺省封存，与全站其它开关「缺失默认开放」相反，ADR-2）。 mock 后端不下发 commerce.* ⇒ 今天巡检到的就是 F01。本页不因封存而重定向， 封存卡是模板内的一个真实渲染分支，故画进 F01；F02–F05 需 commerce.enabled=true 才可达。
  • 解封竞态补偿在册：:278-282 的 watch(commerceSealed) 保证配置异步拉回后补拉商品； 回归测试若删掉它，五支 v-if 全假 ⇒ 整页空白（这条是本基准唯一的「结构不变量」屏）。
  • 价格 ¥99 / 原价 ¥129 / 已售 56 / 库存 200 = mock 种子（:102-113 mockCatalog id=1， 与 shop/index.vue:141-204 的本地源同源）。useMock() 为假时走 GET /products/{id}，价格/销量/库存以 admin 商品管理维护的后端真值为准 ⇒ 画板数字只是 mock 演示种子， 不得被当成后端真值验收。分类标签「活动票务」= shop.categoryTicket。
  • 「立即购买」不收款：handleBuyNow（:252-259）只发 toast shop.buyUnavailable 「支付功能暂未开放」；封存态则发 commerce.sealedToast。开关开启 ≠ 支付可用，两条口径分开看。
  • 栈底兜底：无上一页时 goBack 走 switchTab /pages/home/index（:247）， 与 wallet 的 profile 兜底不同域不同目标——本页画板不表现该跳转。
  • BASE_PROBLEM：本页不需要补档——detail 用到的令牌在 board-base.css 里全部已登记 （含 --c-neutral-shadow-xs / --c-brand-border-tint-stronger / --c-overlay-strong）， 故本页 :root 无镜像声明。同域另两页才需要补：market/wallet 缺 --c-brand-bg-tint-strong（scss:880 真值 rgba(61,201,148,.12)，其 .vue 兜底写 .35 属过期字面量， 按已知机制 §2 不采信）与 --r-2xl（两个登记处均无定义，运行时靠 32rpx 兜底）； vip 三页的 --c-gold 错档见各自画板 §04。本页封存卡走已登记的 --r-xxl 16px，不受断引用影响。
  • 本页在 market 分包、navigationStyle: custom：无原生导航栏、无 tabbar——画板若出现 tabbar 即为错。
