页面状态稿 · 7 屏

三态页级 + 四态内容级

本页状态机有 7 屏，逐条来自源码条件表达式： 页级 pageState === 'loading'（:346）/ pageState === 'error'（:352）/ v-else 内容区（:365）；内容级 form.enabled（:387，联动 statusText = form.value.enabled ? t("dnd.statusOn") : t("dnd.statusOff") :306 与其 status-row__value--on 字色类 :397）、form.repeatMode === 'CUSTOM'（:479， 决定自定义星期整块 v-if，并连带改变末条单选的 radio-row--no-border :460）、 isSaving（:523 按钮降透明 + :529 文案切「处理中...」）、 validateForm() 返回非空（:245 → :220/:224 toast）。 页头三态常驻（在 v-if 之外），帧即视口，超 812px 由画框裁掉。
02

组件状态规范

每类交互件的全状态枚举，缺一不可

本页四类控件互相联动：总开关 → 状态行文案与字色；重复方式 → 星期块是否出现 + 单选末行是否去边线； 两个时段值 → 保存时的合法性。联动的每一环都必须在帧上看得见。

04

素材依赖

本页零图片素材：全部控件由几何 + 令牌构成

周一周一
控件件 0 素材 / 图标 0 枚

本页模板里没有一处 <image>：开关是原生 <switch>、 单选指示器与星期芯片是纯 CSS 圆与方块、行末「›」是文字字形（.time-row__arrow :839）， 返回键「‹」同样是文字（.nav-bar__back-icon :593）。⇒ 素材池 59 件引用 0 件，无 NEED_ASSET。

演示值仅 22:00 / 08:00（源码 form 初值 :54-55）与周一/三/六的选中组合，无编造数值
与实况的已知差异（画板不修，登记在此）：
  • 总开关不做门控。模板中「免打扰时段 / 重复方式 / 紧急消息穿透」三块 都没有 v-if="form.enabled" 或 disabled，关闭态下照样可改可点； 唯一的联动是「当前状态」行的文案与字色（:393-399 + :306）。画板按实况画，不替产品补门控。
  • 本页 .nav-bar 横向内衬是裸 24rpx=12px，而 .section 已收 --page-padding=16px （:567 / :679）⇒ 返回键比下方卡群左缘外突 4px。同域 settings/index.vue:737 已把这条收口，本页未跟改。
  • 两处分组标题被删（R8-L11-D06 / R9-L11-D05）：总开关组与紧急穿透组不再重复出现同名 section__title，自定义星期组也无标题 ⇒ 帧上「开启免打扰」「紧急消息仍会通知…」各只出现一次。 若回归成重复两遍，即为退稿。
  • 错误态正文是运行时 error.message（:113），无固定串；画板取兜底档 common.networkError「网络错误」，并在题注标明，不当作文案真值。
  • 时段行展开后是微信系统时间滚轮，不由本页绘制 ⇒ 不画、不占屏。
  • 本页在 profile-extra 分包，无 tabbar——画板若出现 tabbar 即为错。
