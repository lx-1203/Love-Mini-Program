01

页面状态稿 · 10 屏

内容态 6 支 / 首屏空档 / 页面级空态 3 支

本页状态机有 10 态，来自模板分支 v-if="currentTopic"（内含 v-if="loading" / v-else-if="replies.length > 0" / v-else 空回复、 v-if="currentTopic.author.school" 学校行、v-if="images && images.length > 0" 配图、 getDisplayName(isAnonymous, name) 匿名换名、v-if="isReplyAtLimit" 触顶提示、 anonymous-toggle--active）与三条兄弟分支 v-else-if="!loading && paramMissing"、v-else-if="!loading && errorMessage"、 v-else-if="!loading"。页头由页面自绘（navigationStyle custom），返回是文字「返回」白胶囊。

三列等宽 · calc((100% - 24rpx)/3)
与同族 circles/topic-detail 的实测差异：两页是同一份 template 骨架 + 同一份 style 的复制体，结构基本相同； 逐条核下来差异 19 条——有意 5 条 / 漂移 12 条 / 待定 2 条。本域视角，值取自 subpackages/campus/campus/topic-detail.vue 与 subpackages/circles/circles/topic-detail.vue 原文：
  • 【有意】本页顶部多一条分类标签 .topic-category-tag（CAMPUS_CATEGORY_MAP 六档，浅渐变底 + brand 字 12px/600）；circles 无分类轴。
  • 【有意】作者身份字段两页不同：本页第二行是 author.school（v-if，缺值整行不占位，见 F02），且作者名与回复名一律走 getDisplayName(isAnonymous, name)，匿名时替换成词条「匿名校友」、头像兜底字随之取「匿」；circles 第二行是 author.headline（恒渲染、nowrap + 省略号），且是实名体系、无此函数。
  • 【有意】底栏三件（输入 / 匿名开关 / 发送），匿名开关是回复身份唯一出口；circles 底栏只有两件。
  • 【有意】回复分页靠 @scrolltolower + 本地 repliesHasMore ref 估算，无显式钮；circles 是「加载更多回复」钮 + isLoadingMoreReplies 文案态，且 .detail-page 为此必须定高（本页 height:100%;overflow:hidden，circles 是 min-height:100vh + min-height:0）。
  • 【有意】回复项右侧没有「打个招呼」钮（circles 独有的跨域私信出口，点击先过 ensureCertified("realname")）；校园域互动不出口到私信。
  • 【漂移】评论区空态：本页是 <EmptyState> 组件两行（60px 图标 + 「暂无回复」+「快来抢沙发吧」），circles 是一句行内灰字（词条整句「暂无回复，快来抢沙发吧」）。同一句话两种组件、两种词格；且本页 .replies-empty / .replies-empty__text 样式已无消费者（改造后未删的死样式）。
  • 【漂移】返回胶囊配色：本页 R10-L05-D07 用 25% 白胶囊 + 深墨字；circles R10-L04-D06 用深玻璃底 + 白字。同一判点两条相反口径，全站导航带读法因此分叉。
  • 【漂移】卡片底色与影：本页三张卡 + 底栏在 R4-02525 统一改 --c-bg-container（深色模式自适应），circles 仍写裸 --c-neutral-0；卡影本页是页内 $card-soft-shadow（0 2rpx 16rpx 单段），circles 用登记的 --s-card-soft（双段合成）。深色模式下 circles 必掉档。
  • 【漂移】页头几何与色：本页底是页内自写三档 brand→brand-300→romance-300，circles 用 --c-gradient-brand（两档纯 mint）；本页上内边距 statusbar + 24rpx（≈56px），circles 是 statusbar + 20px + --sp-6（≈76px）⇒ 导航带差 20px，正文起始线不同（本页 112px / circles 122px）。
  • 【漂移】字号：本页导航标题与话题标题源码硬写 34rpx（17px，无 --fs-* 档，违 §1 令牌纪律），circles 走 --fs-xl 15px；作者头像兜底字本页 15px，circles 13px。
  • 【漂移】正文墨色：本页局部变量 $text-secondary = var(--c-neutral-500) #6B7571，与它自己的 tertiary 同值 ⇒ 话题正文与回复正文比 circles 淡一档，且两档在本页塌成一档。同族还有发送钮前景 --c-text-inverse（.95 白）vs circles --c-neutral-0（纯白）、禁用底 --c-neutral-200 vs --c-border-default（同值异名）。
  • 【漂移】配图网格：本页 gap 12rpx + 圆角 --r-lg 10px、宽度直接给 img；circles gap 10rpx + 圆角 --r-md 6px + 外包一层 wrap。同为三列 100px 高，圆角差 4px。判空条件也不同（本页 images && images.length > 0，circles 只写 images.length > 0，字段缺失时 circles 抛错）。
  • 【漂移】返回钮热区：本页 .detail-header__back 补了 min-height:88rpx（R13-L05-D04，帧上 44px），circles 只有 padding（≈34px），低于同族与自述的 44px 标准。
  • 【漂移】发送钮热区：本页 .reply-btn 补了 min-height:88rpx（R14-L05-D04，明写「同条控件不许只修一半」），circles 未补（≈39px）。同批可达性修复只落在本域。
  • 【漂移】错误态兜底标题：本页 errorMessage || t('storeErrors.campus.loadTopicDetailFailed')「加载话题详情失败」；circles 兜底成「话题不存在或已被删除」，把网络失败说成内容被删。本页口径是对的。
  • 【漂移】空态宿主写法：本页在 <EmptyState> 外面包一层 view.empty-state（注释判定组件标签打不进页面样式），circles 直接把 class 挂在组件标签上（注释判定可行）——两条注释对同一条 mp 编译机制的结论互相否定，必有一页是错的。本页 .empty-state 取 flex:1 1 auto; min-height:0; align-items:center，circles 取 flex:1; align-items:stretch。
  • 【漂移】缺参判定：本页 paramMissing 一次性 latch，circles 读实时 !topicId；词条同源（「话题 ID 无效」），实现分叉。
  • 【待定】本页有 :maxlength="500" + 触顶提示行，circles 两者皆无（微信 <input> 不写 maxlength 默认 140 字静默截断）。字数上限与提示是否全站统一，需产品定性；差异本身是同步缺失。
  • 【待定】本页无举报入口（circles 有长按举报五档原因）；校园域是实名 + 认证私域不等于免举报，倾向漏做。
  • 【口径】两页共用 formatDateTime(dateStr,"relative","zh-CN")，时间字一律「刚刚 / N 分钟前 / N 小时前 / N 天前」。
  • 【登记】本页在 campus 分包、navigationStyle custom、无原生导航栏，不画 tabbar；画了即退稿。演示人设取真名池（阿辰/周岚/小满/星辰/小溪），学校用真校名（广州大学），话题与回复正文逐字取自 stores/campus/mock-data.ts；本页无分数/百分比位，故无留空判点。十屏均未触达 812px 裁切线（每屏只放该态必需的最少回复条数，保证判点同屏可读）；若后续把条数加满，超出部分按「帧即视口」裁切，裁切说明只写题注、不写画面。
