路由 subpackages/profile-extra/feedback/history。 它是反馈域的另一半：提交页 subpackages/support/feedback/index 负责写入与摘要，本页负责按类型筛选 + 点开看详情，两页共用 feedbackStore.submissions。 页头是一行式（返回圆钮与标题同排，走 AppShell 的 #header 槽，R11-L11-D14）， 与同域其它页的两行式页头不同档。本页状态机有 7 个可见态，逐屏画全作为该页验收基准。

01

页面状态稿 · 7 屏

列表 / 展开详情 / 含附件展开 / 详情加载中 / 筛选空态 / 错误态 / 附件预览

本页状态机有 7 态，来自这些实际分支： ① v-if="errorMessage" 的错误卡（整块列表被替掉）； ② v-else-if="filteredSubmissions.length === 0" 的 EmptyState（本页传 description，两句都在）； ③ v-else 的记录列表； ④ v-if="expandedId === item.id" 的展开详情区，其内再分 v-if="detailLoading[item.id]"（spinner）与 v-else-if="detailCache[item.id]"（内容）； ⑤ 详情内 v-if="(detailCache[id]?.attachments?.length ?? 0) > 0 的附件段与 v-if="detailCache[id]?.latestReplyContent" 的回复段； ⑥ 行内三元 expandedId === item.id ? common.collapse : feedback.historyViewDetail（「收起」/「查看详情」）； ⑦ handleAttachmentTap() → uni.previewImage 的全屏系统层。 筛选 chip 的 activeFilter 与深链 ?id= 的自动展开都并入下面对应屏； 帧即视口，被裁掉的区间只写题注 .d，不写进画面。

与实况的已知差异（画板不修，登记在此）：
  • 反馈两页的衔接（本域口径）：入口两个——提交页 goHistory()（navigateTo，跨分包 support → profile-extra，不带参数 ⇒ 落在 F01 列表态） 与提交页记录行 goDetail(id)（带 ?id= ⇒ 300ms 后自动展开，落在 F02/F03 态）。 出口一个——本页返回件 navigateBack 回提交页（栈与表单值保留），失败才 switchTab「我的」→ reLaunch 首页。 两页共用 feedbackStore.submissions：提交页新写入的记录本页立刻可见，反之本页 loadList() 成功后会清空详情缓存（infra R2-00103）。
  • 页头副标题是硬编码中文常量（缺陷）：HISTORY_SUBTITLE = "按类型筛选，点开记录查看详情" 直接写在 <script> 里， 既给 AppShell :subtitle 又给自绘 header 用，未走 i18n ⇒ 英文环境下整页其余文案翻成英文、这一句仍是中文。画板按实况照画，不改源码。
  • 详情加载失败会把整块列表换成错误卡（缺陷）：v-if="errorMessage" 排在空态与列表之前，且 toggleExpand 的 catch 里同时 expandedId = null ⇒ 用户点开某条记录失败后，既看不到列表也看不到展开行，只得到一句不带 id 的错误文案 + 一个「重试」（重试走的是列表 loadList()，不是重拉详情）。画板如实照画。
  • 卡标题与页头标题同为 feedback.historyTitle「反馈历史」，同屏出现两次；提交页里同一 key 也用作第二张卡标题。
  • 返回件与标题同排的一行式页头（R11-L11-D14）与全站多数页的两行式（返回胶囊独占一行）不同档——本画板按本页源码实际形态画，不代表全站口径。
  • 演示数据口径：两条记录逐字取 services/mocks/fixtures.ts 预置（标题/摘要来自 mockData.submissions.title1|2 / reply1|2， status 分别写死 processing / reviewed，submittedAt 为 ISO 串），时间显示按 utils/time 'full' 预设算成 YYYY-MM-DD HH:mm； F03 的「已提交 + 处理队列」行取 createSubmission 的写死值（status:"submitted" + mockData.submissions.queueReply），提交时刻取画板时钟 9:41。 本页无任何分数/百分比位，故无「真值位留空」项。
  • 本页在 profile-extra 分包，无 tabbar、无原生导航栏（AppShell 传 :show-tab-bar="false"）；画板若出现 tabbar 即为错。
  • AppShell 的 fixed 默认 true（R8-L07-D15）⇒ 页头吸顶、背景 --c-bg-page；本页未显式传该 prop，画板按默认档画吸顶带。
  • 不入静态画板的时序/动效项：深链自动展开的 300ms 定时器（onUnmounted 清理）、spinner 旋转、press-feedback 缩放、previewImage 的滑动切换。
