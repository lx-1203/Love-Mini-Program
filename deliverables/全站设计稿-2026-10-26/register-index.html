A. 旧画板有、现源码无（按实况重画时已删除，不得再画回）：
  • 「四要素」主链路版式：旧稿 01–06 屏只有手机号/验证码/密码/确认四行，昵称+生日被单独关在第 07 屏「契约对齐变体」。现源码两段（card__cap--second「基础身份」）无条件常渲染、formComplete 亦要求昵称与生日 ⇒ 旧稿 §01 下方那块「方案 A / 方案 B 待拍板」的 note 已由代码选边（方案 B），07 屏作为「变体」的语义已失效，本画板把它并回所有屏。
  • 字段整体压暗：旧 04 屏把卡片压到 opacity .86、四个字段挂 .field--off（55%）。现源码无 .field--off 类，提交中只有 <input :disabled>（原生置灰）+ 验证码按钮 .55 + 主按钮 .72 ⇒ F06 按源码画，字段视觉不变。
  • 勾选框红框 + 光环：旧 03 屏 .chk--err 画了红框。现源码未勾选点注册只有「协议文字转红 + 方框抖动」；agree--error 类在模板有绑定、样式块内无定义（死类），方框不变红。
  • 行内成功文案「验证码已发送至 138****8888，请注意查收」（旧 02 屏的绿色 err--ok 行）：现源码成功提示只走 uni.showToast，页面不渲染成功态行内件；验证码行只有 error 一种行内文案。
  • 强度条副文「密码强度 强 / 字母 + 数字」：现源码标签只有单字「弱/中/强」，且整条 v-if="password"。
  • 安全说明「🔒 密码加密传输 · 验证码 5 分钟内有效 · 不向他人展示」：现源码 .safety-note 无图标，文案换成「注册即代表你已满 18 周岁；信息仅用于校园身份核验，严格保密」。
  • 协议行第二句「并知悉平台实名认证与未成年人保护规则」：现源码协议文本止于《隐私政策》。
  • 底部「遇到问题？联系客服」出口（旧 06 屏）：现源码没有这条出口，只有「已有账号？去登录」。
  • 返回钮在 44px 导航带内 + 眉题「Xunmi · Campus」：现源码返回在 hero 内（左 16 / 上 statusbar+44），眉题为全大写「XUNMI · CAMPUS」（首字母大写形式已废）。
  • 「整页压进 812px 视口」的画法：旧稿七屏都把主按钮、协议行画在同一帧内。现源码六字段版式整页高 1034px（默认态，本画板同几何渲染实测），主按钮绝对位置在 812px 视口之外 ⇒ 本画板 F04–F07 明确按下滚 235px 的视口拍，并在题注标注。
B. 现源码有、旧画板无（新增验收点）：
  • 每行可见 label（手机号/短信验证码/设置密码/确认密码/昵称/出生日期，R11-L01-D05）：字段名不再只靠 placeholder 承载。
  • 分组标题带 1px 分隔线：.card__cap「账号信息」+ .card__cap--second「基础身份」。
  • 出生日期 = picker mode="date"（:end="today"）＋行内右挂「需满 18 周岁」hint；未选时文字取 --c-text-placeholder（与输入框占位已提到 tertiary 的口径不一致，本页唯一残留低对比占位，登记不修）。
  • 昵称/生日两条新校验分支：请输入昵称 / 昵称最多 20 字 / 昵称需为 1-20 字 / 请选择出生日期 / 出生日期需已满 18 周岁。
  • formComplete 不含成年判定：只查 !!birthDate，不跑 isAdult ⇒ 填了未成年生日时主按钮已是可用态、错误只在点下去才出现（F04 即画这一真实组合）。设计规范与旧稿都未覆盖此态。
  • 验证码 mockCode Toast：isDev || isMockMode() 下文案为「验证码已发送（模拟：{code}）」；真实构建只发脱敏手机号版。
  • 注册通道被后台关闭（B6）：isRegisterOpen=false 时 Toast「注册功能暂未开放」+ 800ms 退登录页；纯 Toast 态，页面无视觉变化，故不占屏（旧稿无此态）。
  • 失败按 error.message 关键字分支六类（已注册 / 验证码 / 未满 18 / 手机号格式 / 密码长度 / 昵称长度）+ 5xx「服务暂时不可用」+ 无 AppApiError 走网络异常；旧稿只画了「已注册」一种。
  • 88rpx 透明热区层（返回钮 / 清空 / 两只眼睛 / 勾选框，MP-011）：不可见于像素，但属结构验收点。
  • 协议版本随注册落库：fetchAgreedLegalVersion()（失败回退 '1.0.0'）；旧稿无此链路。
  • 主按钮 loading 文案「注 册 中」（全角空格分隔），与 idle 的「注 册」同口径；旧稿写的是「注册中…」。
  • 强度「中」文案色实取 --c-warning #F59E0B：源码写的是 var(--c-warning, #B87400)，令牌已登记 ⇒ fallback 永不生效。设计规范 §5.3 要求的 #B87400（保对比度）在现源码里没有落地（11px 字压白卡约 2.1:1）。
C. 本画板自身的口径说明：
  • 演示数据（138 8888 8888 / 582914 / 小满 · 周岚 · 阿辰 · 星辰 / 2004-03-18）为人设真名池与手机号格式化样例，不含任何分数类位——本页无合拍度/匹配度/共同点，故无留空位。
  • Toast 为 uni.showToast 系统件（非页面 DOM），不入 §01 帧，只在 §02 枚举——旧稿把黑条 Toast 画在帧内，现按「帧只装页面 DOM」口径移除，避免把不保证复现的系统层写进像素基准。
  • 抖动（shake-x 4px×2 / 400ms）、按压（scale .98）、进页淡入是时序态，静帧不可见，一律不画。
  • 本页在主包但不是 Tab 页（pages/register/index），navigationStyle:custom 无原生导航栏，页头由页面自绘 ⇒ 画 tabbar = 退稿。
  • BASE_PROBLEM 候选（不是 base 坏了，是令牌缺口）：① 主标 52rpx 无 --fs-* 对应档（画板按源码字面量 26px 画）；② focus/error 光环只存在于 base 的 .input--focus/.input--err 规则里，未单独出令牌。
