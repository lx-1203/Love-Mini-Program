描边 currentColor · 1.7 · 尺寸写在宿主节点
与实况的已知差异 · 令牌改写（画板不修，登记在此）：
  • 私有色值改写：--c-neutral-50 #f7f8fa（搜索胶囊 / 发帖输入 / 评论预览 / 已关注 chip）→ --c-bg-surface；--c-neutral-100 #eef1f6（外校胶囊描边 · 发帖条上边线）→ --c-border-light；--c-neutral-200（加载环轨道）→ --c-border-default；--c-neutral-0（白字）→ --c-text-inverse；--c-bg-brand → --c-brand-50；--c-bg-brand-soft #f0fdf9 → --c-brand-50；页底 #ffffff（源 R16 硬写字面量）→ --c-bg-container。待裁决：中性灰族与品牌浅底族在本页高度重叠，是 base 少一档 --c-neutral-* 造成的，不在本页改。
  • 渐变与阴影改写：--c-gradient-brand → linear-gradient(135deg, --c-brand, --c-brand-400)；--c-gradient-brand-soft → linear-gradient(180deg, --c-brand-50, --c-bg-container)（2026-10-27 令牌断引用收口把同一组合登记为 --c-gradient-brand-soft，色标停在 60% 与源码一致，画板已改回直接引用该档）；--c-romance-400（banner 渐变终点）→ --c-romance-300；--c-error-bg-solid / --c-error-border-tint（精选话题失败条）→ --c-romance-50 / --c-romance-300；--c-overlay-mid / --c-overlay-text-secondary（热门话题压字）→ --c-text-primary 渐隐 + --c-text-inverse；发帖条 0 -8rpx 24rpx rgba(0,0,0,.08) → --s-sm；--s-md / --s-brand-lg / --btn-height-md / --sp-14 无登记档，分别并到 --s-card-soft / --s-brand / 48px / --sp-10。
  • 频道 Tab 图标：真机是彩色 SVG 素材（cfg.icon）+ 整枚 opacity .55 区分选中；画板用描边图标 + --c-text-tertiary / --c-brand-500 两档上色。色彩语义差异（灰族 vs 品牌族）留给全站图标口径裁决，不在本页发明第二套。
  • 错误态图标语义不符：ErrorState type="network" 的图取 ICONS_COMMON.SEARCH（一枚放大镜），与「搜索无结果」撞语义；本画板按实况忠实照画（F04 / §02），不在设计稿里替它改。
  • 零图帖仍占位：PostCard 的 v-else 分支给无图帖渲染 180rpx 高的 POST_PLACEHOLDER 灰条（F08 第一张卡即此态）。这是实况行为，不是画板自造；是否该留由产品裁定，画板只登记。
  • 无原生导航栏：分包页由页面自绘页头（标题「圈子」+ 副标题 + 搜索胶囊 + 频道 Tab），状态栏带用 --statusbar 避让；本页在 village 分包，画 tabbar 即为错（源码内仅存「同步自定义 TabBar」的空注释，无实际 TabBar 渲染）。注意：路由常量 ROUTES.TAB.VILLAGE 说明该页在真机是 Tab 主页之一，与「分包页不得画 tabbar」的画板口径冲突，属全站口径问题，登记不判。
  • 页头右侧 119px 空带：源 padding-right: calc(var(--capsule-right) + 112px) 为微信胶囊避让；胶囊是系统件，画板不画，空带照留。
  • 「圈子频道」不含 tag-posts：话题胶囊 open-tag 跳 subpackages/village/village/tag-posts，属另一页，本画板不展开；同理每日一问、活动详情、发帖页各为独立路由。
  • 示意值清单（非真值，需真机数据替换）：① 帖子正文与标题（小满/周岚/阿辰/星辰/小溪五条，按校园动态口气自写，作者名用真名池、校名用真校名）；② 评论预览文案与评论人；③ 点赞/评论/收藏计数（18 / 9 / 7 / 4 / 3 / 2 / 1）与相对时间（刚刚 / 5 分钟前 / 1 小时前 / 2 小时前，走 formatRelativeTime 口径）；④ 作者 meta（年龄 · 城市 · 学历，取 educationLabels 真词）与签名行（「中文系大三，爱写信」「篮球队常驻替补」）；⑤ 活动卡 description 两句、置顶展开态的公告标题与摘要；⑥ 精选话题的标题与正文取自 stores/circle/mock-data.ts 演示数据（作者名换用真名池），回复数 45 / 19 同源；⑦ 热门话题四宫格的渐变占位色（源第 4 组是无档蓝 #60A5FA→#93C5FD，画板改用 --c-status-info→--c-brand-300，其余三组按源 designTokens 同档）。已核为真值不属示意：频道名 / 发帖条占位 / 空态与错误文案 / 认证门文案 / 每日一问与 banner 文案 / 登录门全部文案（逐字 i18n/locales/zh-CN.ts）、兴趣八类名（circle.cat*）、热门话题五条 tagName 与浏览量 12800/9600/8200/7400/5300（HotTopicsSection.vue mock 常量）、活动两条标题/时间/地点/报名数 23 与 12（stores/village/mock-data.ts）、F09 帖「今晚电影社放映《你的名字》，现场报名 ing！」与其评论「带我一个！正好周末没安排」（同源 mock 帖 post-32）。
