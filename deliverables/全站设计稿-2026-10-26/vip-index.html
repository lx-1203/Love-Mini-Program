--fs-7xl 28px / weight 300 · 非素材缺口
与实况的已知差异 + 数值口径（画板不修，登记在此）：
  • 当前默认态是「重定向」，画板画的是开关开启态。判据不是后端商业化开关，而是前端常量： config/feature-flags.ts:40 membershipEnabled: false（注释「会员先不上线」）。 三页各自在 onLoad 拦截：本页 vip/index.vue:45（membershipDisabled） → :52-58 guardMembershipDisabled() 弹 toast「会员功能暂未开放」→ :60-69 navigateBack()，无栈时 switchTab(ROUTES.TAB.PROFILE)； vip/promo-code.vue:33-42、vip/bills.vue:36-45 同写法。 ⇒ 今天这三页不可停留；F01–F04 只有在把 membershipEnabled 改 true（前端发版，非后台开关）后才可达。 与 market 三页的 appConfig.isCommerceOn()（后端下发 commerce.*、封存在页内渲染白卡）是两套互不相干的闸， 巡检时把两者混记为「封存态转发」会误读基准。
  • 本页模板没有封存分支：flag=false 时页面仍会完整渲染一帧再被弹走（F05 就是那一帧）， 表现为套餐卡 opacity .45、开关禁用、主钮禁用 + toast。 验收 F05 的判据是「禁用类挂上了」，不是「内容不见了」。
  • 价格 18 / 48 / 158 与原价 28 / 84 / 336、日均 0.6 / 0.53 / 0.43 元/天 = 前端静态配置 （config/vip-plans.ts:54-93；该文件 R2-00058/R2-00134 注释自陈 「前端静态价格，需与后端订单价格一致，后端下发配置后应移除」）。 不是后端真值、也不是 mock 种子——real 下单走 POST /vip/orders {planId}， 金额由服务端按同一档位定价；画板数字口径标为「前端配置真值」。
  • 「下次扣费日期：2026-11-25」= mock 派生值：stores/vip-auto-renew.ts:78-88 首拉返回 enabled:false, nextBillingAt:now+30d，开启分支 :118-127 同给 now+30d； 页面按 YYYY-MM-DD 格式化（:394-406）。画板取本基准日 2026-10-26 + 30 天 = 2026-11-25， 真环境以后端 nextBillingAt 为准。
  • 权益六条的「2 倍 / 5 套 / 3 次」是 i18n 文案里的产品承诺（vip.benefit*Desc）， 不是实测数值；按 §3.3 不新增任何分数/百分比，画板逐字照 key 取，不改写。
  • 在册可达性问题（照实况画，不修）：① 选中套餐卡把 --c-gold #FFD700 字压在 rgba(201,163,106,.3)→rgba(249,115,22,.75) 橙金渐变上（:933-937 只换底不换字色）； ② 皇冠图标的 color:--c-warning 声明在 <image> 节点上，对位图/独立 SVG 素材不生效； ③ 底栏「应付」说明行用 rgba(255,255,255,.7) 压 #1A1F26 = 12px 小字，比值 10.4:1 达标， 但权益卡副题 rgba(255,255,255,.6) 压 rgba(255,255,255,.08) 叠暗底 ≈ 8.2:1， 单行省略后信息量再降——这三处属页面车道，不在画板修。
  • BASE_PROBLEM（base 缺档 / 错档，本页按 scss 真值 1:1 落字面量）： ① 错档一条：base 的 --c-gold 登记为 #C9A36A，而两个登记处 （theme/design-variables.scss:814 与 styles/tokens.scss:347）逐字都是 #FFD700； #C9A36A 是 $vip-from（scss:46）⇒ 谁用 base 的 --c-gold 画 VIP 页都会偏成土金。 ② 缺档：--c-neutral-800(#1A1F26)、--c-accent-400(#F97316)、 --c-accent-bg-tint(rgba(249,115,22,.75))、--c-text-vip-dark(#5D4E37)、 --c-vip-border-tint(rgba(201,163,106,.35))、--c-gold-bg-tint(rgba(255,215,0,.18))、 --c-overlay-white-bg-tint(.08)/-tint-mid(.1)、 --c-overlay-white-text-mid(.7)、--c-overlay-text-{secondary,tertiary,quaternary,placeholder}(.85/.6/.5/.4)。
  • 本页在 vip 分包、navigationStyle: custom：无原生导航栏、无 tabbar； 「我的」页的 VIP 卡入口本身也受 appConfig.isCommerceOn('vip') 控制（pages/profile/index.vue:1325） ⇒ 两道闸都开着才进得来，缺一即不可达。
