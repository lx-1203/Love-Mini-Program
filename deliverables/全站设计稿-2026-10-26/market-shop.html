20px / 20px / 48px · 非素材缺口
与实况的已知差异 + 数值口径（画板不修，登记在此）：
  • 默认态是封存，F02–F05 画的是开关开启态。判据 market/shop/index.vue:32 commerceSealed = !appConfig.isCommerceOn()（不传 module ⇒ 只判总闸 commerce.enabled， 实装 stores/app-config.ts:64-77，缺 key 即封存）；onShow 在封存态直接 return（:43-47）， 积分与商品两条请求都不发。与 VIP 三页不同：本页封存在页面内渲染白卡，不重定向。 :36-40 的 watch(commerceSealed) 是解封补偿（MP-R2-次要22-003），删它会在解封后误显「该分类下暂无商品」。
  • 六件商品的价格 / 原价 / 销量 = mock 种子（:141-204 buildMockShopItems()， 与 detail 页 mockCatalog 同源）：¥99/¥129·56、¥29.9/¥39.9·128、¥9.9/¥15·234、¥19.9/¥25·89、¥15/¥20·45、¥12.9/¥18·167。 real 模式走 GET /products?page=0&pageSize=20（后端页码从 0 起），价格由 admin 商品管理维护 ⇒ 画板数字是演示种子口径，不是后端真值。
  • 积分 100 = mock 种子（constants/growth.ts:37 MOCK_POINTS_BALANCE）， real 由签到状态接口的 points 覆盖；积分与交友币是两套账：本页条展示的是签到积分， wallet 页展示的是 /wallet/balance 交友币，二者不得互推。
  • 角标只在 mock 存在：real 的 toShopItem() 把 tag 写死 ""（:133）， 后端商品无角标字段 ⇒ 四枚角标（热销/新品/限时/推荐）属演示态专属，验收时不得按 real 判缺。
  • 返回盘描边 1px --c-neutral-500 是 R11-L14-D09 的可达性收口结果（原 --c-border-card 在浅绿页底上不可辨）， 画板按收口后的实况画；--statusbar 由 useMenuButtonRect 注入，画板按 44px 状态栏 + 12px 内衬落地。
  • BASE_PROBLEM（base 缺档，本页按 scss 真值 1:1 落字面量）： --c-vip-from(#C9A36A, scss:46/309)、--c-vip-border-tint(rgba(201,163,106,.35), scss:869)、 --c-neutral-400(#9AA39F, scss:355)、--c-tint-gray-50(#F3F4F6, scss:831，本页仅 $border-light 别名引用)、 --c-overlay-text-secondary(rgba(255,255,255,.85), scss:750)。 另 base 的 --c-gold 登记为 #C9A36A，与两个登记处（scss:814 / tokens.scss:347）的 #FFD700 不一致 ⇒ 见 vip 三页画板回报。
  • 本页在 market 分包、navigationStyle: custom：无原生导航栏、无 tabbar； 无上一页时 goBack 兜底 switchTab /pages/home/index（:66-70）。
