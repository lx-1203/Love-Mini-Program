页面状态稿 · 9 屏

素材依赖

本页图标全部走工程既有 ICONS_* 体系，无新素材缺口

ICONS_EMOJI.SEARCH / LOCK

搜索框放大镜、未解锁锁角标。二者是位图/外链 SVG，<image> 吃不到 currentColor，画板按 lucide 同形描边档重绘。

16px / 12px · --c-text-tertiary · --c-bg-container
ICONS_COMMON.CHECK_WHITE_SVG

批量勾选内的白勾（v-if="selectedIds.includes(userId)" 才挂）。画板用同形描边勾，白字压 --c-brand。

14px · --c-bg-container
ICONS_COMMON.HEART / ICONS_SOCIAL.VISITOR / HEART_SIGNAL

空态图标与心动信号丸前缀。工程侧是彩色插画（不走 EmptyState 的 --preset 归色 filter），画板按同形矢量单色档绘制。

60px / 16px · --c-romance-300 · --c-romance
用户实拍 · 头像 / 登录墙头像环

头像位是用户上传（resolveMediaUrl(item.avatar)），设计稿不得放示例或网图。画板统一走源码 v-else 首字占位分支；登录墙 6 枚演示头像用灰底圆 + 心动角标占位。

52px / 48px · 非素材缺口
与实况的已知差异 + 档位替换对照（画板不修，登记在此）：
  • 标签页是 3 档不是 2 档。任务描述写「喜欢我的 / 我喜欢的人」两档，源码 likesTabs 给三档：likedBy / myLikes / visitors（第三档访客懒加载 fetchVisitors）。画板按源码画三档。页标题也不是「喜欢我的」而是 likes.title「匹配列表」。
  • 本页没有「在线标 / 已匹配徽标 / 回关 / 打招呼」。源码里 likes-card--mutual 只改卡框与箭头配色，无文字标签；打招呼/发消息在他人主页（profile.otherMessage）与聊天页，不在这张卡上。画板不补不存在的件。
  • HeartSignalStatus（pending / accepted / expired / declined）不在本页渲染。本页只读 heartSignals.length > 0 决定信号丸显隐，四档 status 的专属视觉属 heart-signals 页，画板只在 §02 列表登记，不在帧内造 UI。
  • 不显示匹配度/合拍度。按产品裁定真值就绪前不回填，画板帧内没有任何百分比；卡片第二行是契约真字段 headline ← LikedUserView.campusName（校名），不是算法分。
  • Tab 角标是计数，属「示意值，非真值」。角标绑 likedBy / likes / visitors 三个数组的 length（0 时隐藏，>99 显示 99+），画板内取演示条数 6 / 4 / 5。帧内未出现「X 人查看过你」一类浮层计数——源码里没有这个件。
  • 角标绑的是未过滤数组。likesTabs 取 likedBy.value.length 而非 displayLikedBy.length ⇒ F06 搜索无结果时列表空、角标仍是 6（画板按实况保留这一对不一致，验收时不要当成画板错）。
  • 错误态图标沿用放大镜。ErrorState type="network" 的 iconSrc 映射到 ICONS_COMMON.SEARCH（组件内既有口径，R12-L11-D08 只改了 EmptyState 的 network 档）⇒ 帧上「网络连接失败」配一枚放大镜，语义不贴，登记不改码。
  • 演示人设：小满（北京大学）、周岚（复旦大学 / 清华大学）、阿辰（浙江大学 · 实名认证 / 中山大学）、星辰（南京大学 · 邮箱认证）、小溪（武汉大学 / 浙江大学）；时间文案逐字取 common.justNow / minutesAgo / hoursAgo / daysAgo 与 likes.monthDay。
  • 未登记档位替换对照（源页 <style> 引用了 base 未收录的 --c-*，画板改用最接近的已登记档）：--c-neutral-50→--c-bg-surface（时间胶囊底）；--c-neutral-100→--c-border-light（同值 #EEF2F0：跳过钮 / 清空钮 / 固定栏上边框）；--c-neutral-200→--c-border-default（骨架 shimmer 中段）；--c-neutral-300→--c-border-strong（checkbox 描边）；--c-bg-brand #E8FBF2→--c-brand-50（头像底/描边、选中卡、箭头渐变）；--c-brand-900 #0B4A38→--c-brand-800（登录墙主钮渐变塌成单色实底）；--c-romance-100/200→--c-romance-50 / --c-romance-300（信号丸底、粉箭头渐变）；--c-romance-700 #CC4A5F→--c-romance（mutual 箭头字形，R14-L06-D12 的 3.05:1 达标值在画板上退一档，真机仍以源码为准）；--c-romance-500→--c-romance（同值）；--c-quaternary/neutral-400→--c-text-placeholder（ErrorState 副标）；--c-overlay-strong(er)→--c-text-primary（锁角标底、已选数胶囊底）；--c-badge-email-*→--c-status-info、--c-badge-idcard-*→--c-warning（VerificationBadge 组件内档位）。
  • 渐变/阴影档位对照：--c-gradient-page #DFF3EA→#EEF7F2→画板用 --c-bg-page 实底；--c-gradient-brand-overlay（brand @ 8%→透明）→--c-brand-50→透明；--c-gradient-brand→linear-gradient(--c-brand, --c-brand-400)；--s-romance 与 --c-black-shadow-sm（固定栏上浮影）base 未登记→画板省略阴影、只留 0.5px 上边框；--r-card 40rpx 与 --card-radius 同值，画板用 --r-card。
  • 帧内可见的两处结构性事实（验收要判）：① 游客态登录墙实高约 728px，而「视口 − 页头带」只有 704px，末钮「稍后再看」下沿被 .likes-page--guest{height:100vh;overflow:hidden} 裁掉约 24px（R10-L06-D25 收口后仍差一档，题注已记，画面无注记）；② 列表末条沉入固定解锁栏（页底 padding-bottom: calc(env + 160rpx) 的 spacer 只在 hasLockedItems 时给）。
  • 对比度遗留（登记不改码）：心动信号丸 12px/600 的 --c-romance-500 字压 --c-romance-50 底 ≈ 2.4:1；批量「取消喜欢」白字压 --c-romance-500 ≈ 2.7:1（同栏「喜欢」用 brand→brand-700 已达标）。两处的收口口径与 R14-L06-D11 相同（落 romance 档最深可用值），画板按源页原样呈现，便于比对时一眼定位。
  • 本页在 discover-extra 分包、navigationStyle: custom，无 tabbar、无原生导航栏；页头是页面自绘的白圆返回「‹」+ 深色标题（R10-L06-D26 / R13-L06-D09 口径），右侧为微信胶囊预留 --capsule-right + 96px 空带——画板里这段空带保持空白，不得填入任何控件。
  • 页头在有心动信号丸时会折行（flex-wrap: wrap + MP-R1-LIKES-001 的换行让位口径）：F04 / F06 / F08 / F09 的「心动信号 + 管理」整体落到标题下方第二行右对齐，F02 / F03 / F05 / F07（无信号丸）则与标题同行。这是源码行为，不是画板排版失误。
  • 本页可下拉刷新（enablePullDownRefresh: true）：三源并发重拉 fetchLikes / fetchHeartSignals / fetchVisitors，画板不画下拉态（非静态可视态）。
