与理想效果图《附近的首页.png》的已知差异（画板不修，登记在此）：
  • 本页最高优先一条：理想图无「附近的人」分区与「附近活动」分区；2026-10-26 裁定选 C 折中保留二者，画板按裁定后的实况画，理想图降为历史参照
  • 理想图五宫格下方还有两张全宽入口卡（「附近的人 · 按距离找到身边的人」「同城的人 · 同城更多心动可能」），2026-10-26 已整块删除；整屏列表出口移到分区头「全部」（goPeople(peopleScope)）。模板内已搜不到 people-entry。
  • 分段标签按规范 §3.5 定为「按距离 / 同城」，不再是「附近的人 / 同城的人」；两枚旧词条（nearby.peopleNearby / nearby.peopleCity）仍在 i18n 里但本页模板零消费。
  • 理想图定位行为「北京大学 · 3km」。实况 buildLocationText() 只返回 city 或 campusName，检索半径无后端字段，其注释点名「字段落地前宁缺：只显地名，不显假距离」⇒ 画板按实况画「北京大学 · 切换城市 ›」，不回填 3km。
  • 理想图校园圈卡次行是「3.2k 位同学」，状态为 已加入 / 去认证 ×3。实况 School 与 CampusView 都只有 id/name/city 三键、全库无学校维度成员数 ⇒ 次行画真实 city；campusChipKey() 只允许本校出「已加入/去认证」，其余恒「公开浏览」⇒ 画 已加入 + 公开浏览 ×3。理想图此处为演示值，产品裁定真值就绪前不回填，画板按留空/按实况画。
  • 理想图兴趣圈计数为 1.2w / 8602 / 1.6w / 1.1w，画板取 mockCircles 前 8 条经 formatMemberCount() 的输出口径（≥1w 折「w」、千位段裸数字不加逗号）。演示计数，非真值。
  • 理想图帖子互动栏是「♡128 💬24」两键。实况 PostCard 底栏为「时间 + 评论/点赞/收藏三键」（R13-L01-D11 已撤除分享死钮），且画板按 nearbyPosts.slice(0,3) 出两条帖。赞评数取理想图值，演示计数，非真值。
  • 理想图分区⑤标题右侧只有一枚箭头。实况统一走 NearbySection，五个分区头一律「全部 ›」。
  • 理想图校园圈四张卡完整并排。实况 .campus-entry 按 R12-L02-D03 改定宽 flex:0 0 248rpx 且 .campus-cards 不可横滚 ⇒ 可用宽 686rpx 只容 2.6 张，第 3 张起被视口右缘裁切。画板按实况几何画，不为了凑齐四张把卡宽压回 flex:1（那正是该条裁定撤掉的形态）。
  • 五宫格五枚字形的工程真值是 CSS filter 烘出的 #36C99A / #36C99A / #0EA5E9 / #F97316 / #4F6EF7。后三档在 base 未登记 ⇒ 画板用同族已登记的 --c-status-info / --c-warning / --c-purple 近似，色相族（蓝/橙/靛）不变。
  • 右下角 FAB 为 position:fixed，滚动后仍压在「附近动态」首帖右上一带——这是缺陷4-6 落地后的实况遮挡，非画板笔误。
  • board-base.css 缺 --c-lavender-50 / --c-lavender-500 / --c-apricot-100 / --c-apricot-500 四枚（design-variables.scss v4.0.0 已有，本页「去认证」胶囊与活动图标底板正在消费）⇒ 画板以同族已登记令牌 --c-purple / --c-warning 加同值 rgba 底近似，待主控补登后回改。
  • 本页是主包五页之一 ⇒ TabBar 必画，选中「附近」。理想图与实况一致，无差异。
