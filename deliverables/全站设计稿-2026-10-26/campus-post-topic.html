页面状态稿 · 6 屏

可发空表单 / 未认证横幅 / 填写中 / 超字数 / 发布中 / mock 档

本页状态机有 6 屏，分支全部取自源码：v-if="certGate === 'denied'"（未认证横幅， certGate 三态 allowed / denied / unknown）、v-if="!imagesAccepted"（配图常驻说明， 现 CAMPUS_TOPIC_IMAGES_SUPPORTED = true 故不渲染）、v-if="images.length < MAX_IMAGES"（加图格子）、 anonymousBlocked ? anonymousUnsupported : anonymousDesc（匿名说明二选一 + 开关禁用）、 以及 canSubmit / isSubmitting 驱动的顶栏与底部两枚提交钮。 页头无原生导航栏：左「取消」白半透胶囊、中标题、右「发布 / 发布中」白胶囊（右端让出微信胶囊 104px）。 帧即视口：超出 812px 的内容被裁掉，被裁掉什么写在题注里，不写进画面。

TopicSelector（共享组件）

话题选择区是 components/village/TopicSelector.vue，其完整状态规范在 village-index.html 的 F11–F12 已定档；本页只画它在这张表单里的落地形态（已选 2/3、空态、搜索、热门、创建行）， 不重复定义组件状态。热门话题名取 config/popular-topics.ts 真值，其 usageCount 已按 R12-L05-D08 撤下，画板不出现热度数字。

chip --r-full · 选中底 --c-bg-brand + --c-brand-200 描边
与同族「兴趣圈发话题页」（circles/circles/post-topic）的差异清单（两页共用同一计数常量，其余形态各走各的）：
  • 页头右端：本页顶栏常驻「发布 / 发布中」白胶囊，与底部主 CTA 双出口并存； 兴趣圈页已按 §3.14（R11-L04-D10）撤除页头那颗，只留等宽占位块。两页现在对「一处发布出口」的口径并不一致。
  • 返回文案：本页 campus.postTopic.cancel =「取消」；兴趣圈页 circle.postTopicBack =「返回」。同一形态两种文案。
  • 正文计数：两页同 0/1000（MAX_LENGTH = POST_MAX_LENGTH，2026-10-26 统一到 1000）。 差异只在标题上限：本页 maxlength="50"（页内字面量），兴趣圈页 :maxlength="POST_TITLE_MAX_LENGTH" = 30。
  • 配图上限：本页 UI_LIMITS.PHOTO_GALLERY_MAX = 6，计数在分区标题右侧 N/6，格子内是「添加图片」文案； 兴趣圈页 MAX_IMAGES = 9，格子内显示 N/9。
  • 卡片圆角：本页按 R11-L05-D09 统一 --card-radius（40rpx=20px）；兴趣圈页仍是 --r-xl（24rpx=12px）。
  • 底部主 CTA：本页 brand→brand-300 mint 渐变 + 禁用底 --c-border-light； 兴趣圈页按 R10-L04-D10 收成 --c-brand-800 实底 + --c-status-disabled 禁用底。
  • 目标选择：本页无「发布到」，改为 6 个话题分类宫格（课程交流 / 社团招新 / 校园活动 / 学习互助 / 生活服务 / 校友动态）； 兴趣圈页是「校园圈 / 兴趣圈」二选一 + 8 个兴趣分类。
  • 本页独有：未认证横幅（certGate === 'denied'）、TopicSelector 话题选择器、匿名发布开关、双提交出口。 兴趣圈页独有：话题标签多选（≤3）、喜爱开关、帖子模式关联活动与活动弹层（后两者 v-if="useMock()"，real 档整块不渲染）。
  • 页边距：本页 .post-body 四边 24rpx（12px）；兴趣圈页按 R11-L04-D08 左右走 --page-padding（16px）。
与实况的已知差异 / base 缺档登记（画板不修，登记在此）：
  • base 未登记档位：本页源码用了五个 board-base.css 里没有的令牌，画板按真值以字面量落盘并逐条注明—— rgba(255,255,255,.25) = --c-overlay-white-bg-mid-strong（取消胶囊底）、 rgba(255,255,255,.95) = --c-overlay-bg-pure（发布胶囊底）、 #92400E = --c-text-warning-dark（横幅左轨/按钮/警示字）、 #E8F5E9 = --c-tint-green-50（分类选中渐变终点）、 rgba(0,0,0,.5) = --c-bg-overlay（删除钮底）、 0 1px 8px rgba(0,0,0,.04) = $card-soft-shadow（--c-black-shadow-xs）。 另 --c-bg-secondary(#D1F5E7) 与 --c-text-quaternary(#9AA39F) 未登记， 与在册的 --c-brand-100 / --c-text-placeholder 同值，画板直接取后者。
  • 状态栏字色：pages.json 全局 navigationBarTextStyle: "black"，故画板用深色状态栏字； 页头文字本身也已按 R9-L05-D07 收成 --c-text-primary。
  • 「暂未开放配图」常驻说明画不出来：v-if="!imagesAccepted" 里 imagesAccepted = isMockMode || CAMPUS_TOPIC_IMAGES_SUPPORTED，而后端写侧契约已于 2026-09-26 补齐 ⇒ 该分支恒 false，属死 UI。画板按实况不画，登记在此以免有人以为是漏画。
  • F04 的 1012/1000 是被测状态，不是文本长度反推：mp <textarea> 未开 auto-height ⇒ 定高 240rpx 内滚，画板只落可见首段并把其余裁在框内。真机上键盘输入被 :maxlength 截断在 1000， 红态只能由非键入路径到达。
  • 不捏造数据：本页无分数/共同点位；话题名取 config/popular-topics.ts，分类名取 stores/campus.ts CAMPUS_CATEGORY_MAP，文案逐字取 i18n/locales/zh-CN.ts，均未自创。
  • 本页在 campus 分包，无 tabbar——画板若出现 tabbar 即为错。
