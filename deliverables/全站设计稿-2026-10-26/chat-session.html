基准声明：聊天会话页此前只有《全站设计规范与逐页设计稿说明》§3.7 文字规范、无整页基准图，本画板是它的第一张帧基准（§01 的 11 屏即验收对照帧）。凡源码渲染与 §3.7 冲突之处均以源码实况画出，逐条登记如下（画板不修）：
  • §3.7「输入栏（语音/文字/表情/加号）」与实况冲突：语音输入模式已从本页源码下线（index.vue 注释「语音功能已移除」），输入栏实际 = 表情键 + 「＋」键 + input + 常显发送；语音仅作为历史 VoicePill 消息兜底渲染（F03 已画）。
  • §3.7 四段结构「顶部…→ 匹配成功引导 + 破冰问题 chips → 消息流」与实况冲突：MatchGreetingTip 实际渲染在消息流内部首行（v-if showMatchGreeting，空会话时垂直居中），BreakQuestion 卡片实际在输入栏正上方（输入区内），均非「页头下引导区」。按源码实况画（F02）。
  • §3.7 组件清单含 IcebreakerSuggestions，本页源码未引用（破冰卡实际是 BreakQuestion；IcebreakerSuggestions 为 messages 页件）。§3.7 未提的 ActivityCard（活动卡片消息）与 HeartSignal 本页模板有分支但为纯数据驱动，未整帧，仅在此登记。
  • §3.7 未提的实况分支：页头与消息流之间还有关系状态带（relationshipInfo）、缘分速配带（fromSignal）、引用卡（quoteContext）三段；错误态整条身份带撤下、输入区仅剩「返回/消息」（R11-L11-D15/D17，F05）。
  • 气泡规格 R20 与令牌逐条一致，无冲突：--bubble-max-width 58% / padding 14·22rpx / 圆角 20+4rpx / 正文 28rpx·1.6 / 纯 emoji 56rpx / 头像 64rpx 顶对齐 / --bubble-shadow none（双方禁用）/ 对方气泡 --c-bubble-other #FFFFFF 纯白，均与 §3.7 逐字对上。ChatBubble :259 注释仍写旧值「84%」为未同步的陈旧注释，以令牌值为准。
  • 58% 口径注明：max-width 量在「头像+气泡」整体容器 .bubble-wrap 上，气泡本体实际更窄（§3.7 未写明口径）。
  • 临时/普通会话页头兜底值：「认识 1 天」「离线」是前端兜底渲染（relationDays 缺省 1、online 初值折叠 false），源码已登记 NOT-FIXABLE-HERE→F2，本画板按实况照画（F06/F07）。
  • 私有色归一对照（改令牌、留注记）：ChatHeader 私写 #36C99A/#222/#999/#666/#FF6B81 → --c-brand/--c-text-primary/--c-text-placeholder/--c-text-tertiary/--c-romance；--c-neutral-50 #F7FAF9（键底/输入底）与 --c-bg-brand #E8FBF2（语音条/错误动作底）→ 就近 --c-bg-surface / --c-brand-50；BreakQuestion 全套私色（#f8fffc/#eaf9f2/#22a976/#fff0f6/#ffd2e3/#e94d87）→ --c-bg-surface/--c-brand-50/--c-brand-600/--c-romance-50/--c-romance-300/--c-romance；temp 横幅边 --c-brand-shadow-tint → --c-brand-100；助手气泡 #E8F8F1 → --c-brand-50；时间条底 --c-overlay-faint 与遮罩 --c-black-overlay-mid（rgba 中性/黑）无登记档位，按 base 同源 rgba 中性色保留字面值。--bubble-* 家族与 --c-bubble-other 未登记进 board-base.css（BASE_PROBLEM 已回报），本画板按 design-variables.scss :637/646-657 1:1 声明使用。
  • 不捏造分数：关系状态带「亲密度」按产品裁定不回填，画板显示「—」（无后端快照即整区不渲染）；signal 进度 30% 为消息数换算的互动进度，非匹配度类数值。
  • LockScreen（v-if="!isUnlocked"）为跨页共享未登录闸门组件，不在本画板重复出帧。
  • 本页在 chat 分包，无 tabbar——画板若出现 tabbar 即为错。
