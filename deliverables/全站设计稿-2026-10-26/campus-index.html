校园圈私域主页 高保真设计稿

路由 subpackages/campus/campus/index。 这是认证通过后的本校私域主页，唯一入口是校园圈 Hub（campus/hub） 点校名卡片带 ?school= 跳入。 本页权限门不在组件里，而在两条 computed 上：isVerified 决定「引导 / 私域」， isOwnCertifiedView 决定「本校可发帖 / 非本校只读」。 本画板把门链四分支 × 内容区四态共 8 屏画全，作为该页永久验收基准。

页面状态稿 · 8 屏

权限门四分支 + 内容区四态 + 认证拉取失败条

本页状态机有 8 屏，分支全部取自模板条件表达式： v-if="certificationError"（:284，门链之外的独立错误条）、 v-if="!isVerified"（:298 引导卡 / :310 推荐兴趣圈）、 v-else-if="!isOwnCertifiedView"（:324 公开浏览提示条）、 v-if="isVerified || viewSchool"（:330 内容区）、 内容区内 loading && topics.length === 0 → topicsError && topics.length === 0 → topics.length === 0 → 列表四段互斥、 v-if="isOwnCertifiedView"（:434 发帖 FAB）。 两条判据的真值源：isVerified = state.certificationStatus === "verified"（stores/campus.ts:387-389）、 isOwnCertifiedView = isVerified.value && (!viewSchool.value || viewSchool.value === certificationInfo.value?.schoolName)（本页 :72-74）。 帧即视口 375×812：超出部分裁掉，被裁掉了什么只写在题注 .d 里，画面内零注记。

画板内以 lucide 描边 symbol 替身，不改 base
与实况的已知差异 / 结构性事实（画板不修，登记在此）：
  • 分包页，无 tabbar；navigationStyle: custom 无原生导航栏 ⇒ 页头由页面自画渐变带， 返回是 88rpx 半透明白圆 + 「‹」字形。画板出现 tabbar 即为错。
  • pending / rejected 没有专属视图：isVerified = certificationStatus === "verified" 是唯一门槛， 审核中与未通过都落进「未认证」引导支，引导文案逐字相同，只有页头徽章底色不同。 想给「审核中」做单独画面 = 画板越权，源码里没有。
  • 公开浏览提示条挂在推荐圈的 v-else-if 上（:310 v-if="!isVerified" → :324 v-else-if="!isOwnCertifiedView"）： 未认证用户即使正在看外校也看不到「公开浏览」提示，提示只发给已认证非本校者。F01 与 F03 因此形态不同。
  • 恒 false 死分支两处： ① 话题卡头像位的**图片分支**——mock 夹具（stores/campus/mock-data.ts）16 条 author 的 avatar 全空 ⇒ v-if="topic.author?.avatar" 在 mock 档恒 false，画板按 real 档（后端下发 authorAvatar）画真素材头像。 2026-10-27 更新：源码已把该位改成「外壳常挂 + 内层二选一」（照 topic-detail.vue:225-234 / circles/topics.vue:690-701 先例），具名无头像者出 name 首字圈（底色 --c-bg-brand→--c-bg-romance、 字色 --c-brand-700，比先例 500 档深一档以压住浅薄荷底）；匿名仍什么都不画（产品只裁定了具名那一档）。 ⇒ 本条从「整块空白的死分支」降级为「图片分支在 mock 档不可达」，§02 第三形态位已按新画法改绘并重拍。 ② 页头校名兜底 t('campus.index.defaultSchool') = 广州大学——要 viewSchool 与 certificationInfo 同时为空才显示， 而 viewSchool 为空时 onLoad（:225-226）已 uni.redirectTo(hub) ⇒ 该兜底只在跳转前一瞬可达，不构成可验收屏； 同一条 !viewSchool 也令 isOwnCertifiedView 的第一子条件近似死路（Hub 入口恒带 ?school=）。
  • SafeImage custom-class 已知机制（已知机制 §1）：引导卡图标 56rpx、状态槽图标 100rpx、FAB 图标 44rpx 三处尺寸写在 custom-class 上，跨不过 data-v 边界，源码自证「帧上图标本就不可见、不占宽」（:613-614）。 ⇒ 画板不画引导卡图标（按实况），FAB 与状态槽图标按语义补画 lucide 替身；这三档尺寸日后改挂宿主标签时应当场生效。
  • 两处横向缩进不同源：引导卡 / 话题卡外缩进 24rpx，提示条 32rpx，推荐圈卡（card-base）无左右缩进直接贴屏边。 实况如此，画板照画。
  • 演示数据全部有源：标题 / 摘要 / 回复数 / 相对时间取自 stores/campus/mock-data.ts 的 course_exchange 两条夹具 （「没有更多了」由 topicHasMore = filtered.length >= TOPIC_PAGE_SIZE(10) 判出）； 时间文案取 RELATIVE_TIME_TEXT["zh-CN"]（utils/time.ts:41-46，「30 分钟前」「1 小时前」）。 作者名按规范第 4 条改用真名池（阿辰 / 周岚），夹具原名为「学长小王」。 本页没有分数类真值位（合拍度/匹配度一类），故不存在「留空 vs 造数」的取舍。
  • 本校名与 Hub 画板对齐：certificationInfo.schoolName 取「北京大学」，非本校视角取「清华大学」， 与 campus-hub.html F04/F05 同一套演示事实（i18n defaultSchool「广州大学」是上面那条死兜底，不采用）。
  • FAB 纵向位：原式 calc(env(safe-area-inset-bottom) + 150rpx)，画板不画 iOS home indicator ⇒ 取 env=0（75px）； 真机安全区 34px 时应为 109px。
